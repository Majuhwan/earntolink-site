개인정보처리방침

시행일 2026년 10월 10일

1. 총칙

언투링크(EarnToLink, 이하 "언투링크")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호합니다. 이 방침은 웹사이트 earntolink.com과 언투링크가 만드는 자체 앱에 적용됩니다.

요약: 웹사이트는 회원가입, 입력 양식, 쿠키, 분석 도구, 광고를 사용하지 않습니다. 자체 앱은 파일과 사진을 기기 안에서만 처리하며 외부로 전송하지 않습니다.

2. 웹사이트

  • 회원가입, 로그인, 입력 양식이 없습니다.
  • 쿠키, 접속 분석 도구, 광고 스크립트를 사용하지 않습니다.
  • 웹사이트는 GitHub Pages(GitHub, Inc.)로 제공됩니다. GitHub는 서비스 운영과 보안을 위해 접속 IP 주소 등 접속 기록을 처리할 수 있으며, 이에는 GitHub 개인정보 방침이 적용됩니다.
  • 글꼴(Pretendard)은 jsDelivr CDN에서 불러옵니다. 이 과정에서 브라우저의 IP 주소 등 요청 정보가 jsDelivr에 전달될 수 있습니다.
  • 쿠키나 분석 도구를 도입하는 경우 도입 전에 이 방침을 개정합니다.

3. 이메일 문의

항목목적보유 기간
이메일 주소, 메일에 표시된 이름, 문의 내용과 첨부 파일문의 확인과 답변, 프로젝트 상담, 요청 처리처리 완료 후 지체 없이 파기. 계약으로 이어진 경우 계약 기간과 관계 법령이 정한 기간 동안 보관

문의 메일은 Google LLC가 제공하는 Gmail로 수신하고 보관합니다.

4. 자체 앱

대상: 정리 싹(Roll Tidy), 넘겨 정리(Roll Flick), 용량 지도(Space Map), 중복 싹(Dupeless), 한글 압축(Archive Fix). 모두 출시 준비 중입니다.

앱처리 대상처리 위치외부 전송
정리 싹사진 접근 권한을 허용한 사진첩의 사진 · 동영상기기 안없음
넘겨 정리사진 접근 권한을 허용한 사진첩의 사진기기 안없음
용량 지도사용자가 고른 폴더의 파일 이름 · 크기 · 종류기기 안없음
중복 싹사용자가 고른 폴더의 파일 크기와 내용 해시기기 안없음
한글 압축사용자가 고른 압축 파일과 파일기기 안없음
  • 앱은 네트워크에 연결하지 않으며 파일과 사진을 업로드하지 않습니다.
  • 계정, 광고, 분석 도구, 오류 보고, 추적 기능이 없습니다.
  • 지운 파일과 사진은 운영체제 휴지통(iOS는 최근 삭제된 항목)으로 이동하며 복원할 수 있습니다.
  • 설정값, 정리 기록(넘겨 정리), 사진 분석 값 캐시(정리 싹: 해시 · 선명도 · 밝기)는 기기 안 앱 저장 공간에만 저장됩니다.
  • 결제는 각 앱 스토어가 처리하며 언투링크는 결제 수단 정보를 받지 않습니다.

5. 고객 프로젝트

고객이 의뢰한 프로젝트에서 고객의 개인정보를 다루는 경우, 처리 범위와 방법은 고객과 맺는 계약과 처리 위탁 약정에 따릅니다.

6. 제3자 제공

개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 요구되는 경우는 예외로 합니다.

7. 정보주체의 권리

이용자는 언제든지 개인정보 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 요청은 hello@earntolink.com로 접수하며 지체 없이 조치합니다.

8. 파기

보유 기간이 끝나거나 처리 목적을 달성한 개인정보는 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다.

9. 안전성 확보 조치

문의 메일 열람 권한을 대표로 한정하고, 필요한 범위를 넘는 개인정보를 수집하지 않습니다.
