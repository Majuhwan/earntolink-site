1. ข้อกำหนดทั่วไป2. เว็บไซต์3. การสอบถามทางอีเมล4. แอปของเรา5. โปรเจกต์ของลูกค้า6. การเปิดเผยแก่บุคคลที่สาม7. สิทธิของคุณ8. การลบข้อมูล9. ความปลอดภัย10. ผู้รับผิดชอบด้านข้อมูลส่วนบุคคล11. ช่องทางเยียวยา (เกาหลี)12. การเปลี่ยนแปลง

หน้านี้เป็นฉบับแปล หากมีความแตกต่างจากต้นฉบับภาษาเกาหลี ให้ถือตามต้นฉบับภาษาเกาหลี 한국어 원문

1. ข้อกำหนดทั่วไป

EarnToLink (언투링크 "EarnToLink") คุ้มครองข้อมูลส่วนบุคคลตามกฎหมายคุ้มครองข้อมูลส่วนบุคคลของเกาหลี (Personal Information Protection Act) นโยบายนี้ครอบคลุมเว็บไซต์ earntolink.com และแอปที่ EarnToLink สร้างขึ้น

สรุป: เว็บไซต์ไม่ใช้การสมัครสมาชิก แบบฟอร์ม คุกกี้ การวิเคราะห์ หรือโฆษณา แอปของเราประมวลผลไฟล์และรูปภาพบนอุปกรณ์เท่านั้น และไม่ส่งไปที่ใดเลย

2. เว็บไซต์

  • ไม่มีการสมัครสมาชิก การเข้าสู่ระบบ หรือแบบฟอร์ม
  • ไม่มีคุกกี้ เครื่องมือวิเคราะห์ หรือสคริปต์โฆษณา
  • เว็บไซต์ให้บริการผ่าน GitHub Pages (GitHub, Inc.) GitHub อาจประมวลผลบันทึกการเข้าถึง เช่น ที่อยู่ IP เพื่อการดำเนินงานและความปลอดภัย ตาม GitHub General Privacy Statement
  • ฟอนต์ Pretendard โหลดจาก jsDelivr CDN ซึ่งอาจได้รับข้อมูลคำขอ เช่น ที่อยู่ IP ของเบราว์เซอร์ของคุณ
  • หากมีการนำคุกกี้หรือการวิเคราะห์มาใช้ในอนาคต จะปรับปรุงนโยบายนี้ก่อน

3. การสอบถามทางอีเมล

รายการวัตถุประสงค์ระยะเวลาเก็บรักษา
ที่อยู่อีเมล ชื่อที่แสดง เนื้อหาข้อความ และไฟล์แนบอ่านและตอบการสอบถาม ปรึกษาโปรเจกต์ ดำเนินการตามคำขอลบทันทีเมื่อดำเนินการเสร็จ หากมีการทำสัญญาต่อ จะเก็บไว้ตลอดระยะสัญญาและระยะเวลาที่กฎหมายกำหนด

อีเมลสอบถามถูกรับและจัดเก็บใน Gmail ซึ่งให้บริการโดย Google LLC

4. แอปของเรา

แอปที่อยู่ในขอบเขต: Roll Tidy (정리 싹), Roll Flick (넘겨 정리), Space Map (용량 지도), Dupeless (중복 싹), Archive Fix (한글 압축) ทั้งหมดเร็วๆ นี้

แอปข้อมูลที่ประมวลผลที่ประมวลผลส่งออกภายนอก
Roll Tidyรูปภาพและวิดีโอในคลังที่คุณอนุญาตให้เข้าถึงบนอุปกรณ์ไม่มี
Roll Flickรูปภาพในคลังที่คุณอนุญาตให้เข้าถึงบนอุปกรณ์ไม่มี
Space Mapชื่อ ขนาด และประเภทของไฟล์ในโฟลเดอร์ที่คุณเลือกบนอุปกรณ์ไม่มี
Dupelessขนาดไฟล์และแฮชเนื้อหาในโฟลเดอร์ที่คุณเลือกบนอุปกรณ์ไม่มี
Archive Fixไฟล์บีบอัดและไฟล์ที่คุณเลือกบนอุปกรณ์ไม่มี
  • แอปไม่เชื่อมต่อเครือข่ายและไม่อัปโหลดไฟล์หรือรูปภาพเด็ดขาด
  • ไม่มีบัญชีผู้ใช้ โฆษณา การวิเคราะห์ การรายงานแอปค้าง หรือการติดตาม
  • ไฟล์และรูปภาพที่ลบจะไปอยู่ในถังขยะของระบบ (ลบล่าสุดบน iOS) และกู้คืนได้
  • การตั้งค่า บันทึกความคืบหน้า (Roll Flick) และแคชการวิเคราะห์รูปภาพ (Roll Tidy: แฮช ความคมชัด ความสว่าง) อยู่ในพื้นที่เก็บข้อมูลของแอปบนอุปกรณ์
  • การชำระเงินดำเนินการโดยแอปสโตร์แต่ละแห่ง EarnToLink ไม่ได้รับรายละเอียดการชำระเงิน

5. โปรเจกต์ของลูกค้า

เมื่อโปรเจกต์ของลูกค้าเกี่ยวข้องกับข้อมูลส่วนบุคคลของลูกค้า ขอบเขตและวิธีการประมวลผลเป็นไปตามสัญญาและข้อตกลงการประมวลผลข้อมูลกับลูกค้ารายนั้น

6. การเปิดเผยแก่บุคคลที่สาม

เราไม่ให้ข้อมูลส่วนบุคคลแก่บุคคลที่สาม เว้นแต่กฎหมายกำหนด

7. สิทธิของคุณ

คุณสามารถขอเข้าถึง แก้ไข ลบ หรือระงับการประมวลผลได้ทุกเมื่อ ส่งคำขอมาที่ hello@earntolink.com เราจะดำเนินการโดยไม่ชักช้า

8. การลบข้อมูล

ข้อมูลส่วนบุคคลจะถูกทำลายโดยไม่ชักช้าเมื่อครบระยะเวลาเก็บรักษาหรือบรรลุวัตถุประสงค์แล้ว ไฟล์อิเล็กทรอนิกส์จะถูกลบจนไม่สามารถกู้คืนได้

9. ความปลอดภัย

การเข้าถึงอีเมลสอบถามจำกัดเฉพาะผู้แทน และเราเก็บข้อมูลส่วนบุคคลเท่าที่จำเป็นเท่านั้น

  • คณะกรรมการไกล่เกลี่ยข้อพิพาทข้อมูลส่วนบุคคล: www.kopico.go.kr, 1833-6972
