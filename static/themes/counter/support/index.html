Counter support

Email us and we will reply within two business days.

Email hello@earntolink.com

Please include

  1. Your name (first and last)
  2. Your email address (the one you want us to reply to)
  3. Store URL, for example https://your-store.myshopify.com
  4. Theme version, shown in Online Store > Themes (for example 1.0.0)
  5. Subject: a short summary of the issue
  6. Description of the problem: what you expected, what happened, and the page where it happens
  7. Screenshots attached to the email, if possible

The button above opens an email with these fields ready to fill in.

What support covers

  • Questions about theme settings, sections and features
  • Bugs in the theme (layout, broken links, logic errors), fixed in a theme update
  • Help with the setup steps in the documentation

Not covered

  • Custom code changes, or code you added
  • Third-party apps
  • Store design or content work

Before editing theme code, duplicate your theme. For custom work, consider hiring a Shopify Partner.
