使用方式

開啟工具

  1. 在首頁選擇類別或在搜尋方塊中輸入以尋找工具。
  2. 將檔案拖入工具，設定選項後執行。除非另選資料夾，結果儲存在「文件\Kemptly」。

釋放磁碟空間

  1. 使用空間地圖、重複檔案、相似相片或大型舊檔查看佔用空間的內容。
  2. 選取的檔案會移至資源回收筒。免費版每天最多 20 個。

復原移動和重新命名

  1. 開啟「記錄」。所有移動和重新命名都會記錄，並可復原。

自動整理新下載的檔案

  1. 在「資料夾規則」中新增包含條件（名稱、類型、大小）和動作（移動、重新命名、資源回收筒）的規則。
  2. 免費版最多 3 條規則。

功能

  • 清理、去除重複、整理檔案,隨時可復原
  • 壓縮、轉換和編輯圖片與照片
  • PDF 合併、分割、簽名、OCR 和塗黑
  • 影片轉換與剪輯,轉寫為字幕
  • 搜尋文件內容,依人臉或描述尋找照片（Pro）
  • 工作流程和監看資料夾,離線可用,不需帳號（監看資料夾：Pro）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

檔案和輸入內容僅在此電腦上處理，不會上傳。部分功能首次使用時會下載一次模型或元件，之後可離線使用。沒有帳戶、廣告或追蹤。

支援哪些檔案格式？

影像：JPG、PNG、WEBP、BMP、TIFF、GIF、ICO（HEIC 和 AVIF 需免費 Windows 擴充功能）。文件：PDF；Word、Excel、PowerPoint 轉 PDF 需已安裝 Microsoft Office。郵件：EML、MBOX。影音：MP4、MOV、MKV、MP3、WAV、M4A 等。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

無法將 Word、Excel 或 PowerPoint 轉為 PDF。

此轉換使用電腦上安裝的 Microsoft Office。請安裝桌面版 Office 並啟動一次後重試。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

處理速度慢。

大型檔案或大量檔案需要更長時間。請關閉其他佔用資源的應用程式，筆電請接上電源，並在工作完成前避免電腦進入睡眠。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
