使用方式

查看哪些應用程式在連線

  1. 即時清單依應用程式分組顯示遠端位址、主機名稱、連接埠和簽署發行者，每秒更新。
  2. 新應用程式首次對外連線時，可在通知中直接允許或封鎖。

封鎖或允許應用程式

  1. 選取應用程式並選擇「封鎖」或「允許」。規則是名稱以 ETLNW- 開頭的 Windows Defender 防火牆規則，開啟應用程式後第一次變更時 Windows 會要求一次權限。
  2. 免費版最多同時封鎖 5 個應用程式，允許不限數量。

查看被封鎖的連線嘗試

  1. 在設定中開啟封鎖紀錄。開啟期間，Windows 會稽核防火牆封鎖的連線（安全性稽核「篩選平台連線」失敗），歷史紀錄中會列出已封鎖應用程式的嘗試。
  2. 關閉此項或結束應用程式時，會將 Windows 稽核設定還原為原本的值。如果應用程式意外結束而未能還原，設定中會顯示「還原」。連線較多的電腦上，開啟期間安全性記錄會更快寫滿。

功能

  • 依應用程式的即時連線：路徑、發行者、位址、連接埠、主機、狀態
  • 新應用程式首次連線時提醒，可直接允許或封鎖
  • 用 Windows Defender 防火牆規則封鎖或允許應用程式
  • 不需系統管理員權限執行，每次開啟應用程式只需一次 UAC 確認
  • 可選：記錄被封鎖的連線嘗試（Windows 稽核）
  • 鎖定模式與工作 / 遊戲設定檔（Pro）
  • 依應用程式的連線紀錄、CSV 匯出（Pro）、系統匣應用程式

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

解除安裝後規則仍然存在。

移除應用程式後 Windows 會保留防火牆規則。解除安裝前請在「設定」中刪除規則。以 ETLNW- 開頭的規則也可在 Windows Defender 防火牆中刪除。

出現權限提示。

部分操作會變更系統設定或其他程式，需要系統管理員權限。請在「使用者帳戶控制」提示中選取「是」。選取「否」只會略過該操作。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
