使用方式

合併和整理 PDF

  1. 選取「合併與整理」，新增 PDF 或整個資料夾（… 選單），或拖入視窗。每個 PDF 都有自己的頁面縮圖區塊。
  2. 拖曳頁面調整順序或移到另一個文件。放下時按住 Ctrl 為複製。Shift/Ctrl+按一下可選取多頁一起拖曳。拖到「用所選頁新增文件」即可新增文件。
  3. 旋轉（旋轉按鈕）或移除（Delete）頁面。Ctrl+Z 復原、Ctrl+Y 重做，最多 100 步。
  4. 選擇儲存方式：一個 PDF，或每個文件分別儲存（每個區塊一個檔案），然後儲存。免費：每次最多 3 個來源 PDF；Pro：不限。頁面中的連結、註解和表單欄位會保留。

分割 PDF

  1. 選取「分割」並開啟 PDF（或在檔案總管中按右鍵 → Split with PDF Binder）。
  2. 免費預設：每頁、每 N 頁或 1-3, 5, 8- 等範圍（每次最多 10 個檔案）。Pro 預設：依書籤（1–3 層）、依檔案大小（如 10 MB）或依空白分隔頁（空白頁會去掉）。
  3. 清單會顯示將產生的檔案。檔名預設為 {name}_{range}（如 Report_1-3.pdf）；Pro 可用 {name} {n} {range} {from} {to} {pages} {bookmark} {date} 自訂規則。不會覆寫既有檔案（Report (2).pdf）。

書籤與輸出選項（Pro）

  1. 書籤：「保留」會把原書籤移到新頁面位置；「每個檔案一個」會為每個合併的檔案加入書籤，並把原書籤放在其下。分割時勾選「書籤 · 保留」可讓每部分帶上書籤。
  2. 輸出選項：壓縮（輕度、建議、強力，僅在檔案變小時採用）、使用 {n} 和 {total} 的頁碼或頁首/頁尾文字、浮水印文字、用 Windows OCR 產生可搜尋文字（使用 Windows 已安裝的 OCR 語言）、開啟密碼（AES-256）。
  3. 所有選項都可免費選擇並標有 Pro；只有在儲存時才會詢問 Pro，購買後會立即繼續儲存。

檔案總管、監看資料夾和命令列

  1. 檔案總管（免費）：選取 PDF，按右鍵 → Merge with PDF Binder 或 Split with PDF Binder。Windows 11 中位於「顯示更多選項」內；「開啟檔案 → PDF Binder」也可以。這樣開啟的檔案會進入已開啟的視窗。
  2. 監看資料夾（Pro）：在「自動化」中選擇要監看的資料夾和另一個結果資料夾，選擇動作（依目前分割設定分割、套用輸出選項或合併同時到達的檔案）並開始。PDF Binder 開啟期間運作，不變更原始檔案。
  3. 命令列（Pro）：pdfbinder merge <檔案或資料夾> -o out.pdf [--bookmarks perfile]，pdfbinder split in.pdf --bookmarks 1 | --size 10 | --blank | --every 2 | --ranges "1-3,5" [-o 資料夾] [--name "{n} {bookmark}"]，另有 --compress、--numbers、--watermark、--ocr、--password。執行 pdfbinder help 查看全部選項。結束代碼：0 成功，1 用法錯誤，2 失敗，3 需要 Pro。

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

PDF（受密碼保護的 PDF 需輸入密碼開啟）。Pro 還可將圖片（JPG、PNG、TIFF、HEIC…）作為頁面加入。結果一律儲存為新檔案，原始檔案不會被變更。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

PDF 要求輸入密碼。

輸入開啟 PDF 的密碼。不知道密碼的檔案無法開啟。儲存的結果沒有密碼（在輸出選項中設定密碼需 Pro）。

合併後的 PDF 中的連結無法跳轉。

網頁連結和指向頁面的連結會保留，並跟隨頁面到新位置。指向已移除頁面的連結無處可去。使用其他檔案「命名目標」的連結可能失效；書籤（Pro）會重建，始終指向正確頁面。

OCR 後找不到文字或語言不對。

PDF Binder 使用 Windows 內建的文字辨識及已安裝的 OCR 語言。請在 Windows 設定 → 時間與語言 → 語言與地區中新增該語言（光學字元辨識）。已有文字的頁面會略過。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
