使用方式

輸入資料和公式

  1. 在儲存格中輸入，或以 = 開始輸入公式。函數助手會顯示引數和範例；按一下或拖曳儲存格插入參照。
  2. 支援 F2、F4、Ctrl+D、Ctrl+R、Alt+= 等 Excel 快速鍵。拖曳填滿控點可延續數字和日期。

排序、篩選和格式

  1. 使用「資料」功能表排序、篩選 (Ctrl+Shift+L) 和移除重複項，使用「格式」功能表設定數值格式和設定格式化的條件。

插入圖表

  1. 選取資料後選擇「插入」>「圖表」(Alt+F11)。可選 8 種圖表，進階圖表需 Pro。

列印或匯出 PDF

  1. 開啟「檔案」>「版面設定」設定方向、邊界和縮放為一頁，然後列印或匯出 PDF。

功能

  • 開啟並儲存 Excel xlsx，支援 xls、csv、tsv、ods
  • Excel 快速鍵，含函數助手的資料編輯列
  • 自由版面：表格、圖表、文字和圖形
  • 30 多種表格樣式、設定格式化的條件、資料驗證
  • 預覽列印和 PDF 匯出、自動儲存和復原
  • 樞紐分析表、大型 CSV/Parquet 資料模式、進階圖表（Pro）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

開啟和儲存：Excel (.xlsx) 和 CSV。匯出：PDF。現有 Excel 檔案中的圖表、圖片和樞紐分析表儲存時暫不保留，儲存前會提示。資料模式 (Pro) 可開啟數百萬列的 CSV 和 Parquet。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

儲存後 Excel 檔案中的圖表或樞紐分析表消失了。

現有 Excel 檔案中的這些物件儲存時暫不保留，儲存前會顯示警告。請使用「另存新檔」保留原始檔案，並從版本記錄還原舊版本。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
