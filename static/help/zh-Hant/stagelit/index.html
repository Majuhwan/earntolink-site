使用方式

建立簡報

  1. 選擇佈景主題和投影片大小，然後從版面配置中新增投影片。
  2. 透過「插入」功能表新增文字、圖案、圖片、表格、圖表和影片。智慧參考線協助對齊物件。

使用神奇移動製作動畫

  1. 複製投影片，然後在副本上移動物件或變更其大小和色彩。
  2. 在第二張投影片上選擇「神奇移動」轉場。它會儲存為轉化轉場，因此在其他簡報應用程式中也能播放。

簡報放映

  1. 選取「播放」。連接第二台顯示器時，觀眾看到放映，您看到包含備忘稿、下一張投影片和計時器的簡報者檢視。
  2. 放映時可使用雷射筆、畫筆或 B/W 鍵（黑畫面/白畫面）。

功能

  • 開啟並儲存 pptx，開啟 odp
  • 神奇移動（儲存為其他應用程式也能播放的變形轉場）
  • 41 種轉場與 63 種動畫，可預覽
  • 含備忘稿、計時與下一張投影片的簡報者檢視
  • 42 個佈景主題、187 種圖案、含公式的表格、圖表、影片
  • 匯出 PDF、圖片、MP4 與動畫 GIF

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

開啟和儲存：PowerPoint (.pptx) 和 OpenDocument (.odp)。匯出：PDF、圖片、MP4 影片（1080p；4K 和 HEVC 需 Pro）、動畫 GIF (Pro)。無法開啟 .ppt (97–2003) 和 .key 檔案。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

在其他應用程式中投影片顯示不同。

其他電腦上未安裝的字型會被取代。請使用常見字型，或匯出 PDF 或影片分享固定版本。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
