使用方式

從首頁開始

  1. 在「新增」下選擇文件、試算表或簡報。
  2. 或選擇範本：在圖庫上方切換文件、試算表和簡報。
  3. 「最近」列出你最近開啟的各類檔案。「開啟」可開啟任何支援的檔案。

使用索引標籤

  1. 每個檔案在頂端開啟一個索引標籤，圖示顏色表示類型。
  2. Ctrl+Tab 和 Ctrl+Shift+Tab 在索引標籤和首頁之間切換。選取索引標籤上的 × 關閉檔案。
  3. 索引標籤中的功能表、工具列和快速鍵屬於該檔案類型的編輯器（與 Folios、Spreadwell 和 Stagelit 相同）。

從檔案總管開啟

  1. 以滑鼠右鍵按一下檔案，選取「開啟檔案」並選擇 Docfern。若要設為預設，請前往「設定」>「應用程式」>「預設應用程式」。
  2. 也可以把檔案拖曳到首頁，會在對應的編輯器中開啟。

免費版和 Pro

  1. 免費版包含 Folios、Spreadwell 和 Stagelit 免費版的所有功能。
  2. Pro 在首頁「取得 Pro」中一次性購買，會開啟三個編輯器的所有 Pro 功能。
  3. 在單獨的 Folios、Spreadwell 或 Stagelit 應用程式中購買的 Pro 是不同的產品，不會解除鎖定此處的 Pro（反之亦然）。

功能

  • 文件、試算表和簡報在一個視窗的索引標籤中
  • 開啟和儲存 docx、xlsx 和 pptx；也能開啟 doc、odt、rtf、HWPX、xls、csv、ods、ppt 和 odp
  • 首頁提供新增檔案、範本、佈景主題和各類最近檔案
  • 追蹤修訂、註解、含公式的表格、目錄
  • 含函數說明的資料編輯列、設定格式化的條件和圖表
  • 神奇移動、簡報者檢視和在放映中播放的旁白
  • 所有檔案類型都能匯出 PDF
  • 免費使用；Pro 為一次性購買

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

文件 – 開啟：.docx .dotx .docm .doc .rtf .odt .hwpx .hwp .md .txt .html；儲存：.docx .dotx .rtf .md .html .txt；匯出 PDF。試算表 – 開啟：.xlsx .xlsm .xls .csv .tsv .ods；儲存：.xlsx .csv；PDF。簡報 – 開啟：.pptx .potx .ppsx .pptm .ppt .odp；儲存：.pptx；匯出 PDF、圖片、MP4。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
