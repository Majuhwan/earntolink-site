使用方式

格式化和驗證 JSON

  1. 在側邊欄中選取 JSON，將文字貼到輸入框。
  2. 選取「格式化」或「壓縮」。
  3. 如果 JSON 無效，會顯示錯誤所在的行和欄。
  4. 選取「複製」以複製結果。

Base64、URL 和 HTML 編碼與解碼

  1. 在側邊欄中選取 Base64、URL 編碼或 HTML。
  2. 選取「編碼」或「解碼」，然後將文字貼到輸入框。
  3. 用於 URL 或權杖的 Base64，請開啟「URL 安全」。

文字雜湊與總和檢查碼比對

  1. 選取「雜湊」並輸入文字。MD5、SHA-1、SHA-256 和 SHA-512 會立即顯示。
  2. 將預期值貼到「要比對的雜湊」。相符的列會標示「相符」。
  3. Pro：開啟 HMAC 並輸入金鑰，即可得到 HMAC-SHA256 和 HMAC-SHA512。

驗證下載的檔案 (Pro)

  1. 在「雜湊」中選取「檔案雜湊」，然後選擇一個或多個檔案。不限大小。
  2. 將下載網站公布的總和檢查碼貼到「要比對的雜湊」。

檢視 JWT 內容

  1. 選取 JWT 並貼上權杖。
  2. 將顯示標頭和承載。如果權杖包含 exp，也會顯示到期時間。
  3. 不驗證簽章。

轉換 Unix 時間戳記

  1. 選取「時間戳記」，輸入秒、毫秒或 ISO 8601 日期。選取「現在」會填入目前時間。
  2. 將顯示 Unix 秒、毫秒、UTC 和本地時間。

產生 UUID

  1. 選取 UUID，用 − 和 + 設定數量（1–100），然後選取「產生」。
  2. 選取「複製」可複製整個清單。

測試規則運算式

  1. 選取「規則運算式」，輸入模式，並將測試文字貼到輸入框。
  2. 相符項目和擷取群組會與相符數一起列出。
  3. Pro：開啟「取代」並輸入 $1 等取代內容即可預覽結果。另有多行和點比對換行選項。

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

顯示輸入無效。

檢查訊息旁的「行:欄」位置。常見原因是結尾逗號、單引號和註解，JSON 不允許這些內容。

Base64 解碼結果顯示為十六進位位元組而不是文字。

解碼後的資料不是 UTF-8 文字（例如影像或壓縮資料）。為避免遺失內容，以十六進位顯示位元組。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
