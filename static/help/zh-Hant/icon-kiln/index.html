使用方式

用影像製作圖示

  1. 將影像拖入視窗或開啟影像。1024 px 以上的正方形影像效果最好。
  2. 選擇輸出類型和尺寸，在淺色和深色背景上查看預覽，然後建立。
  3. 每次都會儲存到新資料夾，不會覆寫先前的結果。

調整非正方形影像

  1. 「完整顯示」以透明邊距顯示整張影像，「填滿」則裁切中間部分。

建立網站圖示組 (Pro)

  1. 選取「網站圖示」。包含 favicon.ico、16 和 32 px PNG、Apple 觸控圖示、Android 192 和 512 px、Web 資訊清單以及可貼上的 HTML。

功能

  • Windows .ico 與 ICNS 圖示（.icns）（.icns：Pro）
  • 網站圖示套組和 HTML（Pro）
  • 16–1024 px PNG
  • 完整顯示或裁切填滿
  • 離線，不上傳，無廣告
  • 免費：Windows .ico 和各尺寸 PNG · Pro：ICNS 圖示（.icns）和網站 favicon 套組

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

輸入：PNG、JPG、WebP、BMP 等常見影像。輸出：Windows 圖示（.ico，16–256 px）、PNG（16–1024 px）、ICNS (Pro)、網站圖示組 (Pro)。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

大尺寸圖示模糊。

來源影像小於輸出尺寸。來源影像過小時會顯示警告。請使用至少 1024 px 的影像。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
