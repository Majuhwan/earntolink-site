使用方式

依名稱尋找檔案

  1. 首次選擇要建立索引的磁碟機和資料夾。新增、重新命名和刪除的檔案會自動更新。
  2. 輸入即可立即顯示結果。可依類型、大小、日期篩選，並使用 ext:pdf、size:>100mb、dm:2025-06、"精確詞組"、!排除 等語法。

隨處搜尋

  1. 按全域快速鍵可開啟小型搜尋視窗。應用程式可在通知區域中待命。
  2. 用 ↑ ↓ 和 Enter 開啟，Ctrl+Enter 在資料夾中顯示，Ctrl+Shift+C 複製路徑。

搜尋檔案內容 (Pro)

  1. 為 PDF、Word、Excel、PowerPoint、文字和程式碼開啟內容索引。免費版顯示包含該詞的檔案數量。
  2. Pro 會顯示帶醒目提示摘錄的相符檔案，並提供圖片文字 (OCR)、依描述搜尋相片和人物。

功能

  • 邊輸入邊搜檔名：百萬檔案毫秒出結果，即時更新
  • 篩選、萬用字元、規則運算式、大小和日期；排序、預覽、拖出檔案
  • 全域快速鍵在任何應用程式上開啟小搜尋框
  • 搜尋 PDF、Word、Excel、PowerPoint、文字和程式碼的內容（Pro）
  • 依文字描述或人物尋找照片（Pro）
  • 離線使用，不需帳戶和系統管理員權限

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

檔案和輸入內容僅在此電腦上處理，不會上傳。部分功能首次使用時會下載一次模型或元件，之後可離線使用。沒有帳戶、廣告或追蹤。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

找不到確實存在的檔案。

請確認該磁碟機或資料夾已包含在索引設定中。網路磁碟機和 Windows 不允許讀取的資料夾會被略過。

處理速度慢。

大型檔案或大量檔案需要更長時間。請關閉其他佔用資源的應用程式，筆電請接上電源，並在工作完成前避免電腦進入睡眠。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
