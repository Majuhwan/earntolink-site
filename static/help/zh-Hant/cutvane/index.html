使用方式

在時間軸上編輯

  1. 將媒體庫中的片段拖到時間軸上。空隙會自動閉合，連結的片段一起移動。
  2. 用 J/K/L 播放，在播放頭處分割並漣漪刪除。效果、轉場和標題無需轉譯即可預覽。

製作預告片

  1. 選擇預告片範本，填寫每個鏡頭位和標題卡，音樂會自動配合。

匯出影片

  1. 選取「匯出」，選擇解析度和品質後儲存為 MP4。免費版無浮水印，最高 1080p。

功能

  • 即時 GPU 預覽：效果、轉場和標題立即播放
  • 20 個預告片範本和 12 個主題（免費 5 個和 4 個）
  • 磁性多軌時間軸，波紋、滾動、內滑、外滑和 J/K/L
  • 調色、曲線、風格和視訊示波器；色輪和 LUT (Pro)
  • 24 種轉場、動畫標題、色度鍵和子母畫面
  • OpenTimelineIO、EDL 和 FCPXML 交換
  • 無浮水印 1080p 匯出；4K 和 HEVC (Pro)

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

匯入：MP4、MOV、MKV 等 Windows 可播放的影片，MP3、WAV、M4A 音訊，JPG、PNG 影像，OpenTimelineIO 和 EDL。匯出：最高 1080p 的 MP4（4K、1440p、HEVC 需 Pro），OpenTimelineIO、EDL、FCPXML。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

手機影片看起來發白。

手機 HDR 影片（HLG 或 PQ）會自動色調對應。如仍顯平淡，請為片段套用色彩風格或調整曝光和對比。

預覽卡頓或畫面異常。

從電腦或顯示卡製造商處將顯示卡驅動程式更新至最新版本。筆電請連接電源變壓器，並將電源模式設為「最佳效能」。

處理速度慢。

大型檔案或大量檔案需要更長時間。請關閉其他佔用資源的應用程式，筆電請接上電源，並在工作完成前避免電腦進入睡眠。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
