使用方法

剪掉静音

  1. 打开录制文件。会自动找到静音。
  2. 选择预设（紧凑、普通、宽松）或设置阈值、最短静音和前后留白。节省的时间会立即更新。

检查和调整剪切

  1. 播放预览时会跳过剪掉的部分。J/K/L 播放，C 剪切或保留，I/O/X 剪切范围。
  2. Pro：还可查找 9 种语言的口头禅（嗯、呃）。语音识别在本机进行。

导出

  1. 选择“导出”，选择 MP4、仅音频或 SRT 字幕。免费版最多 15 分钟的文件。
  2. Pro：导出 Final Cut Pro、DaVinci Resolve (FCPXML)、Premiere Pro (XML) 或 EDL 剪辑列表，并批量处理多个录制。

功能

  • 立即找到静音，用本机语音识别找到口头禅（口头禅：Pro）
  • 波形时间线：保留、剪切、调整、手动添加，撤销重做
  • 跳过剪切处的预览，J/K/L 键盘编辑
  • 导出 MP4（逐帧精确或智能剪切）、音频和 SRT 字幕（免费：15 分钟以内的文件）
  • Final Cut、DaVinci Resolve、Premiere Pro 和 EDL 剪辑列表（Pro）
  • 批量处理，离线，无需账户，Pro 一次买断（批量处理：Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

文件和输入内容仅在此电脑上处理，不会上传。部分功能首次使用时会下载一次模型或组件，之后可离线使用。没有帐户、广告或跟踪。

支持哪些文件格式？

打开：MP4、MOV、MKV、MP3、WAV、M4A 等 Windows 可播放的视频和音频。导出：MP4、M4A、MP3、WAV、FLAC、SRT，FCPXML、Premiere XML、EDL 需 Pro。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

预览没有画面。

预览使用 Windows Media Foundation。HEVC 等部分编解码器需要 Microsoft Store 中的扩展。导出不受影响。

预览卡顿或画面异常。

从电脑或显卡制造商处将显卡驱动更新到最新版本。笔记本电脑请连接电源适配器，并将电源模式设为“最佳性能”。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
