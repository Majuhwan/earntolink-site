使用方法

调整照片

  1. 打开照片，使用白平衡、曝光、对比度、高光、阴影和颜色滑块。自动色调可设定起点。
  2. 按住前后对比按钮进行比较。每一步都会保留在历史记录中。

裁剪和修饰

  1. 使用裁剪、拉直和透视调整构图。使用修复画笔或仿制图章去除斑点。

导出

  1. 选择“导出”，选择格式、大小和质量后保存。原文件不会被修改。

功能

  • 无损冲印：白平衡、色调、曲线、混色器、细节、效果
  • 画笔、渐变、径向、明亮度与颜色蒙版的局部调整
  • 最大 30,000 像素的 16 位图层编辑器，27 种混合模式、编组、剪贴蒙版
  • 矢量钢笔、智能对象、图层样式、60 种效果
  • HDR 合并、全景、焦点堆栈、内容识别填充
  • 色彩管理的导出（P3、Adobe RGB、CMYK TIFF、16 位、OpenEXR、PDF）与打印

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

打开：JPG、PNG、TIFF、WebP，以及需免费 Windows 扩展的相机 RAW 和 HEIC。导出：JPG、PNG、TIFF、WebP。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

RAW 或 HEIC 照片无法打开。

从 Microsoft Store 安装免费的 Raw 图像扩展或 HEIF 图像扩展，然后重新打开照片。

预览卡顿或画面异常。

从电脑或显卡制造商处将显卡驱动更新到最新版本。笔记本电脑请连接电源适配器，并将电源模式设为“最佳性能”。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
