使用方法

隐藏照片中的人脸和个人信息

  1. 添加照片。会自动找到人脸、电话号码、电子邮件、卡号、账号和证件号码。
  2. 开启或关闭框、移动或绘制新框。选择模糊、马赛克或纯色块后保存。原文件不会被修改。

模糊视频中的人脸

  1. 打开视频。人脸会跨帧跟踪；在时间轴上开关轨道并设置起止时间。
  2. 绘制方框可跟踪其他物体。导出保留原音频的新 MP4；免费版限 1 分钟以内的视频。

涂黑 PDF

  1. 打开 PDF，检查找到的个人信息，并在页面上拖动以添加区域。
  2. 保存。框下的文字会从文件中删除并再次检查，隐藏的内容无法被复制出来。

功能

  • 自动模糊照片中的人脸，并在视频中跟踪遮挡
  • 查找图片中的电话、邮箱、卡号和银行账号
  • 真正的 PDF 涂黑：从文件中删除文字并验证结果
  • 视频时间线：裁剪和拆分轨迹、跟随运动的框、哔声
  • 删除 EXIF 和 GPS；文件夹批量处理和监视文件夹（批量和监视文件夹：Pro）
  • 带校验值的审计日志；离线，无需账户，不上传（导出 CSV：Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

照片：JPG、PNG、WebP、HEIC（需 Windows 扩展）。视频：MP4、MOV 等 Windows 可播放的格式，输出为 MP4。文档：PDF。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

未检测到某张人脸或号码。

较小、侧脸或模糊的人脸以及手写号码可能被漏检。请务必检查结果，并为遗漏处绘制方框。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
