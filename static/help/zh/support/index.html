如何申请退款？

付款由 Microsoft 处理。请在 Microsoft 帐户的订单历史记录中申请退款。 Microsoft 订单历史记录

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。
