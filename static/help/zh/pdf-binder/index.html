使用方法

合并 PDF

  1. 选择“合并”，添加 PDF 文件或将其拖入窗口。
  2. 拖动页面调整顺序，按需旋转或删除页面。
  3. 保存。免费版一次最多合并 3 个 PDF。

拆分 PDF

  1. 选择“拆分”并打开 PDF。
  2. 可按每页、每 N 页或 1-3, 5, 8-10 等范围拆分。会先预览将要生成的文件。
  3. 结果以“报告 (2).pdf”这样的新名称保存。免费版一次最多 10 个文件。

功能

  • 合并 PDF，拖动调整页面顺序（免费：每次最多 3 个）
  • 旋转和删除页面
  • 按页、每 N 页或页码范围拆分（免费：每次最多 10 个文件）
  • 支持带密码的 PDF
  • 离线，不上传，无广告
  • 免费：页面整理不限，最多合并 3 个 PDF，最多拆分为 10 个文件 · Pro：无限制

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

PDF（受密码保护的 PDF 需输入密码打开）。结果保存为新的 PDF 文件。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

PDF 要求输入密码。

输入打开 PDF 的密码。不知道密码的文件无法打开。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
