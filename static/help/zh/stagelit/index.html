使用方法

创建演示文稿

  1. 选择主题和幻灯片大小，然后从版式中添加幻灯片。
  2. 通过“插入”菜单添加文本、形状、图片、表格、图表和视频。智能参考线帮助对齐对象。

使用神奇移动制作动画

  1. 复制幻灯片，然后在副本上移动对象或更改其大小和颜色。
  2. 在第二张幻灯片上选择“神奇移动”切换。它会保存为平滑切换，因此在其他演示应用中也能播放。

放映演示

  1. 选择“播放”。连接第二台显示器时，观众看到放映，您看到包含备注、下一张幻灯片和计时器的演示者视图。
  2. 放映时可使用激光笔、画笔或 B/W 键（黑屏/白屏）。

功能

  • 打开和保存 pptx，打开 odp
  • 神奇移动（保存为其他应用也能播放的变体切换）
  • 41 种切换和 63 种动画，可预览
  • 带备注、计时和下一张幻灯片的演示者视图
  • 42 个主题、187 种形状、带公式的表格、图表、视频
  • 导出 PDF、图片、MP4 和动画 GIF

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

打开和保存：PowerPoint (.pptx) 和 OpenDocument (.odp)。导出：PDF、图片、MP4 视频（1080p；4K 和 HEVC 需 Pro）、动画 GIF (Pro)。无法打开 .ppt (97–2003) 和 .key 文件。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

在其他应用中幻灯片显示不同。

其他电脑上未安装的字体会被替换。请使用常见字体，或导出 PDF 或视频分享固定版本。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
