使用方法

开始创作歌曲

  1. 选择风格模板或演示歌曲，或从空白开始。
  2. 从浏览器将循环拖到轨道上，它们会始终跟随歌曲的速度和调性播放。

录制音频或 MIDI

  1. 将轨道设为录音准备，选择输入并按“录音”。先播放预备拍；循环录音会保留每次录制。

混音和导出

  1. 在混音器中设置音量、声像和发送，并为每个轨道添加效果。
  2. 选择“导出”，选择 WAV、MP3 或 MIDI。

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

导入：WAV、MP3、FLAC 等常见音频及 MIDI。导出：WAV、MP3、MIDI；FLAC、M4A、分轨和 DAWproject 需 Pro。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

录音有延迟或爆音。

在音频设置中选择音频接口并调整缓冲区大小：减小可降低延迟，有爆音则增大。关闭其他音频应用。

没有声音。

在 Windows 声音设置和音量合成器中检查输出设备和音量。如果其他应用独占使用音频设备，请关闭该应用。

麦克风无法使用。

在“设置”>“隐私和安全性”>“麦克风”中，打开“麦克风访问权限”和“允许桌面应用访问麦克风”。然后在应用中选择正确的输入设备。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
