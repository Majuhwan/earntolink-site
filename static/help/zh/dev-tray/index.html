使用方法

格式化和验证 JSON

  1. 在侧栏中选择 JSON，将文本粘贴到输入框。
  2. 选择“格式化”或“压缩”。
  3. 如果 JSON 无效，会显示错误所在的行和列。
  4. 选择“复制”以复制结果。

Base64、URL 和 HTML 编码与解码

  1. 在侧栏中选择 Base64、URL 编码或 HTML。
  2. 选择“编码”或“解码”，然后将文本粘贴到输入框。
  3. 用于 URL 或令牌的 Base64，请打开“URL 安全”。

文本哈希与校验和比较

  1. 选择“哈希”并输入文本。MD5、SHA-1、SHA-256 和 SHA-512 会立即显示。
  2. 将预期值粘贴到“要比较的哈希”。匹配的行会标记“匹配”。
  3. Pro：打开 HMAC 并输入密钥，即可得到 HMAC-SHA256 和 HMAC-SHA512。

验证下载的文件 (Pro)

  1. 在“哈希”中选择“文件哈希”，然后选择一个或多个文件。不限大小。
  2. 将下载站点公布的校验和粘贴到“要比较的哈希”。

查看 JWT 内容

  1. 选择 JWT 并粘贴令牌。
  2. 将显示标头和载荷。如果令牌包含 exp，还会显示过期时间。
  3. 不验证签名。

转换 Unix 时间戳

  1. 选择“时间戳”，输入秒、毫秒或 ISO 8601 日期。选择“现在”会填入当前时间。
  2. 将显示 Unix 秒、毫秒、UTC 和本地时间。

生成 UUID

  1. 选择 UUID，用 − 和 + 设置数量（1–100），然后选择“生成”。
  2. 选择“复制”可复制整个列表。

测试正则表达式

  1. 选择“正则表达式”，输入模式，并将测试文本粘贴到输入框。
  2. 匹配项和捕获组会与匹配数一起列出。
  3. Pro：打开“替换”并输入 $1 等替换内容即可预览结果。另有多行和点匹配换行选项。

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

显示输入无效。

检查消息旁边的“行:列”位置。常见原因是末尾逗号、单引号和注释，JSON 不允许这些内容。

Base64 解码结果显示为十六进制字节而不是文本。

解码后的数据不是 UTF-8 文本（例如图像或压缩数据）。为避免丢失内容，以十六进制显示字节。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
