使用方法

在时间轴上编辑

  1. 将媒体库中的片段拖到时间轴上。空隙会自动闭合，关联片段一起移动。
  2. 用 J/K/L 播放，在播放头处拆分并波纹删除。效果、转场和标题无需渲染即可预览。

制作预告片

  1. 选择预告片模板，填写每个镜头位和标题卡，音乐会自动匹配。

导出影片

  1. 选择“导出”，选择分辨率和质量后保存为 MP4。免费版无水印，最高 1080p。

功能

  • 实时 GPU 预览：效果、转场和标题即刻播放
  • 20 个预告片模板和 12 个主题（免费 5 个和 4 个）
  • 磁性多轨时间线，波纹、滚动、内滑、外滑和 J/K/L
  • 调色、曲线、风格和视频示波器；色轮和 LUT (Pro)
  • 24 种转场、动画标题、色度键和画中画

  • 无水印 1080p 导出；4K 和 HEVC (Pro)

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

导入：MP4、MOV、MKV 等 Windows 可播放的视频，MP3、WAV、M4A 音频，JPG、PNG 图像，OpenTimelineIO 和 EDL。导出：最高 1080p 的 MP4（4K、1440p、HEVC 需 Pro），OpenTimelineIO、EDL、FCPXML。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

手机视频看起来发白。

手机 HDR 视频（HLG 或 PQ）会自动色调映射。如仍显平淡，请为片段应用色彩风格或调整曝光和对比度。

预览卡顿或画面异常。

从电脑或显卡制造商处将显卡驱动更新到最新版本。笔记本电脑请连接电源适配器，并将电源模式设为“最佳性能”。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
