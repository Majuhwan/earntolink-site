使用方法

无损剪切

  1. 打开视频（或拖入窗口）。视频会立即打开，关键帧在索引时以橙色刻度显示在时间线上。
  2. 移到起点（方向键逐帧，Ctrl+方向键跳到关键帧），按 I，再移到终点按 O。每对 I/O 添加一个区段，可在时间线上拖动边缘。
  3. 在“导出”中选择保留或移除、一个文件或每个区段一个文件以及格式，然后导出。视频和音频直接复制，不重新编码。未使用智能剪切时，每个区段从起点前的关键帧开始（以斜线显示）。

逐帧智能剪切（Pro）

  1. 在“导出”中打开智能剪切。只有剪切点与最近关键帧之间的帧会用同一编解码器的 Windows 编码器重新编码，其余部分原样复制。
  2. 智能剪切支持 H.264 和 HEVC 视频（8 位 4:2:0）。HEVC 需要 Windows 中有 HEVC 编码器（HEVC 视频扩展或显卡编码器）。不可用时按关键帧剪切保存并显示提示。

轨道、音频和帧

  1. 在“轨道”中取消勾选不需要的音轨或字幕轨。“导出音频”将勾选的每条音轨不重新编码地另存为文件。
  2. “保存帧”将播放头处的精确帧保存为 PNG。“合并”将编解码器、画面尺寸和音轨相同的整个文件连接起来。

场景、章节、列表和批量处理（Pro）

  1. “按场景拆分”在每个场景切换处创建区段。“章节”为合并文件的每个区段添加章节。“导入列表/导出列表”读写 CSV（开始、结束、名称）和章节文本（00:00 名称）。
  2. 批量处理会无损地从多个文件的开头和结尾裁掉相同秒数。

保存工作

  1. “保存项目”将区段、轨道和选项写入视频旁的 .clipkeel.json 文件；“打开项目”可稍后继续。原文件不会更改，结果保存为新文件。

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

结果比起点稍早开始。

无损剪切只能从关键帧开始，因此会从起点前的关键帧开始（时间线上的斜线部分）。可将起点移到关键帧（Ctrl+方向键），或使用智能剪切（Pro）精确到帧。

预览中视频无法播放。

播放使用 Windows 中安装的视频编解码器。暂停画面始终显示，Windows 无法播放的文件也能剪切。播放 HEVC 或 AV1 需从 Microsoft Store 安装相应扩展。

合并提示无法连接文件。

不重新编码的合并要求所有文件的视频编解码器、画面尺寸和音轨相同（如同一相机、相同设置）。不同的文件需先在视频编辑器中转换。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

“联系支持”无法打开邮件应用。

如果没有设置默认邮件应用，请选择“复制信息”，并通过任意邮件服务发送至 hello@earntolink.com。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。

联系支持

请发送邮件至 hello@earntolink.com，并注明应用名称和版本。在应用中使用“帮助”>“联系支持”会自动填入这些信息。
