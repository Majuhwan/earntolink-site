Guías

Formatear y validar JSON

  1. Seleccione JSON en la barra lateral y pegue el texto en Entrada.
  2. Seleccione Formatear o Minificar.
  3. Si el JSON no es válido, se muestran la línea y la columna del error.
  4. Seleccione Copiar para copiar el resultado.

Codificar y decodificar Base64, URL y HTML

  1. Seleccione Base64, Codificar URL o HTML en la barra lateral.
  2. Seleccione Codificar o Decodificar y pegue el texto en Entrada.
  3. Para Base64 en URL o tokens, active Seguro para URL.

Calcular hash de texto y comparar sumas

  1. Seleccione Hash y escriba texto. MD5, SHA-1, SHA-256 y SHA-512 aparecen al instante.
  2. Pegue el valor esperado en Comparar con hash. La fila que coincide se marca.
  3. Pro: active HMAC e introduzca una clave para obtener HMAC-SHA256 y HMAC-SHA512.

Verificar archivos descargados (Pro)

  1. En Hash, seleccione Hash de archivos y elija uno o varios archivos. No hay límite de tamaño.
  2. Pegue la suma de verificación publicada por el sitio de descarga en Comparar con hash.

Leer un JWT

  1. Seleccione JWT y pegue el token.
  2. Se muestran el encabezado y la carga. Si el token tiene exp, se muestra la caducidad.
  3. La firma no se verifica.

Convertir marcas de tiempo Unix

  1. Seleccione Marca de tiempo e introduzca segundos, milisegundos o una fecha ISO 8601. Ahora inserta la hora actual.
  2. Se muestran segundos y milisegundos Unix, UTC y hora local.

Generar UUID

  1. Seleccione UUID, ajuste la cantidad (1–100) con − y + y seleccione Generar.
  2. Copiar copia toda la lista.

Probar expresiones regulares

  1. Seleccione Regex, escriba un patrón y pegue el texto de prueba en Entrada.
  2. Las coincidencias y los grupos se muestran con el recuento.
  3. Pro: active Reemplazar e introduzca, por ejemplo, $1 para ver el resultado. También hay opciones multilínea y dot-all.

Funciones

  • Codificar/decodificar Base64, URL y HTML

Preguntas frecuentes

¿Qué es Pro?

Pro es un complemento de compra única en Microsoft Store, no una suscripción. Funciona en los PC con Windows que usen la misma cuenta Microsoft.

¿Cómo recupero Pro en otro PC o tras reinstalar?

Inicie sesión en Microsoft Store con la cuenta de la compra y seleccione Ayuda > Restaurar compra.

¿Cómo obtengo un reembolso?

Microsoft gestiona los pagos y reembolsos. Vaya a account.microsoft.com > Historial de pedidos, seleccione el pedido y solicite un reembolso. Se aplica la directiva de reembolso de Microsoft.

¿La aplicación necesita internet? ¿Se envían mis datos?

No. Los archivos y datos se procesan solo en este PC y nunca se envían. No hay cuentas, anuncios ni seguimiento. Internet solo se usa para compras y actualizaciones de Microsoft Store.

¿Cómo actualizo la aplicación?

Microsoft Store instala las actualizaciones automáticamente. Para comprobarlo ahora, abra Microsoft Store > Biblioteca y seleccione Obtener actualizaciones.

Solución de problemas

Aparece «Entrada no válida».

Compruebe la posición línea:columna junto al mensaje. Las causas habituales son comas finales, comillas simples y comentarios, que JSON no admite.

La decodificación Base64 muestra bytes hexadecimales en lugar de texto.

Los datos decodificados no son texto UTF-8, como una imagen o datos comprimidos. Los bytes se muestran en hexadecimal sin pérdida.

Compré Pro, pero las funciones siguen bloqueadas.

Seleccione Ayuda > Restaurar compra. Compruebe que Microsoft Store tiene iniciada la sesión con la cuenta de la compra. Justo después de comprar, la confirmación puede tardar unos minutos.

¿Cómo cambio el idioma de la aplicación?

La aplicación usa el idioma de Windows. Cámbielo en Configuración > Hora e idioma > Idioma y región y reinicie la aplicación.

La aplicación no se inicia o deja de responder.

Cierre y vuelva a abrir la aplicación. Si continúa, vaya a Configuración > Aplicaciones > Aplicaciones instaladas > Opciones avanzadas de la aplicación y seleccione Reparar. Restablecer también borra la configuración.
