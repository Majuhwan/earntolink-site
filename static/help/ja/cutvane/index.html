使い方

タイムラインで編集する

  1. メディア ライブラリからクリップをタイムラインにドラッグします。隙間は自動で詰まり、リンクされたクリップは一緒に動きます。
  2. J/K/L で再生し、再生ヘッドで分割、リップル削除を行います。エフェクト・トランジション・タイトルはレンダリングなしでプレビューできます。

予告編を作る

  1. 予告編テンプレートを選び、各ショット枠とタイトル カードを埋めると、音楽が合わせられます。

動画を書き出す

  1. [書き出し] を選択し、解像度と品質を選んで MP4 で保存します。無料版は透かしなしで 1080p まで書き出せます。

機能

  • リアルタイム GPU プレビュー: エフェクト、トランジション、タイトルをすぐに再生
  • 予告編テンプレート 20 種とテーマ 12 種 (無料 5 種と 4 種)
  • マグネティック マルチトラック タイムライン、リップル、ローリング、スリップ、スライド、J/K/L
  • 色補正、カーブ、ルック、ビデオ スコープ。カラー ホイールと LUT (Pro)
  • トランジション 24 種、アニメーション タイトル、クロマキー、ピクチャー イン ピクチャー
  • OpenTimelineIO、EDL、FCPXML の交換
  • 透かしなしの 1080p 書き出し。4K と HEVC (Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

読み込み: MP4、MOV、MKV など Windows で再生できる動画、MP3・WAV・M4A 音声、JPG・PNG 画像、OpenTimelineIO・EDL。書き出し: 1080p までの MP4 (4K・1440p・HEVC は Pro)、OpenTimelineIO・EDL・FCPXML。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

スマートフォンの動画が白っぽく見えます。

スマートフォンの HDR 動画 (HLG・PQ) は自動でトーン マッピングされます。それでも平坦に見える場合は、クリップにカラー ルックを適用するか露出・コントラストを調整してください。

プレビューがカクつく、または表示が乱れます。

PC または GPU メーカーからグラフィックス ドライバーを最新に更新します。ノート PC では電源アダプターを接続し、電源モードを [最適なパフォーマンス] にします。

処理が遅いです。

大きなファイルや多数のファイルは時間がかかります。ほかの重いアプリを閉じ、ノート PC は電源につなぎ、作業が終わるまでスリープしないようにしてください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
