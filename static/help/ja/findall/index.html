使い方

名前でファイルを探す

  1. 最初にインデックスするドライブとフォルダーを選びます。新規・名前変更・削除は自動で反映されます。
  2. 入力するとすぐに結果が表示されます。種類・サイズ・日付で絞り込み、ext:pdf、size:>100mb、dm:2025-06、"完全一致"、!除外 などの構文を使えます。

どこからでも検索する

  1. グローバル ショートカットを押すと小さな検索ウィンドウが開きます。アプリは通知領域で待機できます。
  2. ↑ ↓ と Enter で開き、Ctrl+Enter でフォルダーに表示、Ctrl+Shift+C でパスをコピーします。

ファイルの内容を検索する (Pro)

  1. PDF、Word、Excel、PowerPoint、テキスト、コードの内容インデックスをオンにします。無料版では語を含むファイル数が表示されます。
  2. Pro では、強調表示された抜粋付きでファイルを表示し、画像内の文字 (OCR)、説明による写真検索、人物検索も使えます。

機能

  • 入力するそばからファイル名を検索：100 万件も数ミリ秒、リアルタイム反映
  • フィルター、ワイルドカード、正規表現、サイズと日付、並べ替え、プレビュー
  • どのアプリからでもショートカットで小さな検索ボックス
  • PDF・Word・Excel・PowerPoint・テキスト・コードの中身を検索（Pro）
  • 言葉の説明や人物で写真を探す（Pro）
  • オフライン、アカウントも管理者権限も不要

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。一部の機能は初回使用時にモデルやコンポーネントを 1 回ダウンロードし、その後はオフラインで動作します。アカウント、広告、トラッキングはありません。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

存在するファイルが見つかりません。

そのドライブやフォルダーがインデックス設定に含まれているか確認してください。ネットワーク ドライブや Windows が読み取りを許可しないフォルダーは除外されます。

処理が遅いです。

大きなファイルや多数のファイルは時間がかかります。ほかの重いアプリを閉じ、ノート PC は電源につなぎ、作業が終わるまでスリープしないようにしてください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
