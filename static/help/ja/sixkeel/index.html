使い方

アカウントを追加する

  1. Web サイトで認証アプリを使う 2 段階認証をオンにします。QR コードとキーが表示されます。
  2. Sixkeel で [追加] を選択します。保存した QR 画像は [画像ファイル] または [クリップボード]、画面の QR コードは [画面の範囲] (Pro)、otpauth:// リンクは [セットアップ リンク]、キーを入力する場合は [キーを入力] を選びます。
  3. Sixkeel に表示された 6 桁のコードを Web サイトに入力して完了します。

コードをコピーする

  1. コードまたはコピー ボタンを選択します。円は残り秒数を示し、下に次のコードが表示されます。
  2. コピーしたコードはクリップボードの履歴やクラウド クリップボードに残らず、30 秒後に消去されます ([設定] > [クリップボードを消去])。

パスワードや Windows Hello でロックする

  1. アカウントは常にこの PC の Windows ユーザー単位で暗号化されます。[設定] > [パスワードを設定] でパスワードを追加すると、コードを開くときに必要になります。
  2. パスワードを設定したら、Windows Hello (Pro) をオンにすると顔・指紋・PIN でロック解除できます。自動ロックは指定時間後と Windows のロック時に働きます。

バックアップと復元

  1. [バックアップ] > [バックアップをエクスポート] は、バックアップのパスワードで暗号化した .sixkeel ファイルを 1 つ保存します (scrypt + AES-256-GCM)。USB ドライブや別の PC に保管してください。
  2. [復元] は .sixkeel ファイルを読み取り、一覧にないアカウントを追加します。フォルダーへの世代付き自動バックアップは Pro の機能です。

他の認証アプリから移行する

  1. 他のアプリでアカウントをファイル (Aegis・2FAS・andOTP) またはエクスポート用 QR コードとしてエクスポートします。
  2. [インポート] > [ファイルを選択] (Pro) でファイルを読み取ります。暗号化されたファイルはパスワードを尋ねます。エクスポート用 QR コードは [追加] > [画像ファイル] または [画面の範囲] を使います。

機能

  • アカウント数無制限、時間ベースとカウンター ベース
  • QR 画像・クリップボード・セットアップ リンク・キーで追加
  • この PC に暗号化して保存、任意のパスワード、自動ロック
  • コピーしたコードは履歴に残らず消去
  • 暗号化バックアップと復元、インターネット接続なし
  • Windows Hello、画面範囲の QR、インポート、フォルダー、自動バックアップ (Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

Web サイトでコードが拒否されます。

時間ベースのコードには正しい PC の時刻が必要です。Windows の [設定] > [時刻と言語] > [日付と時刻] で [時刻を自動的に設定する] をオンにし、[今すぐ同期] を選択します。コードがすぐ切り替わる場合は次のコードを待ってください。

QR コードが見つかりません。

コード全体が写った鮮明な画像を使うか、[画面の範囲] でコードだけを選択します。それでも失敗する場合は、QR コードの横に表示されるキーを [キーを入力] で入力します。

パスワードを忘れました。

パスワードはどこにも保存されないため、回復やリセットはできません。Windows Hello がオンなら Windows Hello でロックを解除して新しいパスワードを設定します。そうでない場合はバックアップを復元します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

[お問い合わせ] でメール アプリが開きません。

既定のメール アプリがない場合は、[情報をコピー] を選択し、お使いのメール サービスから hello@earntolink.com に送信してください。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
