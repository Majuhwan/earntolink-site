使い方

PDF と画像を表示する

  1. Paperwise PDF を既定のアプリにしてからファイルをダブルクリックします。アプリ起動中に開いたファイルは新しいタブで開きます。
  2. 表示メニューで単一ページ、見開き、閲覧モード、プレゼンテーションを選びます。検索はすべての一致を前後の文脈とともに表示します。

注釈・署名・フォーム入力

  1. 注釈ツール バーでハイライト、メモ、図形、手書き、テキスト ボックスを使います。
  2. [署名] を選択して手書き、入力、画像の読み込みで署名します。フォームはこの PC に保存したプロフィールで入力できます。

ページ整理・結合・変換

  1. ページのサムネイルを開き、並べ替え、回転、削除、空白ページや他の PDF の挿入を行います。
  2. OCR、墨消し、比較、圧縮、パスワード、PDF → Word などは [ツール] メニューにあります。保存時は確認済みのコピーを先に書き込み、以前の版のバックアップを残します。

機能

  • PDF と写真を約 0.5 秒で表示、矢印キーでフォルダー内の画像を移動
  • 注釈・署名・自動入力付きフォーム、PDF 内のテキストを直接編集
  • ページの結合・分割・整理、OCR・墨消し・比較・圧縮・変換
  • 画像のトリミング・サイズ変更・回転・色補正・マークアップ、JPG・PNG・WebP・TIFF・PDF などへ変換
  • スライドショー・GIF のフレーム表示・カメラ情報と GPS の情報パネル・スキャナー取り込み
  • 安全な保存:新しいファイルを確認してから元を置き換え、バックアップと復元

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

PDF、画像: JPG、PNG、GIF、BMP、ICO、TIFF、WebP、SVG、PSD (HEIC・AVIF・JPEG XL・RAW は無料の Windows 拡張機能が必要)。XPS・OXPS は PDF のコピーとして開きます。Office・HTML・画像を PDF に変換できます。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

HEIC・AVIF・RAW の写真が開きません。

Microsoft Store から無料の HEIF 画像拡張機能、AV1 Video Extension、Raw 画像拡張機能をインストールしてから開き直してください。

ファイルが開きません。

ファイルが別のアプリで開かれている、破損している、または対応していない形式の可能性があります。ファイルを使用しているアプリを閉じて再試行してください。対応形式は上の質問をご覧ください。

保存またはエクスポートできません。

フォルダーが読み取り専用か、ディスクの空き容量が不足している可能性があります。ドキュメントなど別のフォルダーを選択してください。Windows セキュリティの [コントロールされたフォルダー アクセス] がオンの場合は、このアプリを許可します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
