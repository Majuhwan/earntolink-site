使い方

クイック メモを取る

  1. どこからでも Ctrl+Alt+N で小さなクイック メモ ウィンドウが開きます。アプリが通知領域にあるだけでも動作します。

書く・書式設定

  1. #、-、[ ]、** などの Markdown 記法やツール バーで見出し、リスト、チェックリスト、表、コードを入れます。
  2. [[ と入力して別のメモにリンクします。タイトルが変わるとリンクも更新されます。

別の PC で使う

  1. Jottings には独自の同期サービスはありません。[設定] でメモ フォルダーを OneDrive などのクラウド ドライブ フォルダー内に置いてください。

機能

  • グローバル ショートカットのクイックメモ、通知領域アイコン、デスクトップの付箋
  • 自分のフォルダーの Markdown ファイル、アトミック保存、ごみ箱・バージョン履歴
  • チェックリスト、表、コード ブロック、メモ リンク、計算行
  • 筆圧対応の手書き、書類スキャン、画像・PDF・録音の添付
  • スマートフォルダー、入れ子のタグ、全言語の高速検索
  • Markdown フォルダー・ENEX・TextBundle・Takeout・Simplenote JSON のインポート

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

メモは Markdown (.md) ファイルで、添付ファイルは隣の _attachments フォルダーにあります。読み込み: Markdown、テキスト、ENEX など、ノートブック ファイル (.one、.onepkg) は Pro。書き出し: md、txt、html、rtf、pdf、ENEX、TextBundle、Word・EPUB (Pro)。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

メモの競合コピーができました。

編集中に別の PC などでディスク上のメモが変更された場合です。両方の版が残るので、比較して不要な方を削除してください。

ファイルが開きません。

ファイルが別のアプリで開かれている、破損している、または対応していない形式の可能性があります。ファイルを使用しているアプリを閉じて再試行してください。対応形式は上の質問をご覧ください。

保存またはエクスポートできません。

フォルダーが読み取り専用か、ディスクの空き容量が不足している可能性があります。ドキュメントなど別のフォルダーを選択してください。Windows セキュリティの [コントロールされたフォルダー アクセス] がオンの場合は、このアプリを許可します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
