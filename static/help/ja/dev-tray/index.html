使い方

JSON を整形・検証する

  1. サイドバーで JSON を選択し、入力欄に貼り付けます。
  2. [整形] または [圧縮] を選択します。
  3. JSON にエラーがあると、エラーの行と列が表示されます。
  4. [コピー] を選択して結果をコピーします。

Base64・URL・HTML のエンコードとデコード

  1. サイドバーで Base64、URL エンコード、HTML のいずれかを選択します。
  2. [エンコード] または [デコード] を選択し、入力欄に貼り付けます。
  3. URL やトークンで使う Base64 は [URLセーフ] をオンにします。

テキストのハッシュとチェックサムの比較

  1. [ハッシュ] を選択してテキストを入力します。MD5、SHA-1、SHA-256、SHA-512 がすぐに表示されます。
  2. [比較するハッシュ] に期待値を貼り付けます。一致する行に [一致] が表示されます。
  3. Pro: [HMAC] をオンにしてキーを入力すると、HMAC-SHA256 と HMAC-SHA512 が表示されます。

ダウンロードしたファイルの確認 (Pro)

  1. [ハッシュ] で [ファイルのハッシュ] を選択し、ファイルを 1 つ以上選びます。サイズの制限はありません。
  2. 配布サイトで公開されているチェックサムを [比較するハッシュ] に貼り付けます。

JWT の内容を見る

  1. [JWT] を選択してトークンを貼り付けます。
  2. ヘッダーとペイロードが表示されます。exp があれば有効期限も表示されます。
  3. 署名は検証しません。

Unix タイムスタンプの変換

  1. [タイムスタンプ] を選択し、秒・ミリ秒または ISO 8601 の日付を入力します。[現在] で現在時刻が入ります。
  2. Unix 秒・ミリ秒、UTC、ローカル時刻が表示されます。

UUID を生成する

  1. [UUID] を選択し、− と + で個数 (1～100) を決めて [生成] を選択します。
  2. [コピー] で一覧全体をコピーします。

正規表現をテストする

  1. [正規表現] を選択してパターンを入力し、入力欄にテキストを貼り付けます。
  2. 一致した文字列とグループが件数とともに表示されます。
  3. Pro: [置換] をオンにして $1 などの置換文字列を入力すると、結果をプレビューできます。複数行・改行一致オプションもあります。

機能

  • JSON の整形・圧縮・検証、エラー位置を表示
  • Base64・URL・HTML のエンコード/デコード
  • MD5・SHA-1・SHA-256・SHA-512 とチェックサム比較
  • JWT デコード、UUID、Unix 時刻の変換

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

入力が無効と表示されます。

メッセージ横の 行:列 の位置を確認してください。末尾のカンマ、単一引用符、コメントは JSON では使用できず、よくある原因です。

Base64 のデコード結果が文字ではなく 16 進数で表示されます。

デコードしたデータが画像や圧縮データなど UTF-8 テキストではない場合です。内容を失わないよう 16 進数で表示します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
