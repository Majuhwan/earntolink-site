使い方

PDF を結合・整理する

  1. [結合と整理] を選び、PDF やフォルダー(… メニュー)を追加するか、ウィンドウにドラッグします。PDF ごとにページサムネイルの区画ができます。
  2. ページをドラッグして並べ替えたり、別の文書へ移動します。Ctrl を押しながらドロップするとコピーします。Shift/Ctrl+クリックで複数選択してまとめてドラッグ。「選択から新しい文書」にドロップすると新しい文書になります。
  3. ページを回転(回転ボタン)・削除(Delete)。Ctrl+Z で元に戻し、Ctrl+Y でやり直し — 100 ステップまで。
  4. 保存方法を選びます:1 つの PDF、または文書ごと(区画ごとに 1 ファイル)。そして保存。無料:一度に元の PDF 3 個まで、Pro:無制限。ページ内のリンク・注釈・フォームフィールドは保持されます。

PDF を分割する

  1. [分割] を選び PDF を開きます(またはエクスプローラーで右クリック → Split with PDF Binder)。
  2. 無料プリセット:1 ページずつ、N ページごと、1-3, 5, 8- のような範囲(1 回 10 ファイルまで)。Pro プリセット:しおり(1〜3 階層)、ファイルサイズ(例:10 MB)、白紙の区切りページ(白紙は除外)。
  3. 一覧に作成されるファイルが表示されます。ファイル名は既定で {name}_{range}(例:Report_1-3.pdf)。Pro では {name} {n} {range} {from} {to} {pages} {bookmark} {date} で独自のルールを作れます。既存ファイルは上書きしません(Report (2).pdf)。

しおりと出力オプション(Pro)

  1. しおり:「保持」は元のしおりを新しいページ位置へ移し、「ファイルごと」は結合したファイルごとにしおりを作り、その下に元のしおりを置きます。分割時は「しおり · 保持」をオンにすると各部分にしおりが付きます。
  2. 出力オプション:圧縮(軽め・おすすめ・強め — 小さくなる場合のみ)、{n} と {total} を使ったページ番号やヘッダー/フッター文字、透かし文字、Windows OCR による検索可能な文字(Windows にインストールされた OCR 言語を使用)、開くパスワード(AES-256)。
  3. すべてのオプションは無料で選択でき、Pro の印が付きます。Pro は保存時にのみ確認され、購入後そのまま保存を続けます。

エクスプローラー・監視フォルダー・コマンドライン

  1. エクスプローラー(無料):PDF を選び右クリック → Merge with PDF Binder または Split with PDF Binder。Windows 11 では「その他のオプションを確認」の中にあります。「プログラムから開く → PDF Binder」も使えます。開いたファイルは既に開いているウィンドウに送られます。
  2. 監視フォルダー(Pro):[自動化] で監視するフォルダーと別の結果フォルダーを選び、処理(現在の分割設定で分割、出力オプションを適用、同時に届いたファイルを結合)を選んで開始します。PDF Binder を開いている間動作し、元のファイルは変更しません。
  3. コマンドライン(Pro):pdfbinder merge <ファイル・フォルダー> -o out.pdf [--bookmarks perfile]、pdfbinder split in.pdf --bookmarks 1 | --size 10 | --blank | --every 2 | --ranges "1-3,5" [-o フォルダー] [--name "{n} {bookmark}"]、さらに --compress、--numbers、--watermark、--ocr、--password。すべてのオプションは pdfbinder help。終了コード:0 成功、1 使い方、2 失敗、3 Pro が必要。

  • Pro:しおりを保持、結合したファイルごとにしおり

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

PDF(パスワード付き PDF はパスワードを入力して開きます)。Pro では画像(JPG、PNG、TIFF、HEIC…)もページとして追加できます。結果は常に新しいファイルとして保存され、元のファイルは変更されません。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

PDF でパスワードを求められます。

PDF を開くためのパスワードを入力します。パスワードがわからないファイルは開けません。保存結果にはパスワードは付きません(出力オプションで設定する場合は Pro)。

結合した PDF 内のリンクが移動しません。

Web リンクとページを指すリンクは保持され、ページの新しい位置に追従します。削除したページへのリンクは移動先がありません。他のファイルの「名前付き移動先」を使うリンクは動作しない場合があります。しおり(Pro)は作り直され、常に正しいページを指します。

検索可能(OCR)にしても文字が認識されない、または言語が違います。

PDF Binder は Windows 標準の文字認識と、インストール済みの OCR 言語を使います。Windows の設定 → 時刻と言語 → 言語と地域で言語(光学式文字認識)を追加してください。既に文字があるページはスキップします。

ファイルが開きません。

ファイルが別のアプリで開かれている、破損している、または対応していない形式の可能性があります。ファイルを使用しているアプリを閉じて再試行してください。対応形式は上の質問をご覧ください。

保存またはエクスポートできません。

フォルダーが読み取り専用か、ディスクの空き容量が不足している可能性があります。ドキュメントなど別のフォルダーを選択してください。Windows セキュリティの [コントロールされたフォルダー アクセス] がオンの場合は、このアプリを許可します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
