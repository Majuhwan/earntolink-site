使い方

Web サイトのレシピを保存する

  1. ブラウザーでレシピ ページのアドレスをコピーします。
  2. [インポート] の [Web アドレス] に貼り付けて [ページをダウンロード] を選択します。そのページとレシピの写真だけがダウンロードされます。
  3. タイトル・材料・作り方を確認して [保存] を選択します。出典アドレスはレシピと一緒に保存されます。

人数と単位を変える

  1. レシピを開き、[人数] の横の + と − を使います。分量が再計算され、読みやすい場合は分数 (1 1/2 カップ) で表示されます。
  2. [単位] で元の単位・メートル法 (ml、g)・米国式 (カップ、oz) を切り替えます。大さじ・小さじはそのままです。

調理モード

  1. 調理モードでは大きな文字で 1 手順ずつ表示し、横に材料を表示します。開いている間は画面がオフになりません。
  2. ← と → (または [前へ] と [次へ]) で移動します。手順に時間がある場合は [タイマー] ボタンでカウントダウンを開始できます。

買い物リストと献立

  1. [買い物リストに追加] で、表示中の人数分の材料がリストに入ります。同じ材料は合算され、売り場ごとにまとめられます。
  2. Pro では [献立] で 1 週間を計画し、[今週の材料を買い物リストへ] でまとめて追加できます。

印刷・PDF・他のアプリのファイル

  1. レシピの [...] メニューに [印刷] と [PDF にエクスポート] があります。買い物リストは印刷またはテキストとしてコピーできます。
  2. [インポート] > [ファイルから] で JSON (schema.org) ファイルを読み込みます。Paprika・MealMaster ファイル、複数アドレスの一括、Paprika・MealMaster へのエクスポート、レシピ集 PDF は Pro の機能です。

機能

  • Web ページのレシピを広告なしで保存 (schema.org レシピ データ)
  • 人数の変更と単位の換算 (メートル法、米国式)
  • 大きな文字の手順・タイマー・画面オンの調理モード
  • 材料を合算し売り場ごとにまとめる買い物リスト
  • 手持ちの材料で検索、タグ、評価、印刷・PDF
  • 週間献立表、レシピ集 PDF、一括インポート (Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

アプリはインターネットを使いますか?

[ページをダウンロード] を選択したときだけ、そのページとレシピの写真をダウンロードします。レシピ・写真・献立・買い物リストはこの PC にだけ保存され、アップロードされません。アカウント・広告・追跡はなく、購入と更新は Microsoft Store が処理します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

Web サイトをインポートできません。

一部のサイトはアプリからのダウンロードをブロックしたり、ページにレシピ データを含めていません。ブラウザーでレシピの文章を選択してコピーし、[テキストまたは HTML を貼り付け] に貼り付けると材料と作り方に分けます。

カップの量が違って見えます。

カップは国によって異なります。日本と韓国のレシピは 200 ml、ドイツ・フランス・イタリアは通常 250 ml、米国は 236.6 ml です。Ladlewise はレシピで使われた語に応じて換算します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

[お問い合わせ] でメール アプリが開きません。

既定のメール アプリがない場合は、[情報をコピー] を選択し、お使いのメール サービスから hello@earntolink.com に送信してください。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
