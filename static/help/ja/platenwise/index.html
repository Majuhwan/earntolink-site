使い方

スキャナーでスキャン

  1. スキャナーを開き、デバイスを選びます。WIA ドライバーのあるスキャナーが表示されます。ネットワーク スキャナーは、設定 > Bluetooth とデバイス > プリンターとスキャナーで追加すると表示されます。
  2. フラットベッドまたはフィーダー (両面フィーダーは両面)、解像度、カラー モードを選び、スキャンを選びます。スキャンを繰り返すとページが追加されます。600 dpi 以上は Pro です。
  3. スキャン後に印刷をオンにすると、スキャナーとプリンターをコピー機として使えます。

スマートフォンの写真とカメラ

  1. 写真をウィンドウにドラッグするか、インポートを選びます。カメラは Web カメラで撮影します。
  2. ページの端を自動で検出してまっすぐにします。トリミングで角をドラッグして調整します。自動は端を再検出し、画像全体は写真全体を使います。
  3. カラー・グレースケール・白黒・オリジナルから選びます。カラーは影を除去し、紙を白くします。

PDF を保存

  1. ページを整理し (上下移動・回転・削除)、形式・用紙サイズ・ファイル サイズを選んで保存を選びます。すべてのページが 1 つの PDF になります。
  2. Pro: 検索可能な PDF は見えないテキスト層 (Windows OCR) を追加し、検索とコピーができます。パスワードで PDF を保護し、白紙ページの削除・白紙ページで分割でフィーダーの一括スキャンを整理します。

ページからテキストをコピー

  1. ページを選び、テキストをコピーを選びます。Windows にインストールされた OCR 言語でこの PC 上で認識します。言語は設定で選ぶか、自動のままにします。

フォルダーのインポート (Pro)

  1. フォルダーのインポートでフォルダーを選び、ドキュメントに追加を選びます。画像が名前順に追加され、ページの端が自動で検出されます。

機能

  • WIA スキャナー: フラットベッド・フィーダー・両面
  • スマートフォンの写真: ページの端を自動検出して補正
  • 影のないカラー・グレースケール・白黒
  • 複数ページ PDF・JPG・PNG・TIFF と印刷 (無料)
  • Windows OCR の検索可能な PDF・白紙ページ削除 (Pro)
  • オフライン、アカウント不要、買い切りの Pro

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

スキャナーが一覧にありません。

Platenwise は Windows 標準のスキャナー方式 (WIA) を使います。メーカーのドライバーをインストールし、Windows スキャンまたは Windows FAX とスキャンで認識されることを確認してから最新の情報に更新を選んでください。ネットワーク スキャナーは先に設定 > Bluetooth とデバイス > プリンターとスキャナーで追加します。

ページの端がずれています。

ページが暗い面の上にあり、4 つの角がすべて見えるときに最もよく検出できます。トリミングで各角をページの角にドラッグするか、画像全体を選んでください。

テキストが認識されない、または別の言語として認識されます。

認識には Windows にインストールされた OCR 言語を使います。設定 > 時刻と言語 > 言語と地域でその言語 (光学式文字認識を含む) を追加し、Platenwise の設定の OCR 言語で選んでください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

[お問い合わせ] でメール アプリが開きません。

既定のメール アプリがない場合は、[情報をコピー] を選択し、お使いのメール サービスから hello@earntolink.com に送信してください。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
