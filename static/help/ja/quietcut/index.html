使い方

無音をカットする

  1. 録画ファイルを開きます。無音が自動で検出されます。
  2. プリセット (タイト・標準・ゆったり) を選ぶか、しきい値、最小無音長、前後の余白を設定します。短縮時間がすぐに表示されます。

カットを確認・調整する

  1. プレビューを再生すると、カット部分はスキップされます。J/K/L で再生、C でカット/保持、I/O/X で範囲をカットします。
  2. Pro: 9 言語のフィラー (えー、あの) も検出します。音声認識はこの PC で行います。

エクスポート

  1. [エクスポート] を選択し、MP4、音声のみ、SRT 字幕から選びます。無料版は 15 分以下のファイルまでです。
  2. Pro: Final Cut Pro・DaVinci Resolve (FCPXML)、Premiere Pro (XML)、EDL のカット リストのエクスポートと、複数録画の一括処理。

機能

  • 無音はすぐに、フィラーは PC 内の音声認識で検出(フィラー語:Pro)
  • 波形タイムライン: 残す・カット・長さ調整・手動追加、元に戻す
  • カットを飛ばすプレビュー、J/K/L キーボード編集
  • MP4（フレーム精度・スマートカット）、音声、SRT 字幕を書き出し(無料:15 分以内のファイル)
  • Final Cut・DaVinci Resolve・Premiere Pro・EDL 用カットリスト(Pro)
  • 一括処理、オフライン、アカウント不要、Pro は買い切り(一括処理:Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。一部の機能は初回使用時にモデルやコンポーネントを 1 回ダウンロードし、その後はオフラインで動作します。アカウント、広告、トラッキングはありません。

対応しているファイル形式は?

開く: MP4、MOV、MKV、MP3、WAV、M4A など Windows で再生できる動画・音声。エクスポート: MP4、M4A、MP3、WAV、FLAC、SRT、FCPXML・Premiere XML・EDL (Pro)。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

プレビューに映像が表示されません。

プレビューは Windows Media Foundation を使用します。HEVC など一部のコーデックには Microsoft Store の拡張機能が必要です。エクスポートは可能です。

プレビューがカクつく、または表示が乱れます。

PC または GPU メーカーからグラフィックス ドライバーを最新に更新します。ノート PC では電源アダプターを接続し、電源モードを [最適なパフォーマンス] にします。

処理が遅いです。

大きなファイルや多数のファイルは時間がかかります。ほかの重いアプリを閉じ、ノート PC は電源につなぎ、作業が終わるまでスリープしないようにしてください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
