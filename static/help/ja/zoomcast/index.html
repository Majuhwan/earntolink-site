使い方

画面を録画する

  1. 全画面、ウィンドウ、ドラッグした領域から選び、システム音声とマイクを選びます。
  2. 録画を開始します。Ctrl+Shift+F9 でいつでも停止できます。無料版は 5 分までです。

ズームを編集する

  1. クリックや入力をした箇所に自動でズームが入ります。タイムラインで追加・削除・移動・伸縮を行います。
  2. 背景、余白、角の丸み、影を設定し、前後をトリミングします。

動画をエクスポートする

  1. [エクスポート] を選択し、縦横比と解像度を選んで MP4 で保存します。可能な場合は GPU エンコーダーを使います。

機能

  • クリックと入力に合わせて滑らかに自動ズーム
  • ズームのタイムライン編集: 倍率・タイミング・イーズ・固定位置
  • 大きく滑らかなカーソル、クリックの波紋、ショートカット表示
  • 背景・余白・角丸・影、Web カメラのバブル(カスタム背景・Web カメラ:Pro)
  • 画面・PC の音・マイク・Web カメラを別トラックで録画(Web カメラ:Pro)
  • MP4（最大 4K 60fps）・GIF、オフライン、Pro は買い切り(1080p 30 fps 超・GIF:Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

エクスポート: MP4 (1080p、1440p・4K・60 fps は Pro)、GIF (Pro)。背景画像: PNG、JPG。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

録画に音声が入っていません。

録画前にシステム音声とマイクがオンで、正しいデバイスが選ばれているか確認してください。Windows のプライバシー設定でマイクへのアクセスを許可する必要があります。

プレビューがカクつく、または表示が乱れます。

PC または GPU メーカーからグラフィックス ドライバーを最新に更新します。ノート PC では電源アダプターを接続し、電源モードを [最適なパフォーマンス] にします。

保存またはエクスポートできません。

フォルダーが読み取り専用か、ディスクの空き容量が不足している可能性があります。ドキュメントなど別のフォルダーを選択してください。Windows セキュリティの [コントロールされたフォルダー アクセス] がオンの場合は、このアプリを許可します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
