使い方

大きなファイルを開く

  1. ファイルを開くかウィンドウにドラッグします。区切り文字、見出し、列の型、エンコードを自動検出します。
  2. 最初の行はすぐに表示され、残りは進行状況とキャンセル付きでバックグラウンドで準備されます。

並べ替え・フィルター・検索

  1. 列見出しを選択して並べ替えるか、フィルター (含む・等しい・より大きい/小さい・空・正規表現) を追加します。
  2. [検索] で全列を検索し、件数を確認します。列の統計はサイド パネルに表示されます。

列を整える

  1. 列ツールで分割、結合、空白削除、大文字小文字・型の変換、空欄の補完、置換、SQL 式による新しい列を作成します。
  2. すべての変更は元に戻す・やり直しができます。

現在の表示をエクスポートする

  1. [エクスポート] を選択し、形式とエンコード (Excel 用は UTF-8 BOM 付き) を選んで保存します。無料版は 10 万行までです。

機能

  • 10 GB 超の CSV・Excel・Parquet・JSON をメモリに全部読まずに開く
  • 区切り・型・文字コード（Shift-JIS・CP949・GBK）を自動判別
  • 数百万行もなめらかな仮想グリッド、編集と元に戻す
  • 並べ替え・抽出・検索と置換・列の統計
  • 分割・結合・整形・重複削除・ピボット・SQL(結合・ファイル分割・ピボット・SQL:Pro)
  • CSV（文字コード選択）・Excel・Parquet・JSON へ書き出し(無料:10 万行まで)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

開く: CSV、TSV、TXT、Excel (.xlsx)、Parquet、JSON。エンコードは自動検出 (UTF-8/16、CP949/EUC-KR、Shift-JIS、GBK、Big5、Windows-1252)。エクスポート: エンコードを選んだ CSV/TSV、.xlsx、Parquet、JSON。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

文字化けしています。

エンコード メニューから手動で選びます。例: 日本語は Shift-JIS、古い韓国語 Excel ファイルは CP949。

非常に大きなファイルの並べ替えに失敗します。

大きな並べ替えにはデータとほぼ同じ一時ディスク領域が必要です。システム ドライブの空きを増やして再試行してください。

保存またはエクスポートできません。

フォルダーが読み取り専用か、ディスクの空き容量が不足している可能性があります。ドキュメントなど別のフォルダーを選択してください。Windows セキュリティの [コントロールされたフォルダー アクセス] がオンの場合は、このアプリを許可します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
