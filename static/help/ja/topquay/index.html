使い方

ノッチを使う

  1. [ノッチを表示] を選択します。画面上部の中央に小さなバーが表示され、クリックは下のウィンドウにそのまま届きます。
  2. バーをポイントすると開き、再生中のメディアと操作、タイマー・ストップウォッチ、バッテリーが表示されます。離すと閉じます。
  3. 設定ウィンドウを閉じてもノッチは動作し続けます。通知領域のアイコンから設定を再び開けます。

メディアの操作

  1. Windows のメディア操作に対応したアプリ (音楽プレーヤー・ブラウザー・動画アプリ) のタイトル・アーティスト・アートワーク・進行状況が表示されます。
  2. 開いたノッチで [前へ]・[再生/一時停止]・[次へ] を使います。

サイズ・位置・色

  1. [外観] でサイズを変え、ノッチを左右に移動できます (ノート PC のカメラ位置に合わせるなど)。
  2. 配色テーマ、大サイズ、別のディスプレイ、クリップボードと CPU/メモリ ウィジェット、ポモドーロは Pro の機能です。

機能

  • 画面上部の細いバー、閉じている間はクリック通過
  • アートワークと前へ・再生・次へ付きの再生情報
  • プリセットと通知付きタイマー、ラップ付きストップウォッチ
  • バッテリー残量と残り時間、日付と時刻
  • 全画面アプリ中は非表示、位置調整、モニターごとの拡大率
  • 配色テーマ、クリップボード/CPU・メモリ ウィジェット、ポモドーロ、別ディスプレイ (Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

ノッチが消えます。

そのディスプレイで全画面のゲーム・動画・プレゼンテーションが実行されている間はノッチが隠れ、終わると戻ります。表示し続けるには [設定] > [全画面アプリの実行中は非表示] をオフにします。排他的全画面のゲームは常にノッチを覆います。

メディアが表示されません。

Windows のメディア操作に情報を送るアプリだけが表示されます (Windows の音量フライアウトと同じ)。アプリで再生を始めてからノッチをポイントしてください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

[お問い合わせ] でメール アプリが開きません。

既定のメール アプリがない場合は、[情報をコピー] を選択し、お使いのメール サービスから hello@earntolink.com に送信してください。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
