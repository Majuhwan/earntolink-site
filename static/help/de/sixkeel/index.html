Anleitungen

Konto hinzufügen

  1. Aktivieren Sie auf der Website die Zweistufige Überprüfung mit einer Authentifizierungs-App. Die Website zeigt einen QR-Code und einen Schlüssel.
  2. Wählen Sie in Sixkeel „Hinzufügen“. Für ein gespeichertes QR-Bild „Bilddatei“ oder „Zwischenablage“, für einen QR-Code auf dem Bildschirm „Bildschirmbereich“ (Pro), für einen otpauth://-Link „Einrichtungslink“ oder „Schlüssel eingeben“.
  3. Geben Sie zum Abschluss den in Sixkeel angezeigten 6-stelligen Code auf der Website ein.

Code kopieren

  1. Wählen Sie den Code oder die Kopierschaltfläche. Der Ring zeigt die verbleibenden Sekunden, darunter steht der nächste Code.
  2. Der kopierte Code wird nicht im Zwischenablageverlauf oder in der Cloud-Zwischenablage gespeichert und nach 30 Sekunden gelöscht (Einstellungen > Zwischenablage leeren).

Mit Kennwort oder Windows Hello sperren

  1. Konten sind auf diesem PC immer für Ihren Windows-Benutzer verschlüsselt. Unter Einstellungen > Kennwort festlegen fügen Sie ein Kennwort hinzu, das zum Öffnen der Codes nötig ist.
  2. Mit Kennwort können Sie Windows Hello (Pro) einschalten und per Gesicht, Fingerabdruck oder PIN entsperren. Automatisch sperren greift nach der gewählten Zeit und beim Sperren von Windows.

Sichern und wiederherstellen

  1. Sicherung > Sicherung exportieren speichert eine mit dem Sicherungskennwort verschlüsselte .sixkeel-Datei (scrypt + AES-256-GCM). Bewahren Sie sie auf einem USB-Laufwerk oder einem anderen PC auf.
  2. Wiederherstellen liest eine .sixkeel-Datei und fügt fehlende Konten hinzu. Automatische Sicherungen mit Versionen in einen Ordner gehören zu Pro.

Von einer anderen Authentifizierungs-App umziehen

  1. Exportieren Sie die Konten in der anderen App als Datei (Aegis, 2FAS, andOTP) oder als Export-QR-Codes.
  2. Importieren > Datei auswählen (Pro) liest die Datei; verschlüsselte Dateien fragen nach dem Kennwort. Für Export-QR-Codes Hinzufügen > Bilddatei oder Bildschirmbereich verwenden.

Funktionen

  • Unbegrenzt viele Konten, zeit- und zählerbasierte Codes
  • Hinzufügen per QR-Bild, Zwischenablage, Einrichtungslink oder Schlüssel
  • Verschlüsselt auf diesem PC, optionales Kennwort, automatische Sperre
  • Kopierte Codes nicht im Verlauf und automatisch gelöscht
  • Verschlüsselte Sicherung und Wiederherstellung, ohne Internet
  • Windows Hello, QR aus Bildschirmbereich, Import, Ordner, automatische Sicherungen (Pro)

Häufige Fragen

Was ist Pro?

Pro ist ein einmaliger Add-on-Kauf im Microsoft Store, kein Abonnement. Es gilt auf Windows-PCs, die mit demselben Microsoft-Konto angemeldet sind.

Wie erhalte ich Pro auf einem anderen PC oder nach einer Neuinstallation zurück?

Melden Sie sich mit dem Kaufkonto im Microsoft Store an und wählen Sie dann Hilfe > Kauf wiederherstellen.

Wie erhalte ich eine Erstattung?

Zahlungen und Erstattungen wickelt Microsoft ab. Öffnen Sie account.microsoft.com > Bestellverlauf, wählen Sie die Bestellung und beantragen Sie eine Erstattung. Es gelten die Erstattungsrichtlinien von Microsoft.

Braucht die App Internet? Werden meine Daten gesendet?

Nein. Dateien und Eingaben werden nur auf diesem PC verarbeitet und nie hochgeladen. Keine Konten, Werbung oder Tracking. Das Internet wird nur für Käufe und Updates im Microsoft Store genutzt.

Wie aktualisiere ich die App?

Der Microsoft Store installiert Updates automatisch. Zum sofortigen Prüfen öffnen Sie Microsoft Store > Bibliothek und wählen Updates abrufen.

Problembehandlung

Die Website lehnt den Code ab.

Zeitbasierte Codes brauchen eine richtige PC-Uhr. Schalten Sie unter Windows-Einstellungen > Zeit und Sprache > Datum und Uhrzeit „Uhrzeit automatisch festlegen“ ein und wählen Sie „Jetzt synchronisieren“. Wechselt der Code gleich, warten Sie auf den nächsten.

Der QR-Code wird nicht gefunden.

Verwenden Sie ein scharfes Bild mit dem ganzen Code oder wählen Sie mit „Bildschirmbereich“ nur den Code aus. Klappt es nicht, geben Sie den Schlüssel neben dem QR-Code mit „Schlüssel eingeben“ ein.

Ich habe das Kennwort vergessen.

Das Kennwort kann nicht wiederhergestellt oder zurückgesetzt werden; es wird nirgends gespeichert. Ist Windows Hello aktiv, entsperren Sie damit und legen ein neues Kennwort fest. Sonst stellen Sie eine Sicherung wieder her.

Ich habe Pro gekauft, aber die Funktionen sind gesperrt.

Wählen Sie Hilfe > Kauf wiederherstellen. Prüfen Sie, ob der Microsoft Store mit dem Kaufkonto angemeldet ist. Direkt nach dem Kauf kann die Bestätigung einige Minuten dauern.

Wie ändere ich die Sprache der App?

Die App verwendet die Windows-Anzeigesprache. Ändern Sie sie unter Einstellungen > Zeit und Sprache > Sprache und Region und starten Sie die App neu.

Ist keine Standard-E-Mail-App festgelegt, wählen Sie Infos kopieren und senden Sie den Text mit einem beliebigen E-Mail-Dienst an hello@earntolink.com.
