사용법

PDF·그림 보기

  1. Paperwise PDF를 기본 앱으로 정한 뒤 파일을 두 번 누릅니다. 앱이 열려 있을 때 여는 파일은 새 탭으로 열립니다.
  2. 보기 메뉴에서 한 쪽·두 쪽·읽기 모드·발표를 고릅니다. 찾기는 모든 일치를 문맥과 함께 보여 줍니다.

표시·서명·양식 채우기

  1. 표시 도구 모음에서 형광펜, 메모, 도형, 손글씨, 글상자를 씁니다.
  2. 서명을 선택해 그리거나 입력하거나 그림을 가져옵니다. 양식 칸은 이 PC에 저장한 프로필로 채울 수 있습니다.

쪽 정리·합치기·변환

  1. 쪽 썸네일을 열어 순서 바꾸기, 회전, 삭제, 빈 쪽·다른 PDF 넣기를 합니다.
  2. OCR, 가림, 비교, 압축, 암호, PDF → 워드 같은 도구는 도구 메뉴에 있습니다. 저장은 확인한 사본을 먼저 쓰고 이전 판 백업을 남깁니다.

기능

  • PDF·사진을 약 0.5초 만에 열고, 화살표 키로 폴더 안 그림 넘기기
  • 표시·서명·자동 채우기 양식, PDF 안 글자 직접 고치기
  • 쪽 합치기·나누기·정리, OCR·진짜 가림·비교·압축·변환
  • 그림 자르기·크기·회전·색 보정·표시, JPG·PNG·WebP·TIFF·PDF 등으로 변환
  • 슬라이드 쇼·GIF 프레임·카메라 정보와 GPS 를 보여 주는 정보 창·스캐너 가져오기
  • 안전한 저장: 새 파일을 확인한 뒤에만 원본을 바꾸고 백업·복원

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

PDF, 그림: JPG, PNG, GIF, BMP, ICO, TIFF, WebP, SVG, PSD(HEIC·AVIF·JPEG XL·RAW는 무료 Windows 확장 필요), XPS·OXPS는 PDF 사본으로 열기. 오피스·HTML·그림을 PDF로 변환.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

HEIC·AVIF·RAW 사진이 열리지 않습니다.

Microsoft Store에서 무료 HEIF 이미지 확장, AV1 비디오 확장, Raw 이미지 확장을 설치한 뒤 다시 엽니다.

파일이 열리지 않습니다.

파일이 다른 앱에서 열려 있거나, 손상되었거나, 지원하지 않는 형식일 수 있습니다. 파일을 사용하는 다른 앱을 닫고 다시 시도합니다. 지원 형식은 위 질문을 참고합니다.

저장하거나 내보낼 수 없습니다.

폴더가 읽기 전용이거나 디스크 공간이 부족할 수 있습니다. 문서 폴더 같은 다른 폴더를 선택합니다. Windows 보안의 제어된 폴더 액세스가 켜져 있으면 이 앱을 허용합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
