사용법

홈에서 시작하기

  1. 새로 만들기에서 문서, 스프레드시트, 프레젠테이션 중 하나를 고릅니다.
  2. 또는 템플릿을 고릅니다: 갤러리 위에서 문서, 스프레드시트, 프레젠테이션을 바꿉니다.
  3. 최근 항목에는 마지막으로 연 모든 종류의 파일이 있습니다. 열기…로 지원하는 파일을 엽니다.

탭으로 작업하기

  1. 파일마다 위쪽에 탭이 하나씩 열리고, 아이콘 색으로 종류를 알 수 있습니다.
  2. Ctrl+Tab, Ctrl+Shift+Tab으로 탭과 홈 사이를 옮깁니다. 탭의 ×를 선택하면 파일을 닫습니다.
  3. 탭 안의 메뉴, 도구 모음, 바로 가기 키는 그 파일 종류의 편집기(Folios, Spreadwell, Stagelit과 같음)의 것입니다.

파일 탐색기에서 열기

  1. 파일을 마우스 오른쪽 단추로 클릭하고 연결 프로그램에서 Docfern을 고릅니다. 기본 앱으로 하려면 설정 > 앱 > 기본 앱으로 갑니다.
  2. 파일을 홈으로 끌어 놓아도 됩니다. 알맞은 편집기에서 열립니다.

무료와 Pro

  1. 무료판에는 Folios, Spreadwell, Stagelit 무료판의 기능이 모두 있습니다.
  2. Pro는 홈의 Pro 받기에서 한 번 결제하며, 세 편집기의 Pro 기능이 모두 켜집니다.
  3. Folios, Spreadwell, Stagelit 개별 앱에서 산 Pro는 다른 제품이라 여기의 Pro를 열지 않습니다(반대도 마찬가지).

기능

  • 문서·스프레드시트·프레젠테이션을 한 창의 탭으로
  • docx, xlsx, pptx 열기·저장, doc, odt, rtf, HWPX, xls, csv, ods, ppt, odp 열기
  • 새 파일, 템플릿, 테마, 모든 종류의 최근 파일이 있는 홈
  • 변경 내용 추적, 메모, 수식이 있는 표, 목차
  • 함수 도움말이 있는 수식 입력줄, 조건부 서식, 차트
  • 마법 이동, 발표자 화면, 슬라이드 쇼에서 재생되는 내레이션
  • 모든 파일 종류 PDF 내보내기
  • 무료로 사용, Pro는 한 번 결제

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

문서 – 열기: .docx .dotx .docm .doc .rtf .odt .hwpx .hwp .md .txt .html, 저장: .docx .dotx .rtf .md .html .txt, PDF 내보내기. 스프레드시트 – 열기: .xlsx .xlsm .xls .csv .tsv .ods, 저장: .xlsx .csv, PDF. 프레젠테이션 – 열기: .pptx .potx .ppsx .pptm .ppt .odp, 저장: .pptx, PDF·그림·MP4 내보내기.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

파일이 열리지 않습니다.

파일이 다른 앱에서 열려 있거나, 손상되었거나, 지원하지 않는 형식일 수 있습니다. 파일을 사용하는 다른 앱을 닫고 다시 시도합니다. 지원 형식은 위 질문을 참고합니다.

저장하거나 내보낼 수 없습니다.

폴더가 읽기 전용이거나 디스크 공간이 부족할 수 있습니다. 문서 폴더 같은 다른 폴더를 선택합니다. Windows 보안의 제어된 폴더 액세스가 켜져 있으면 이 앱을 허용합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
