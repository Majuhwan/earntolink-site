사용법

조준점 만들기

  1. 모양(십자·T자·점·원·갈매기·삼각형·사각형·호·방사형)을 고르고 길이, 두께, 간격, 색, 회전, 테두리, 링, 가운데 점을 정합니다.
  2. 어두운·밝은·샘플 배경에서 확인하고 프리셋으로 저장합니다. 무료 버전은 프리셋 3개까지 저장합니다.

조준점 10,000개에서 고르기

  1. 라이브러리를 엽니다. 분류·색·크기·모양으로 좁히거나 「초록 원」 같은 태그, #1234 같은 번호를 입력하세요. 랜덤을 누르면 아무거나 하나 고릅니다.
  2. 조준점을 클릭하면 바로 적용됩니다. 별표로 즐겨찾기에 넣거나 「복사해서 편집」으로 디자이너에서 다듬으세요. 무료 버전은 #1–#500(모든 분류 포함), Pro는 10,000개 전부를 씁니다.

공유 코드와 PNG

  1. 「코드 가져오기」를 누르고 Crossnib 코드, Counter-Strike 2 조준점 코드(CSGO-…), Valorant 조준점 프로필 코드(0;P;…)를 붙여 넣으세요. 게임 코드는 1080p 화면 기준 근사치입니다. 가져오기는 무료입니다.
  2. 「코드 복사」로 다른 사람이 가져올 수 있는 코드를 만듭니다. 「PNG 내보내기」(Pro)는 조준점을 1×·2×·4× 크기의 투명 배경 그림으로 저장합니다.

게임에서 표시

  1. 처음 실행하면 오버레이는 꺼져 있습니다. 조준점 화면의 스위치를 켜거나 Ctrl + Alt + H를 누르세요. 선택한 모니터의 정중앙에 픽셀 단위로 정확히 놓입니다.
  2. 게임 목록에 게임을 넣으면 그 게임이 앞에 있을 때만 오버레이가 보입니다.

기능

  • 기본 조준점 10,000개, 11개 분류, 필터·태그 검색·즐겨찾기·랜덤(무료: 500개)
  • 창 모드·테두리 없는 창 게임 위에 클릭이 통과되는 조준점 오버레이
  • 디자이너: 십자·T자·점·원·갈매기·삼각형·사각형·호·방사형, 회전·테두리·링, PNG 그림(Pro)
  • 공유 코드, Counter-Strike 2·Valorant 코드 가져오기, PNG 내보내기(Pro)
  • 전역 단축키, 모니터 선택, 게임 목록, 게임별 프리셋(Pro), 시계·시스템 정보·글자·그림 오버레이(Pro)
  • 주입·후킹·메모리 읽기 없음, 알림 영역 앱, CPU 1% 미만

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

게임에서 조준점이 보이지 않습니다.

전용 전체 화면은 오버레이를 가립니다. 게임을 테두리 없는 창 또는 창 모드 전체 화면으로 바꿉니다. 일부 안티치트도 오버레이를 막습니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

문의하기에서 메일 앱이 열리지 않습니다.

기본 메일 앱이 없으면 정보 복사를 선택하고, 사용하는 메일 서비스에서 hello@earntolink.com(으)로 보냅니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.

문의하기

앱 이름과 버전을 적어 hello@earntolink.com(으)로 메일을 보내십시오. 앱의 도움말 > 문의하기를 사용하면 이 정보가 자동으로 들어갑니다.
