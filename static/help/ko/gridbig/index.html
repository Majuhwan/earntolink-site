사용법

큰 파일 열기

  1. 파일을 열거나 창에 끌어 놓습니다. 구분자, 머리글, 열 형식, 인코딩을 자동으로 감지합니다.
  2. 처음 줄은 바로 보이고, 나머지는 진행률과 취소가 있는 상태로 뒤에서 준비합니다.

정렬·거르기·찾기

  1. 열 머리글을 선택해 정렬하거나 거르기(포함·같음·크다/작다·비었음·정규식)를 추가합니다.
  2. 찾기로 모든 열에서 찾고 찾은 개수를 확인합니다. 열 통계는 옆 패널에 표시됩니다.

열 정리

  1. 열 도구로 나누기, 합치기, 공백 지우기, 대소문자·형 바꾸기, 빈 칸 채우기, 바꾸기, SQL 식으로 새 열을 만듭니다.
  2. 모든 변경은 되돌리기·다시 하기가 됩니다.

지금 보기 내보내기

  1. 내보내기를 선택하고 형식과 인코딩(엑셀용은 UTF-8 BOM)을 골라 저장합니다. 무료 버전은 10만 줄까지입니다.

기능

  • 10 GB 넘는 CSV·엑셀·Parquet·JSON 을 메모리에 다 올리지 않고 열기
  • 구분자·형식·인코딩(CP949·Shift-JIS·GBK 포함) 자동 감지
  • 수백만 줄도 부드러운 가상 격자, 고치고 되돌리기
  • 정렬·거르기·찾아 바꾸기·열 통계
  • 나누기·합치기·정리·중복 지우기·피벗·잇기·SQL(잇기·파일 나누기·피벗·SQL: Pro)
  • CSV(인코딩 고르기)·엑셀·Parquet·JSON 으로 내보내기(무료: 10만 줄까지)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

열기: CSV, TSV, TXT, 엑셀(.xlsx), Parquet, JSON. 인코딩 자동 감지(UTF-8/16, CP949/EUC-KR, Shift-JIS, GBK, Big5, Windows-1252). 내보내기: 인코딩을 고른 CSV/TSV, .xlsx, Parquet, JSON.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

글자가 깨져 보입니다.

인코딩 메뉴에서 직접 고릅니다. 예: 예전 한국어 엑셀 파일은 CP949, 일본어는 Shift-JIS.

아주 큰 파일 정렬이 실패합니다.

큰 정렬은 데이터 크기만큼의 임시 디스크 공간이 필요합니다. 시스템 드라이브 공간을 비운 뒤 다시 시도합니다.

저장하거나 내보낼 수 없습니다.

폴더가 읽기 전용이거나 디스크 공간이 부족할 수 있습니다. 문서 폴더 같은 다른 폴더를 선택합니다. Windows 보안의 제어된 폴더 액세스가 켜져 있으면 이 앱을 허용합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
