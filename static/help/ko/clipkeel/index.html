사용법

화질 손실 없이 자르기

  1. 영상을 열거나 창으로 끌어 놓습니다. 바로 열리고, 키프레임을 찾는 동안 타임라인에 주황색 눈금으로 나타납니다.
  2. 시작 지점으로 이동하고(화살표: 한 프레임, Ctrl+화살표: 키프레임) I를 누른 뒤 끝 지점에서 O를 누릅니다. I/O 한 쌍마다 구간이 추가되고, 타임라인에서 가장자리를 끌어 고칩니다.
  3. 내보내기에서 남기기/빼기, 파일 하나/구간마다 파일, 형식을 고르고 내보냅니다. 영상과 소리는 다시 인코딩하지 않고 복사합니다. 스마트 컷이 없으면 각 구간은 시작 앞의 키프레임에서 시작합니다(빗금 표시).

프레임 단위 스마트 컷(Pro)

  1. 내보내기에서 스마트 컷을 켭니다. 자르는 위치와 가장 가까운 키프레임 사이의 프레임만 같은 코덱의 Windows 인코더로 다시 인코딩하고 나머지는 그대로 복사합니다.
  2. 스마트 컷은 H.264·HEVC 영상(8비트 4:2:0)에서 동작합니다. HEVC는 Windows에 HEVC 인코더(HEVC 비디오 확장 또는 그래픽 카드 인코더)가 있어야 합니다. 없으면 키프레임에서 잘라 저장하고 알림을 보여 줍니다.

트랙·오디오·프레임

  1. 트랙에서 결과에 넣지 않을 오디오·자막 트랙의 체크를 끕니다. 오디오 내보내기는 체크한 오디오 트랙을 각각 다시 인코딩 없이 파일로 저장합니다.
  2. 프레임 저장은 재생 위치의 정확한 프레임을 PNG로 저장합니다. 합치기는 코덱·화면 크기·오디오 트랙이 같은 파일을 통째로 잇습니다.

장면·챕터·목록·일괄 처리(Pro)

  1. 장면으로 나누기는 영상의 장면 전환마다 구간을 만듭니다. 챕터는 합친 파일에 구간마다 챕터를 넣습니다. 목록 가져오기·내보내기는 CSV(시작·끝·이름)와 챕터 텍스트(00:00 이름)를 읽고 씁니다.
  2. 일괄 처리는 여러 파일의 앞뒤에서 같은 초만큼 손실 없이 잘라 냅니다.

작업 저장

  1. 프로젝트 저장은 구간·트랙·옵션을 영상 옆의 .clipkeel.json 파일에 씁니다. 프로젝트 열기로 나중에 이어 갑니다. 원본은 바뀌지 않고 결과는 새 파일로 저장됩니다.

기능

  • 다시 인코딩 없는 무손실 자르기, 워터마크 없음(무료)
  • 타임라인의 키프레임 표시, 프레임 단위 이동
  • 구간 남기기·빼기, 파일 하나 또는 구간마다
  • 트랙·MP4/MKV/MOV·합치기·오디오 트랙·PNG 프레임(무료)
  • Windows 인코더로 프레임 단위 스마트 컷(Pro)
  • 일괄 처리·장면 나누기·챕터·구간 목록(Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

결과가 시작 지점보다 조금 앞에서 시작합니다.

무손실 자르기는 키프레임에서만 시작할 수 있어 시작 지점 앞의 키프레임에서 시작합니다(타임라인의 빗금 부분). 시작을 키프레임으로 옮기거나(Ctrl+화살표) 스마트 컷(Pro)으로 정확한 프레임에서 자르십시오.

미리 보기에서 영상이 재생되지 않습니다.

재생은 Windows에 설치된 비디오 코덱을 씁니다. 멈춘 화면은 항상 보이고, Windows가 재생하지 못하는 파일도 자를 수 있습니다. HEVC·AV1 재생은 Microsoft Store에서 해당 확장을 설치하십시오.

합치기에서 파일을 합칠 수 없다고 나옵니다.

다시 인코딩 없이 합치려면 모든 파일의 비디오 코덱·화면 크기·오디오 트랙이 같아야 합니다(같은 카메라·같은 설정). 다른 파일은 먼저 영상 편집기에서 변환해야 합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

문의하기에서 메일 앱이 열리지 않습니다.

기본 메일 앱이 없으면 정보 복사를 선택하고, 사용하는 메일 서비스에서 hello@earntolink.com(으)로 보냅니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.

문의하기

앱 이름과 버전을 적어 hello@earntolink.com(으)로 메일을 보내십시오. 앱의 도움말 > 문의하기를 사용하면 이 정보가 자동으로 들어갑니다.
