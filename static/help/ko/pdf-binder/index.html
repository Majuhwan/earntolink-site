사용법

PDF 합치기·정리

  1. 합치기·정리를 고르고 PDF 나 폴더(… 메뉴)를 추가하거나 창에 끌어 놓습니다. PDF 마다 쪽 썸네일 구역이 생깁니다.
  2. 쪽을 끌어 순서를 바꾸거나 다른 문서로 옮깁니다. 놓을 때 Ctrl 을 누르면 복사합니다. Shift/Ctrl+클릭으로 여러 쪽을 골라 함께 끕니다. “선택한 쪽으로 새 문서” 칸에 놓으면 새 문서가 됩니다.
  3. 쪽을 돌리거나(돌리기 단추) 뺍니다(Delete). Ctrl+Z 되돌리기, Ctrl+Y 다시 하기 — 100단계까지.
  4. 저장 방식을 고릅니다: PDF 하나로, 또는 문서마다 따로(구역마다 파일 하나). 그리고 저장. 무료: 한 번에 원본 PDF 3개까지, Pro: 제한 없음. 쪽 안의 링크·주석·양식 필드는 그대로 남습니다.

PDF 나누기

  1. 나누기를 고르고 PDF 를 엽니다(또는 탐색기에서 오른쪽 클릭 → Split with PDF Binder).
  2. 무료 프리셋: 한 쪽씩, N쪽마다, 1-3, 5, 8- 같은 범위(한 번에 10개 파일까지). Pro 프리셋: 책갈피로(1~3단계), 파일 크기로(예: 10 MB), 빈 구분 쪽으로(빈 쪽은 뺌).
  3. 목록에 만들어질 파일이 보입니다. 파일 이름은 기본으로 {name}_{range}(예: Report_1-3.pdf), Pro 는 {name} {n} {range} {from} {to} {pages} {bookmark} {date} 로 규칙을 직접 정할 수 있습니다. 있는 파일은 덮어쓰지 않습니다(Report (2).pdf).

책갈피·결과 옵션(Pro)

  1. 책갈피: 유지는 원래 책갈피를 새 쪽 위치로 옮기고, 파일마다는 합친 파일마다 책갈피를 만들고 그 아래에 원래 책갈피를 둡니다. 나눌 때는 책갈피 · 유지를 체크하면 조각마다 책갈피가 따라갑니다.
  2. 결과 옵션: 압축(낮음·권장·높음 — 작아질 때만 적용), {n}·{total} 을 쓴 쪽 번호나 머리말/꼬리말 글, 워터마크 글, Windows OCR 로 글자 검색 가능하게(Windows 에 설치된 OCR 언어 사용), 열기 암호(AES-256).
  3. 모든 옵션은 무료로 골라 볼 수 있고 Pro 표시가 붙습니다. Pro 는 저장할 때만 묻고, 구매하면 그 자리에서 이어서 저장합니다.

탐색기·감시 폴더·명령줄

  1. 탐색기(무료): PDF 를 고르고 오른쪽 클릭 → Merge with PDF Binder 또는 Split with PDF Binder. Windows 11 에서는 “추가 옵션 표시” 안에 있습니다. 연결 프로그램 → PDF Binder 도 됩니다. 이렇게 연 파일은 이미 떠 있는 창으로 갑니다.
  2. 감시 폴더(Pro): 자동화에서 지켜볼 폴더와 다른 결과 폴더를 고르고, 할 일(지금 나누기 설정으로 나누기, 결과 옵션 적용, 함께 들어온 파일 합치기)을 정해 시작합니다. PDF Binder 가 열려 있는 동안 동작하고 원본은 바꾸지 않습니다.
  3. 명령줄(Pro): pdfbinder merge <파일·폴더> -o out.pdf [--bookmarks perfile], pdfbinder split in.pdf --bookmarks 1 | --size 10 | --blank | --every 2 | --ranges "1-3,5" [-o 폴더] [--name "{n} {bookmark}"], 그리고 --compress, --numbers, --watermark, --ocr, --password. 모든 옵션은 pdfbinder help. 종료 코드: 0 성공, 1 사용법, 2 실패, 3 Pro 필요.

기능

  • 연 PDF 를 모두 한 화면에 쪽 썸네일로
  • 쪽을 끌어 순서 바꾸기·다른 문서로 옮기기, Ctrl+끌기로 복사
  • 되돌리기·다시 하기(Ctrl+Z / Ctrl+Y), 쪽 돌리기·빼기
  • PDF 합치기(무료: 한 번에 3개까지) 또는 문서마다 따로 저장
  • 한 쪽씩·N쪽마다·범위로 나누기(무료: 한 번에 10개 파일까지)
  • 쪽 안의 링크·주석·양식 필드 유지
  • 탐색기 오른쪽 클릭: Merge / Split with PDF Binder
  • Pro: 개수 제한 없이 합치기, 폴더째, 나누기 파일 수 무제한
  • Pro: 책갈피·파일 크기·빈 구분 쪽으로 나누기
  • Pro: 책갈피 유지 + 합친 파일마다 책갈피
  • Pro: 결과 이름 규칙 {name}, {n}, {bookmark}, {date}
  • Pro: 압축·암호 걸기·쪽 번호·워터마크
  • Pro: 그림 → PDF, 쪽 → 그림, 검색 가능한 PDF(Windows OCR)
  • Pro: 감시 폴더·명령줄(pdfbinder.exe)
  • 오프라인, 업로드·계정·광고 없음, Pro 는 한 번 구매

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

PDF(암호 걸린 PDF는 암호를 넣어 열기). Pro 는 그림(JPG, PNG, TIFF, HEIC…)도 쪽으로 넣습니다. 결과는 늘 새 파일로 저장하고 원본은 바꾸지 않습니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

PDF가 암호를 요구합니다.

PDF를 여는 암호를 입력합니다. 암호를 모르는 파일은 열 수 없습니다. 저장한 결과에는 암호가 없습니다(결과 옵션에서 암호를 걸면 Pro).

합친 PDF 안의 링크가 이동하지 않습니다.

웹 링크와 쪽을 가리키는 링크는 남고, 쪽이 옮겨지면 새 위치를 따라갑니다. 뺀 쪽을 가리키던 링크는 갈 곳이 없습니다. 다른 파일의 ‘이름 붙은 대상’을 쓰는 링크는 동작하지 않을 수 있습니다. 책갈피(Pro)는 새로 만들어 늘 맞는 쪽을 가리킵니다.

검색 가능하게(OCR) 했는데 글자가 안 잡히거나 언어가 틀립니다.

PDF Binder 는 Windows 에 들어 있는 글자 인식과 거기 설치된 OCR 언어를 씁니다. Windows 설정 → 시간 및 언어 → 언어 및 지역에서 그 언어(광학 문자 인식)를 추가하세요. 이미 글자가 있는 쪽은 건너뜁니다.

파일이 열리지 않습니다.

파일이 다른 앱에서 열려 있거나, 손상되었거나, 지원하지 않는 형식일 수 있습니다. 파일을 사용하는 다른 앱을 닫고 다시 시도합니다. 지원 형식은 위 질문을 참고합니다.

저장하거나 내보낼 수 없습니다.

폴더가 읽기 전용이거나 디스크 공간이 부족할 수 있습니다. 문서 폴더 같은 다른 폴더를 선택합니다. Windows 보안의 제어된 폴더 액세스가 켜져 있으면 이 앱을 허용합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
