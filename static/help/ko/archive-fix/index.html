사용법

압축 풀기

  1. 압축 파일을 열거나 창에 끌어 놓습니다. 풀기 전에 안의 파일 목록이 보입니다.
  2. 풀기를 선택합니다. 새 폴더에 풀며 기존 파일을 덮어쓰지 않습니다.

깨진 파일 이름 고치기

  1. 다른 시스템에서 만든 한국어·일본어·중국어 ZIP 이름은 자동으로 복구합니다.
  2. 그래도 이름이 이상하면 인코딩을 직접 고릅니다. 무료 버전은 하루 ZIP 3개까지 이름을 복구합니다.

ZIP·7Z 만들기

  1. 파일과 폴더를 추가하고 ZIP 또는 7Z를 골라 만듭니다.
  2. Pro: AES-256 암호를 걸 수 있습니다.

기능

  • ZIP·7Z·RAR 등 16가지 형식
  • 깨진 이름 자동 복구(한·일·중) - 무료 하루 3개
  • 풀기 전 미리보기
  • AES-256 암호 압축(Pro)
  • 기존 파일 덮어쓰지 않음
  • 무료: 풀기·압축 / Pro: AES-256·복구 무제한

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

풀기: ZIP, 7Z, RAR, TAR, GZ, XZ, ISO 등 16가지(암호 걸린 압축 파일 포함). 만들기: ZIP, 7Z(AES-256 암호는 Pro).

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

암호 오류로 풀리지 않습니다.

대소문자와 입력 언어를 포함해 암호를 확인합니다. 암호는 복구할 수 없습니다.

파일이 열리지 않습니다.

파일이 다른 앱에서 열려 있거나, 손상되었거나, 지원하지 않는 형식일 수 있습니다. 파일을 사용하는 다른 앱을 닫고 다시 시도합니다. 지원 형식은 위 질문을 참고합니다.

저장하거나 내보낼 수 없습니다.

폴더가 읽기 전용이거나 디스크 공간이 부족할 수 있습니다. 문서 폴더 같은 다른 폴더를 선택합니다. Windows 보안의 제어된 폴더 액세스가 켜져 있으면 이 앱을 허용합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
