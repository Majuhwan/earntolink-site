사용법

노치 사용

  1. 노치 표시를 선택합니다. 화면 위 가운데에 작은 막대가 나타나고, 클릭은 아래 창으로 그대로 전달됩니다.
  2. 막대에 마우스를 올리면 펼쳐져 재생 중인 미디어와 조작, 타이머·스톱워치, 배터리가 보입니다. 마우스를 치우면 접힙니다.
  3. 설정 창을 닫아도 노치는 계속 실행됩니다. 알림 영역 아이콘에서 설정을 다시 엽니다.

미디어 조작

  1. Windows 미디어 조작을 지원하는 앱(음악 플레이어·브라우저·동영상 앱)의 제목·아티스트·앨범 그림·진행이 보입니다.
  2. 펼친 노치에서 이전·재생/일시 중지·다음을 씁니다.

크기·위치·색

  1. 모양에서 크기를 바꾸고 노치를 왼쪽·오른쪽으로 옮깁니다(예: 노트북 카메라 위치에 맞추기).
  2. 색 테마, 큰 크기, 다른 디스플레이, 클립보드·CPU/메모리 위젯, 뽀모도로는 Pro 기능입니다.

기능

  • 화면 위 얇은 막대, 접혀 있을 때 클릭 통과
  • 앨범 그림과 이전·재생·다음이 있는 재생 정보
  • 바로 시작·알림이 있는 타이머, 랩 스톱워치
  • 배터리 잔량·남은 시간, 날짜·시간
  • 전체 화면 앱 중 숨기기, 위치 조정, 모니터별 배율
  • 색 테마, 클립보드·CPU/메모리 위젯, 뽀모도로, 다른 디스플레이(Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

노치가 사라집니다.

그 디스플레이에서 전체 화면 게임·동영상·발표가 실행되는 동안 노치가 숨었다가 끝나면 돌아옵니다. 계속 보려면 설정 > 전체 화면 앱 실행 중 숨기기를 끕니다. 독점 전체 화면 게임은 항상 노치를 가립니다.

미디어가 보이지 않습니다.

Windows 미디어 조작에 정보를 알리는 앱만 보입니다(Windows 볼륨 창에 나오는 앱과 같음). 앱에서 재생을 시작한 뒤 노치에 마우스를 올립니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

문의하기에서 메일 앱이 열리지 않습니다.

기본 메일 앱이 없으면 정보 복사를 선택하고, 사용하는 메일 서비스에서 hello@earntolink.com(으)로 보냅니다.
