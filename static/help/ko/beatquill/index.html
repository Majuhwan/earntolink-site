사용법

곡 시작하기

  1. 장르 템플릿이나 데모 곡을 고르거나 빈 곡으로 시작합니다.
  2. 브라우저에서 루프를 트랙으로 끌어 놓습니다. 루프는 항상 곡의 템포와 조에 맞춰 재생됩니다.

오디오·MIDI 녹음

  1. 트랙을 녹음 대기로 두고 입력을 고른 뒤 녹음을 누릅니다. 카운트인 뒤 시작하며 반복 녹음은 모든 테이크를 남깁니다.

믹스·내보내기

  1. 믹서에서 볼륨·팬·센드를 정하고 트랙마다 효과를 넣습니다.
  2. 내보내기를 선택하고 WAV, MP3, MIDI 중에서 고릅니다.

기능

  • CC0 녹음으로 만든 샘플 악기 47종, 신스 엔진 12종, 8개 장르 루프 1,008개
  • 함께 연주하는 드러머: 장르 8개 × 스타일 3개, 복잡도·세기 패드, 필인, 베이스 따라가기
  • 장면이 있는 라이브 루프 격자, 곡 배치, 피아노 롤, 스텝 시퀀서, 인쇄 가능한 악보 보기
  • 테이크·컴핑 녹음, 페이드, 타임스트레치, 박자 맞추기, 음정 보정
  • 기타·베이스 앰프 8종, 페달 14종, 튜너, 효과 28종, 라우드니스 미터, VST3·CLAP
  • WAV·MP3·M4A·FLAC·스템·MIDI·DAWproject 내보내기, 단독 모드 저지연

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

가져오기: WAV, MP3, FLAC 등 일반 오디오, MIDI. 내보내기: WAV, MP3, MIDI, FLAC·M4A·스템·DAWproject(Pro).

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

녹음이 늦게 들리거나 지직거립니다.

오디오 설정에서 오디오 인터페이스를 고르고 버퍼 크기를 조절합니다. 지연을 줄이려면 작게, 지직거리면 크게 합니다. 다른 오디오 앱을 닫습니다.

소리가 나지 않습니다.

Windows 소리 설정과 볼륨 믹서에서 출력 장치와 음량을 확인합니다. 다른 앱이 오디오 장치를 단독으로 사용 중이면 그 앱을 닫습니다.

마이크가 작동하지 않습니다.

설정 > 개인 정보 및 보안 > 마이크에서 마이크 액세스와 데스크톱 앱의 마이크 액세스 허용을 켭니다. 그다음 앱에서 올바른 입력 장치를 선택합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
