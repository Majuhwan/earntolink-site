사용법

연결하는 앱 보기

  1. 실시간 목록이 앱별로 원격 주소, 호스트 이름, 포트, 서명 게시자를 1초마다 보여 줍니다.
  2. 처음 보는 앱이 밖으로 연결하면 알림에서 바로 허용하거나 차단합니다.

앱 차단·허용

  1. 앱을 선택하고 차단 또는 허용을 고릅니다. 규칙은 이름이 ETLNW-로 시작하는 Windows Defender 방화벽 규칙이며, 앱을 연 뒤 처음 바꿀 때 Windows 권한 확인 창이 한 번 뜹니다.
  2. 무료 버전은 동시에 앱 5개까지 차단하며, 허용은 제한이 없습니다.

막힌 연결 시도 보기

  1. 설정에서 차단 기록을 켭니다. 켜 둔 동안 Windows가 방화벽이 막은 연결을 감사 기록으로 남기고(보안 감사 "필터링 플랫폼 연결" 실패), 기록 화면에 차단한 앱의 시도가 나옵니다.
  2. 끄거나 앱을 닫으면 Windows 감사 설정을 원래 값 그대로 되돌립니다. 앱이 비정상 종료되어 되돌리지 못했으면 설정에 되돌리기 단추가 나옵니다. 연결이 많은 PC에서는 켜 둔 동안 보안 로그가 더 빨리 찹니다.

기능

  • 앱별 실시간 연결: 경로, 게시자, 주소, 포트, 호스트, 상태
  • 새 앱이 처음 연결하면 허용·차단 알림
  • Windows Defender 방화벽 규칙으로 앱 차단·허용
  • 관리자 권한 없이 실행, 앱을 열 때마다 UAC 한 번
  • 막힌 연결 시도 기록(선택, Windows 감사)
  • 잠금 모드와 업무·게임 프로필(Pro)
  • 앱별 연결 기록, CSV 내보내기(Pro), 알림 영역 앱

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

앱을 제거해도 규칙이 남습니다.

Windows는 앱을 제거해도 방화벽 규칙을 남깁니다. 제거 전에 설정에서 규칙을 삭제합니다. ETLNW-로 시작하는 규칙은 Windows Defender 방화벽에서도 지울 수 있습니다.

권한을 묻는 창이 나타납니다.

일부 작업은 시스템 설정이나 다른 프로그램을 바꾸므로 관리자 권한이 필요합니다. 사용자 계정 컨트롤 창에서 예를 선택합니다. 아니요를 선택하면 그 작업만 건너뜁니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
