사용법

화면 캡처

  1. 캡처 단축키를 누르거나 영역·창·활성 창·전체 화면 중 하나를 고릅니다.
  2. 영역 모드에서 클릭하면 창·패널·단추에 맞춰 잡히고, 끌면 직접 고릅니다. 돋보기로 가장자리를 정확히 맞춥니다.

캡처에 표시하기

  1. 화살표, 도형, 형광펜, 글자, 번호 단계, 흐림, 스포트라이트를 씁니다. 되돌리기·다시 실행은 제한이 없습니다.
  2. 복사하거나 저장하거나 다른 앱으로 끌어 놓습니다.

화면의 글자 복사

  1. 글자 복사를 선택하고 아무 영역이나 끕니다. Windows 글자 인식으로 오프라인에서 읽고 QR 코드도 읽습니다. 무료 버전은 하루 10번입니다.

기능

  • 영역·창·전체 화면·스크롤 캡처, 돋보기와 창·요소 자동 맞춤(스크롤: Pro)
  • 화살표, 글자, 번호 단계, 형광펜, 흐림·모자이크, 스포트라이트, 돋보기 확대(단계·스타일 프리셋: Pro)
  • 인터넷 없이 Windows OCR 로 화면의 글자 복사, QR 코드도 읽기(무료: 하루 10번)
  • 검색되는 보관함: 표시째 다시 열기, 글자·제목·태그로 찾기
  • PNG·JPG·WEBP·PDF 저장, 그림이나 파일로 복사, 다른 앱으로 끌어 놓기
  • 전역 단축키, 트레이 앱, 여러 모니터·고배율 지원 — 계정 없이 완전 오프라인

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

저장: PNG, JPG, WEBP, PDF. 가져오기: 그림 파일, 클립보드.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

Print Screen 키를 누르면 다른 도구가 열립니다.

Windows 설정 > 접근성 > 키보드에서 「Print Screen 키를 사용하여 화면 캡처 열기」를 끈 뒤 이 앱에서 Print Screen 사용을 켭니다.

캡처 일부가 검게 나옵니다.

보호된 동영상 재생기 같은 일부 앱은 화면 캡처를 막습니다. 그 영역은 캡처할 수 없습니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
