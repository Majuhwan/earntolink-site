사용법

JSON 정리·검사

  1. 사이드바에서 JSON을 선택하고 입력 칸에 붙여 넣습니다.
  2. 정리 또는 한 줄로를 선택합니다.
  3. JSON에 오류가 있으면 오류의 줄·칸 위치가 표시됩니다.
  4. 복사를 선택해 결과를 복사합니다.

Base64·URL·HTML 인코딩·디코딩

  1. 사이드바에서 Base64, URL 인코딩, HTML 중 하나를 선택합니다.
  2. 인코딩 또는 디코딩을 선택하고 입력 칸에 붙여 넣습니다.
  3. URL이나 토큰에 쓸 Base64는 URL 안전을 켭니다.

텍스트 해시와 체크섬 비교

  1. 해시를 선택하고 텍스트를 입력합니다. MD5, SHA-1, SHA-256, SHA-512 값이 바로 표시됩니다.
  2. 비교할 해시 칸에 받은 값을 붙여 넣습니다. 같은 값이 있는 줄에 일치가 표시됩니다.
  3. Pro: HMAC를 켜고 키를 입력하면 HMAC-SHA256과 HMAC-SHA512가 표시됩니다.

내려받은 파일 확인 (Pro)

  1. 해시에서 파일 해시를 선택하고 파일을 하나 이상 고릅니다. 크기 제한이 없습니다.
  2. 배포 사이트의 체크섬을 비교할 해시 칸에 붙여 넣습니다.

JWT 내용 보기

  1. JWT를 선택하고 토큰을 붙여 넣습니다.
  2. 헤더와 내용이 표시됩니다. 토큰에 exp가 있으면 만료 시각도 표시됩니다.
  3. 서명은 검증하지 않습니다.

유닉스 시각 변환

  1. 시각 변환을 선택하고 초·밀리초 값이나 ISO 8601 날짜를 입력합니다. 지금을 선택하면 현재 시각이 들어갑니다.
  2. 유닉스 초·밀리초, UTC, 내 시간대 값이 표시됩니다.

UUID 만들기

  1. UUID를 선택하고 −, +로 개수(1~100)를 정한 뒤 만들기를 선택합니다.
  2. 복사를 선택하면 목록 전체가 복사됩니다.

정규식 시험

  1. 정규식을 선택하고 패턴을 입력한 뒤 입력 칸에 시험할 텍스트를 붙여 넣습니다.
  2. 일치 항목과 그룹이 일치 개수와 함께 표시됩니다.
  3. Pro: 바꾸기를 켜고 $1 같은 바꿀 내용을 입력하면 결과를 미리 봅니다. 여러 줄과 줄바꿈 포함 옵션도 있습니다.

기능

  • JSON 정리·한 줄·검사, 오류 위치 표시
  • Base64·URL·HTML 인코딩·디코딩
  • MD5·SHA-1·SHA-256·SHA-512, 체크섬 비교
  • JWT 해석·UUID·유닉스 시각 변환
  • 오프라인 — 데이터가 PC 밖으로 안 나감
  • 무료: 도구 9가지 모두 · Pro: 정규식 바꾸기·파일 해시·HMAC

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

잘못된 입력이라고 표시됩니다.

메시지 옆의 줄:칸 위치를 확인합니다. 끝에 남은 쉼표, 작은따옴표, 주석은 JSON에서 허용되지 않아 자주 오류가 납니다.

Base64 디코딩 결과가 글자가 아니라 16진수로 나옵니다.

디코딩한 데이터가 이미지나 압축 데이터처럼 UTF-8 글자가 아닌 경우입니다. 내용이 손실되지 않게 바이트를 16진수로 표시합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
