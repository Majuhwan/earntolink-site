사용법

계정 추가

  1. 웹 사이트에서 인증 앱을 쓰는 2단계 인증을 켭니다. 사이트에 QR 코드와 키가 표시됩니다.
  2. Sixkeel에서 추가를 선택합니다. 저장한 QR 그림은 이미지 파일이나 클립보드, 화면에 보이는 QR 코드는 화면 영역(Pro), otpauth:// 링크는 설정 링크, 키를 직접 칠 때는 키 직접 입력을 고릅니다.
  3. Sixkeel에 표시된 6자리 코드를 웹 사이트에 입력해 마칩니다.

코드 복사

  1. 코드나 복사 단추를 선택합니다. 원은 남은 초를 나타내고, 아래에 다음 코드가 보입니다.
  2. 복사한 코드는 클립보드 기록·클라우드 클립보드에 남지 않고 30초 뒤 지워집니다(설정 > 클립보드 지우기).

암호·Windows Hello로 잠그기

  1. 계정은 항상 이 PC의 Windows 사용자 기준으로 암호화됩니다. 설정 > 암호 설정에서 암호를 추가하면 코드를 열 때 암호가 필요합니다.
  2. 암호를 설정한 뒤 Windows Hello(Pro)를 켜면 얼굴·지문·PIN으로 잠금을 풉니다. 자동 잠금은 정한 시간이 지나거나 Windows가 잠길 때 잠급니다.

백업과 복원

  1. 백업 > 백업 내보내기는 백업 암호로 암호화한 .sixkeel 파일 하나를 저장합니다(scrypt + AES-256-GCM). USB 드라이브나 다른 PC에 보관합니다.
  2. 복원은 .sixkeel 파일을 읽어 목록에 없는 계정을 추가합니다. 폴더로 버전을 남기는 자동 백업은 Pro 기능입니다.

다른 인증 앱에서 옮기기

  1. 다른 앱에서 계정을 파일(Aegis·2FAS·andOTP)이나 내보내기 QR 코드로 내보냅니다.
  2. 가져오기 > 파일 선택(Pro)으로 파일을 읽습니다. 암호화된 파일은 그 암호를 묻습니다. 내보내기 QR 코드는 추가 > 이미지 파일이나 화면 영역을 씁니다.

기능

  • 계정 수 제한 없음, 시간 기반·카운터 기반 코드
  • QR 그림·클립보드·설정 링크·키로 추가
  • 이 PC에 암호화 저장, 선택 암호, 자동 잠금
  • 복사한 코드는 클립보드 기록에 남지 않고 지워짐
  • 암호화 백업·복원, 인터넷 연결 없음
  • Windows Hello, 화면 영역 QR, 가져오기, 폴더, 자동 백업(Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

웹 사이트가 코드를 거부합니다.

시간 기반 코드는 PC 시계가 맞아야 합니다. Windows 설정 > 시간 및 언어 > 날짜 및 시간에서 자동으로 시간 설정을 켜고 지금 동기화를 선택합니다. 코드가 곧 바뀔 때는 다음 코드를 기다립니다.

QR 코드를 찾지 못합니다.

코드 전체가 보이는 선명한 이미지를 쓰거나, 화면 영역으로 코드만 선택합니다. 그래도 안 되면 웹 사이트가 QR 코드 옆에 보여 주는 키를 키 직접 입력으로 넣습니다.

암호를 잊었습니다.

암호는 어디에도 저장되지 않으므로 찾거나 초기화할 수 없습니다. Windows Hello를 켜 두었다면 Windows Hello로 잠금을 풀고 새 암호를 설정합니다. 아니면 백업을 복원해야 합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

문의하기에서 메일 앱이 열리지 않습니다.

기본 메일 앱이 없으면 정보 복사를 선택하고, 사용하는 메일 서비스에서 hello@earntolink.com(으)로 보냅니다.
