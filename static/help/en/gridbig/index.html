How-to

Open a large file

  1. Open a file or drag it into the window. The delimiter, header, column types, and encoding are detected.
  2. The first rows appear at once; the rest is prepared in the background with progress and Cancel.

Sort, filter, and find

  1. Select a column header to sort or add a filter (contains, equals, greater/less than, empty, regex).
  2. Use Find to search all columns; the match count is shown. Column statistics appear in the side panel.

Clean up columns

  1. Use column tools to split, merge, trim spaces, change case or type, fill blanks, replace, or add a column from a SQL expression.
  2. Every change can be undone and redone.

Export the current view

  1. Select Export, choose a format and encoding (for Excel, UTF-8 with BOM), and save. The free version exports up to 100,000 rows.

Features

  • Open 10 GB+ CSV, Excel, Parquet and JSON without loading into RAM
  • Auto-detect delimiter, types and encodings incl. CP949, Shift-JIS, GBK
  • Smooth virtual grid for millions of rows, edit with undo
  • Sort, filter builder, find & replace, column stats
  • Split, merge, clean, dedupe, pivot, join and SQL (join, split files, pivot and SQL: Pro)
  • Export to CSV (any encoding), Excel, Parquet and JSON (free: up to 100,000 rows)

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

Which file formats are supported?

Open: CSV, TSV, TXT, Excel (.xlsx), Parquet, JSON. Encodings are detected automatically (UTF-8/16, CP949/EUC-KR, Shift-JIS, GBK, Big5, Windows-1252). Export: CSV/TSV with a chosen encoding, .xlsx, Parquet, JSON.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

Text looks garbled.

Choose the encoding manually from the encoding menu, for example CP949 for older Korean Excel files or Shift-JIS for Japanese.

Sorting a very large file fails.

Large sorts need temporary disk space about the size of the data. Free up space on the system drive and try again.

The app can’t save or export.

The folder may be read-only or the disk may be full. Choose another folder, such as Documents. If Controlled folder access is on in Windows Security, allow this app.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
