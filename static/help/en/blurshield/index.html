How-to

Hide faces and personal data in photos

  1. Add photos. Faces, phone numbers, emails, card and account numbers, and ID numbers are found automatically.
  2. Turn boxes on or off, move them, or draw new ones. Choose blur, pixelate, or solid box, then save. Originals are never changed.

Blur faces in video

  1. Open a video. Faces are tracked across frames; turn tracks on or off and set their start and end on the timeline.
  2. Draw a box anywhere to follow other objects. Export a new MP4 with the original audio; the free version handles videos up to 1 minute.

Redact a PDF

  1. Open a PDF, review the personal data found, and drag on pages to add areas.
  2. Save. Text under each box is removed from the file and the result is checked again, so nothing hidden can be copied out.

Features

  • Blur faces in photos automatically and track them through videos
  • Find phone numbers, e-mails, card and account numbers in pictures
  • True PDF redaction: text removed from the file, result verified
  • Video timeline: trim and split tracks, boxes that follow motion, beep
  • Remove EXIF and GPS; batch folders and a watch folder (batch and watch folder: Pro)
  • Audit log with checksums; offline, no account, no upload (CSV export: Pro)

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

Which file formats are supported?

Photos: JPG, PNG, WebP, HEIC (with the Windows extension). Videos: MP4, MOV, and other formats Windows can play; output is MP4. Documents: PDF.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

A face or number wasn’t detected.

Small, turned, or blurry faces and handwritten numbers can be missed. Always review the result and draw boxes over anything left.

A file won’t open.

The file may be open in another app, damaged, or in an unsupported format. Close other apps that use it and try again. See the supported formats above.

Processing is slow.

Large or many files take longer. Close other heavy apps, keep the laptop plugged in, and keep the PC from sleeping until the task finishes.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
