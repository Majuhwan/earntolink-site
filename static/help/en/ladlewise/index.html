How-to

Save a recipe from a website

  1. Copy the address of the recipe page in your browser.
  2. In Import, paste it into Web address and select Download page. Only that page and its recipe photo are downloaded.
  3. Check the title, ingredients and steps, then select Save. The source address is kept with the recipe.

Change servings and units

  1. Open a recipe and use + and − next to Servings. Quantities are recalculated and shown as fractions where that reads better (1 1/2 cups).
  2. Units switches between As written, Metric (ml, g) and US (cups, oz). Spoons stay spoons.

Cook mode

  1. Cook mode shows one step at a time in large text with the ingredients beside it. The screen stays on while it is open.
  2. Use ← and → (or Previous and Next). When a step mentions a time, a Timer button starts a countdown.

Shopping list and meal plan

  1. Add to shopping list puts a recipe’s ingredients (at the shown servings) on the list. The same ingredient is added up, grouped by store section.
  2. With Pro, plan the week in Meal plan and select Week to shopping list to add everything at once.

Print, PDF and other apps’ files

  1. In a recipe, the … menu has Print and Export PDF. The shopping list can be printed or copied as text.
  2. Import > From a file reads JSON (schema.org) files; Paprika and MealMaster files, several addresses at once, Paprika/MealMaster export and the cookbook PDF are part of Pro.

Features

  • Save recipes from web pages without ads (schema.org recipe data)
  • Scale servings and convert units (metric, US)
  • Cook mode with large steps, timers and screen kept on
  • Shopping list that adds up ingredients by store section
  • Search by ingredients on hand, tags, ratings, print and PDF
  • Weekly meal planner, cookbook PDF, batch import (Pro)

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app use the internet?

Only when you select Download page: Ladlewise then downloads that one page and its recipe photo. Recipes, photos, meal plans and shopping lists stay on this PC and are never uploaded. No accounts, ads or tracking; Microsoft Store handles purchases and updates.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

A website can’t be imported.

Some sites block downloads from apps or don’t include recipe data in the page. Select the recipe text in your browser, copy it, and paste it under Paste text or HTML; Ladlewise splits it into ingredients and steps.

Cup amounts look different.

Cups differ by country: Korean and Japanese recipes use 200 ml, German, French and Italian recipes usually 250 ml, US recipes 236.6 ml. Ladlewise converts each by the word used in the recipe.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

How do I change the app language?

The app follows the Windows display language. Change it in Settings > Time & language > Language & region, then restart the app.

Contact support doesn’t open my email app.

If no default email app is set, select Copy info and send the text to hello@earntolink.com from any email service.

Contact support

Email hello@earntolink.com with the app name and version. In the app, Help > Contact support adds this information automatically.
