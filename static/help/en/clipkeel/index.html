How-to

Cut without quality loss

  1. Open a video (or drag it into the window). It opens at once; keyframes appear on the timeline as orange ticks while they are indexed.
  2. Move to the start (arrows step one frame, Ctrl+arrows jump to keyframes), press I, move to the end and press O. Each I/O pair adds a segment; drag its edges on the timeline.
  3. In Export choose Keep or Remove, One file or File per segment, and the format, then Export. Video and audio are copied, not re-encoded. Without smart cut each segment starts on the keyframe before its start (shown hatched).

Frame-accurate smart cut (Pro)

  1. Turn on Smart cut in Export. Only the frames between each cut point and the nearest keyframe are re-encoded with the Windows encoder of the same codec; everything else is copied unchanged.
  2. Smart cut works with H.264 and HEVC video (8-bit 4:2:0). HEVC needs an HEVC encoder in Windows (HEVC Video Extensions or a graphics card encoder). When it is not available the file is saved with keyframe cuts and a notice is shown.

Tracks, audio and frames

  1. In Tracks, clear audio or subtitle tracks you do not want in the result. Export audio saves each checked audio track as its own file without re-encoding.
  2. Save frame stores the exact frame under the playhead as PNG. Merge joins whole files with the same codec, frame size and audio tracks.

Scenes, chapters, lists and batch (Pro)

  1. Split at scenes makes a segment for every hard cut in the video. Chapters adds one chapter per segment to the merged file. Import list and Export list read and write CSV (start, end, name) and chapter text (00:00 Name).
  2. Batch trims the same seconds from the start and end of many files, losslessly.

Save your work

  1. Save project writes the segments, tracks and options to a .clipkeel.json file next to the video; Open project continues later. Originals are never changed; results are new files.

Features

  • Lossless cuts, no re-encoding, no watermark (free)
  • Keyframes on the timeline, frame-by-frame stepping
  • Keep or remove segments, one file or one per segment
  • Tracks, MP4/MKV/MOV, merge, audio tracks, PNG frames (free)
  • Frame-accurate smart cut with Windows encoders (Pro)
  • Batch, scene split, chapters, segment lists (Pro)

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

The result starts a little before my start point.

A lossless cut can only start on a keyframe, so it starts on the keyframe before your start point (the hatched part on the timeline). Move the start onto a keyframe (Ctrl+arrows) or use smart cut (Pro) for the exact frame.

The video does not play in the preview.

Playback uses the video codecs installed in Windows. Paused frames are always shown, and cutting works even when Windows cannot play the file. For HEVC or AV1 playback install the matching extension from Microsoft Store.

Merge says the files cannot be joined.

Joining without re-encoding needs the same video codec, frame size and audio tracks in every file, as from the same camera with the same settings. Files that differ must be converted in a video editor first.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

How do I change the app language?

The app follows the Windows display language. Change it in Settings > Time & language > Language & region, then restart the app.

Contact support doesn’t open my email app.

If no default email app is set, select Copy info and send the text to hello@earntolink.com from any email service.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.

Contact support

Email hello@earntolink.com with the app name and version. In the app, Help > Contact support adds this information automatically.
