1. Allgemeines

EarnToLink (언투링크, „EarnToLink“) schützt personenbezogene Daten nach dem koreanischen Gesetz zum Schutz personenbezogener Daten (Personal Information Protection Act). Diese Erklärung gilt für die Website earntolink.com und die von EarnToLink entwickelten Apps.

Zusammenfassung: Die Website verwendet keine Registrierung, Formulare, Cookies, Analyse oder Werbung. Unsere Apps verarbeiten Dateien und Fotos nur auf dem Gerät und senden sie nie irgendwohin.

2. Website

  • Keine Registrierung, kein Login und keine Formulare.
  • Keine Cookies, Analysewerkzeuge oder Werbeskripte.
  • Die Website wird über GitHub Pages (GitHub, Inc.) bereitgestellt. GitHub kann Zugriffsprotokolle wie IP-Adressen für Betrieb und Sicherheit verarbeiten, gemäß der GitHub General Privacy Statement.
  • Die Schrift Pretendard wird über das jsDelivr-CDN geladen, das Anfragedaten wie die IP-Adresse Ihres Browsers erhalten kann.
  • Sollten jemals Cookies oder Analyse eingeführt werden, wird diese Erklärung zuvor aktualisiert.

Erfasste Apps: Roll Tidy (정리 싹), Roll Flick (넘겨 정리), Space Map (용량 지도), Dupeless (중복 싹), Archive Fix (한글 압축). Alle demnächst verfügbar.

  • Zahlungen werden vom jeweiligen App Store abgewickelt. EarnToLink erhält nie Zahlungsdaten.

5. Kundenprojekte

Betrifft ein Kundenprojekt personenbezogene Daten des Kunden, richten sich Umfang und Art der Verarbeitung nach dem Vertrag und der Auftragsverarbeitungsvereinbarung mit diesem Kunden.

6. Weitergabe an Dritte

Wir geben personenbezogene Daten nicht an Dritte weiter, außer wenn das Gesetz es verlangt.

7. Ihre Rechte

Sie können jederzeit Auskunft, Berichtigung, Löschung oder Einschränkung der Verarbeitung verlangen. Senden Sie Anfragen an hello@earntolink.com; wir bearbeiten sie unverzüglich.

8. Löschung

Personenbezogene Daten werden unverzüglich vernichtet, sobald die Aufbewahrungsfrist endet oder der Zweck erreicht ist. Elektronische Dateien werden so gelöscht, dass sie nicht wiederhergestellt werden können.

9. Sicherheit

Der Zugriff auf E-Mail-Anfragen ist auf den Inhaber beschränkt, und wir erheben nicht mehr personenbezogene Daten als nötig.
