Guides

Ajouter un compte

  1. Sur le site web, activez la vérification en deux étapes avec une application d’authentification. Le site affiche un code QR et une clé.
  2. Dans Sixkeel, sélectionnez Ajouter. Choisissez Fichier image ou Presse-papiers pour une image QR, Zone de l’écran pour un code QR affiché (Pro), Lien de configuration pour un lien otpauth://, ou Saisir la clé.
  3. Saisissez sur le site le code à 6 chiffres affiché dans Sixkeel pour terminer.

Copier un code

  1. Sélectionnez le code ou le bouton Copier. L’anneau indique les secondes restantes ; le code suivant s’affiche dessous.
  2. Le code copié n’apparaît pas dans l’historique ni dans le presse-papiers cloud et est effacé après 30 secondes (Paramètres > Effacer le presse-papiers).

Verrouiller par mot de passe ou Windows Hello

  1. Les comptes sont toujours chiffrés sur ce PC pour votre utilisateur Windows. Paramètres > Définir un mot de passe ajoute un mot de passe exigé pour ouvrir les codes.
  2. Avec un mot de passe, activez Windows Hello (Pro) pour déverrouiller par visage, empreinte ou code PIN. Le verrouillage automatique s’applique après le délai choisi et quand Windows se verrouille.

Sauvegarder et restaurer

  1. Sauvegarde > Exporter une sauvegarde enregistre un fichier .sixkeel chiffré par un mot de passe (scrypt + AES-256-GCM). Conservez-le sur une clé USB ou un autre PC.
  2. Restaurer lit un fichier .sixkeel et ajoute les comptes absents de la liste. Les sauvegardes automatiques versionnées dans un dossier font partie de Pro.

Migrer depuis une autre application d’authentification

  1. Dans l’autre application, exportez les comptes en fichier (Aegis, 2FAS, andOTP) ou en codes QR d’exportation.
  2. Importer > Choisir un fichier (Pro) lit le fichier ; les fichiers chiffrés demandent leur mot de passe. Pour les codes QR d’exportation, utilisez Ajouter > Fichier image ou Zone de l’écran.

Fonctionnalités

  • Comptes illimités, codes basés sur le temps ou un compteur
  • Ajout par image QR, presse-papiers, lien de configuration ou clé
  • Chiffré sur ce PC, mot de passe facultatif, verrouillage automatique
  • Codes copiés hors historique et effacés automatiquement
  • Sauvegarde chiffrée et restauration, sans Internet
  • Windows Hello, QR d’une zone de l’écran, importation, dossiers, sauvegardes automatiques (Pro)

Questions fréquentes

Qu’est-ce que Pro ?

Pro est un module complémentaire acheté une seule fois dans le Microsoft Store, sans abonnement. Il fonctionne sur les PC Windows connectés au même compte Microsoft.

Comment récupérer Pro sur un autre PC ou après une réinstallation ?

Connectez-vous au Microsoft Store avec le compte de l’achat, puis sélectionnez Aide > Restaurer l’achat.

Comment obtenir un remboursement ?

Les paiements et remboursements sont gérés par Microsoft. Accédez à account.microsoft.com > Historique des commandes, sélectionnez la commande et demandez un remboursement. La politique de remboursement de Microsoft s’applique.

L’application a-t-elle besoin d’Internet ? Mes données sont-elles envoyées ?

Non. Les fichiers et saisies sont traités uniquement sur ce PC et ne sont jamais envoyés. Aucun compte, publicité ni suivi. Internet sert uniquement aux achats et mises à jour du Microsoft Store.

Comment mettre à jour l’application ?

Le Microsoft Store installe les mises à jour automatiquement. Pour vérifier maintenant, ouvrez Microsoft Store > Bibliothèque et sélectionnez Obtenir les mises à jour.

Résolution des problèmes

Le site refuse le code.

Les codes basés sur le temps exigent une horloge juste. Dans Paramètres Windows > Heure et langue > Date et heure, activez Régler l’heure automatiquement puis Synchroniser maintenant. Si le code va changer, attendez le suivant.

Le code QR n’est pas trouvé.

Utilisez une image nette montrant tout le code, ou sélectionnez uniquement le code avec Zone de l’écran. Sinon, saisissez la clé affichée à côté du code QR (Saisir la clé).

J’ai oublié le mot de passe.

Le mot de passe ne peut être ni récupéré ni réinitialisé ; il n’est stocké nulle part. Si Windows Hello est activé, déverrouillez avec Windows Hello et définissez un nouveau mot de passe. Sinon, restaurez une sauvegarde.

J’ai acheté Pro, mais les fonctions restent verrouillées.

Sélectionnez Aide > Restaurer l’achat. Vérifiez que le Microsoft Store est connecté au compte de l’achat. Juste après l’achat, la confirmation peut prendre quelques minutes.

Comment changer la langue de l’application ?

L’application suit la langue d’affichage de Windows. Modifiez-la dans Paramètres > Heure et langue > Langue et région, puis redémarrez l’application.

Contacter le support n’ouvre pas ma messagerie.

Si aucune messagerie par défaut n’est définie, sélectionnez Copier les infos et envoyez le texte à hello@earntolink.com depuis n’importe quel service de messagerie.

Contacter le support

Écrivez à hello@earntolink.com en indiquant le nom et la version de l’application. Dans l’application, Aide > Contacter le support ajoute ces informations automatiquement.
