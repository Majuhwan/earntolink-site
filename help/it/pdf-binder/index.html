Guide

Unire e organizzare PDF

  1. Scegli Unisci e organizza e aggiungi PDF o una cartella (menu …), oppure trascinali nella finestra. Ogni PDF appare come sezione di miniature.
  2. Trascina le pagine per riordinarle o spostarle in un altro documento. Tieni premuto Ctrl al rilascio per copiare. Maiusc/Ctrl+clic seleziona più pagine da trascinare insieme. Rilasciale su «Nuovo documento dalla selezione» per crearne uno.
  3. Ruota (pulsante Ruota) o rimuovi (Canc) le pagine. Ctrl+Z annulla e Ctrl+Y ripete, fino a 100 passaggi.
  4. Scegli Salva come: Un PDF o Ogni documento (un file per sezione), poi salva. Gratis: fino a 3 PDF di origine alla volta; Pro: senza limiti. Link, commenti e campi modulo vengono mantenuti.

Dividere un PDF

  1. Seleziona Dividi e apri un PDF (o clic destro in Esplora file → Split with PDF Binder).
  2. Preimpostazioni gratuite: ogni pagina, ogni N pagine o intervalli come 1-3, 5, 8- (fino a 10 file per divisione). Preimpostazioni Pro: per segnalibri (livello 1–3), per dimensione (es. 10 MB) o alle pagine bianche separatrici, che vengono tolte.
  3. L’elenco mostra i file che verranno creati. Il nome predefinito è {name}_{range} (es. Report_1-3.pdf); con Pro puoi creare la tua regola con {name} {n} {range} {from} {to} {pages} {bookmark} {date}. I file esistenti non vengono mai sovrascritti (Report (2).pdf).

Segnalibri e opzioni di output (Pro)

  1. Segnalibri: Mantieni sposta i segnalibri nelle nuove posizioni; Uno per file aggiunge un segnalibro per ogni file unito con i suoi segnalibri sotto. Quando dividi, spunta «Segnalibri · Mantieni».
  2. Opzioni di output: comprimi (Leggera, Consigliata, Forte – solo se il file diventa più piccolo), numeri di pagina o testo di intestazione/piè con {n} e {total}, filigrana, testo ricercabile con l’OCR di Windows (lingue OCR installate) e password di apertura (AES-256).
  3. Puoi scegliere tutte le opzioni gratis e vederle segnate come Pro; Pro viene chiesto solo al salvataggio e il lavoro continua subito dopo l’acquisto.

Esplora file, cartella monitorata e riga di comando

  1. Esplora file (gratis): seleziona i PDF, clic destro → Merge with PDF Binder o Split with PDF Binder. In Windows 11 si trovano in «Mostra altre opzioni»; anche «Apri con → PDF Binder» funziona. I file vanno nella finestra già aperta.
  2. Cartella monitorata (Pro): in Automatizza scegli una cartella da monitorare e un’altra per i risultati, un’azione (dividi con le impostazioni attuali, applica le opzioni di output o unisci i file arrivati insieme) e avvia. Funziona finché PDF Binder è aperto; gli originali non cambiano.
  3. Riga di comando (Pro): pdfbinder merge <file o cartelle> -o out.pdf [--bookmarks perfile], pdfbinder split in.pdf --bookmarks 1 | --size 10 | --blank | --every 2 | --ranges "1-3,5" [-o cartella] [--name "{n} {bookmark}"], più --compress, --numbers, --watermark, --ocr, --password. Tutte le opzioni: pdfbinder help. Codici di uscita: 0 ok, 1 uso, 2 errore, 3 serve Pro.

Domande frequenti

Che cos’è Pro?

Pro è un componente aggiuntivo con acquisto una tantum su Microsoft Store, non un abbonamento. Funziona sui PC Windows con lo stesso account Microsoft.

Come ripristino Pro su un altro PC o dopo la reinstallazione?

Accedi a Microsoft Store con l’account dell’acquisto, quindi seleziona Guida > Ripristina acquisto.

Come ottengo un rimborso?

Pagamenti e rimborsi sono gestiti da Microsoft. Vai su account.microsoft.com > Cronologia ordini, seleziona l’ordine e richiedi il rimborso. Si applica la politica di rimborso di Microsoft.

L’app richiede Internet? I miei dati vengono inviati?

No. File e dati vengono elaborati solo su questo PC e non vengono mai caricati. Nessun account, pubblicità o tracciamento. Internet serve solo per acquisti e aggiornamenti di Microsoft Store.

Quali formati di file sono supportati?

PDF, inclusi quelli protetti da password (inserendola). Pro aggiunge anche immagini (JPG, PNG, TIFF, HEIC…) come pagine. I risultati sono sempre nuovi file; gli originali non vengono modificati.

Come aggiorno l’app?

Microsoft Store installa gli aggiornamenti automaticamente. Per controllare subito, apri Microsoft Store > Raccolta e seleziona Ottieni aggiornamenti.

Risoluzione dei problemi

Un PDF richiede una password.

Inserisci la password di apertura. I file di cui non conosci la password non si possono aprire. Il risultato non ha password, a meno che tu non la imposti nelle opzioni di output (Pro).

Un link nel PDF unito non funziona più.

I link web e quelli verso una pagina vengono mantenuti e seguono la pagina. Un link a una pagina rimossa non ha destinazione. I link con destinazioni con nome di un altro file possono smettere di funzionare; i segnalibri (Pro) vengono ricostruiti e puntano sempre alla pagina giusta.

Il testo ricercabile (OCR) non trova nulla o la lingua è sbagliata.

PDF Binder usa il riconoscimento testo di Windows e le lingue OCR installate. Aggiungi la lingua in Impostazioni → Data/ora e lingua → Lingua e area geografica (riconoscimento ottico dei caratteri). Le pagine che contengono già testo vengono saltate.

Un file non si apre.

Il file potrebbe essere aperto in un’altra app, danneggiato o in un formato non supportato. Chiudi le app che lo usano e riprova. Vedi i formati supportati sopra.

Impossibile salvare o esportare.

La cartella potrebbe essere di sola lettura o il disco pieno. Scegli un’altra cartella, ad esempio Documenti. Se l’accesso controllato alle cartelle è attivo in Sicurezza di Windows, consenti questa app.

Ho acquistato Pro, ma le funzioni sono ancora bloccate.

Seleziona Guida > Ripristina acquisto. Verifica che Microsoft Store sia connesso con l’account dell’acquisto. Subito dopo l’acquisto, la conferma può richiedere alcuni minuti.

L’app non si avvia o non risponde.

Chiudi e riapri l’app. Se il problema continua, vai in Impostazioni > App > App installate > Opzioni avanzate dell’app e seleziona Ripristina. Reimposta cancella anche le impostazioni dell’app.
