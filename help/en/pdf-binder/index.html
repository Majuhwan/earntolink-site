How-to

Merge and arrange PDFs

  1. Select Merge & arrange and add PDFs, a whole folder (… menu), or drag them into the window. Every PDF appears as its own section of page thumbnails.
  2. Drag pages to reorder them or into another document. Hold Ctrl while dropping to copy. Shift/Ctrl+click selects several pages; drag them together. Drop on “New document from selection” to start a new document.
  3. Rotate (R button) or remove (Delete) pages. Ctrl+Z undoes and Ctrl+Y redoes, up to 100 steps.
  4. Choose Save as: One PDF, or Each document (one file per section), then Save. Free: up to 3 source PDFs at a time; Pro: any number. Links, comments and form fields inside the pages are kept.

Split a PDF

  1. Select Split and open a PDF (or right-click it in File Explorer → Split with PDF Binder).
  2. Free presets: every page, every N pages, or ranges such as 1-3, 5, 8- (up to 10 files per split). Pro presets: by bookmarks (level 1–3), by file size (e.g. 10 MB) or at blank separator pages, which are left out.
  3. The list shows the files you will get. File names use {name}_{range} by default (e.g. Report_1-3.pdf); with Pro you can write your own rule with {name} {n} {range} {from} {to} {pages} {bookmark} {date}. Existing files are never overwritten (Report (2).pdf).

Bookmarks and output options (Pro)

  1. Bookmarks: Keep moves the original bookmarks to the new page positions; One per file adds a bookmark for each merged file with its own bookmarks below it. When splitting, tick Bookmarks · Keep to carry the bookmarks of each part.
  2. Output options: compress (Light, Recommended, Strong – kept only if the file gets smaller), page numbers or header/footer text with {n} and {total}, watermark text, searchable text with Windows OCR (uses the OCR languages installed in Windows), and an open password (AES-256).
  3. You can choose every option for free and see it marked Pro; you are asked about Pro only when you save, and the job continues right after the purchase.

File Explorer, watch folder and command line

  1. File Explorer (free): select PDFs, right-click and choose Merge with PDF Binder or Split with PDF Binder. On Windows 11 these are under Show more options; Open with → PDF Binder also works. Files opened this way go to the window that is already open.
  2. Watch folder (Pro): in Automate, choose a folder to watch and a different folder for results, pick an action (split with the current split settings, apply output options, or merge files that arrive together) and start. It works while PDF Binder is open; originals are not changed.
  3. Command line (Pro): pdfbinder merge <files or folders> -o out.pdf [--bookmarks perfile], pdfbinder split in.pdf --bookmarks 1 | --size 10 | --blank | --every 2 | --ranges "1-3,5" [-o folder] [--name "{n} {bookmark}"], plus --compress, --numbers, --watermark, --ocr, --password. Run pdfbinder help for all options. Exit codes: 0 ok, 1 usage, 2 failed, 3 Pro required.

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

Which file formats are supported?

PDF, including password-protected PDFs (you enter the password). Pro also adds images (JPG, PNG, TIFF, HEIC…) as pages. Results are always saved as new files; originals are never changed.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

A PDF asks for a password.

Enter the password used to open the PDF. Files whose password you don’t know can’t be opened. The saved result has no password unless you set one in Output options (Pro).

A link inside the merged PDF does not jump anymore.

Web links and links that point to a page are kept and follow the page to its new position. A link to a page you removed has nowhere to go. Links that use named destinations from another file can stop working; bookmarks (Pro) are rebuilt and always point to the right page.

Searchable text (OCR) finds nothing or the wrong language.

PDF Binder uses the text recognition built into Windows and the OCR languages installed there. Add the language in Windows Settings → Time & language → Language & region (Optical character recognition). Pages that already contain text are skipped.

A file won’t open.

The file may be open in another app, damaged, or in an unsupported format. Close other apps that use it and try again. See the supported formats above.

The app can’t save or export.

The folder may be read-only or the disk may be full. Choose another folder, such as Documents. If Controlled folder access is on in Windows Security, allow this app.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
