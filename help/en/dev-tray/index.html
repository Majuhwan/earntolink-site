How-to

Format and validate JSON

  1. Select JSON in the sidebar and paste text into Input.
  2. Select Format or Minify.
  3. If the JSON is invalid, the line and column of the error are shown.
  4. Select Copy to copy the result.

Encode and decode Base64, URL, and HTML

  1. Select Base64, URL encode, or HTML in the sidebar.
  2. Select Encode or Decode, then paste text into Input.
  3. For Base64 used in URLs or tokens, turn on URL-safe.

Hash text and compare checksums

  1. Select Hash and type or paste text. MD5, SHA-1, SHA-256, and SHA-512 appear immediately.
  2. Paste an expected value into Compare with hash. The matching row is marked Match.
  3. Pro: turn on HMAC and enter a key to get HMAC-SHA256 and HMAC-SHA512.

Verify downloaded files (Pro)

  1. In Hash, select Hash files and choose one or more files. There is no size limit.
  2. Paste the checksum published by the download site into Compare with hash.

Read a JWT

  1. Select JWT and paste the token.
  2. The header and payload are shown. If the token has exp, the expiry time is shown.
  3. The signature is not verified.

Convert Unix timestamps

  1. Select Timestamp and enter seconds, milliseconds, or an ISO 8601 date. Now inserts the current time.
  2. Unix seconds, milliseconds, UTC, and local time are shown.

Generate UUIDs

  1. Select UUID, set the count (1–100) with − and +, then select Generate.
  2. Select Copy to copy the whole list.

Test regular expressions

  1. Select Regex, enter a pattern, and paste test text into Input.
  2. Matches and capture groups are listed with the match count.
  3. Pro: turn on Replace and enter a replacement such as $1 to preview the result. Multiline and dot-all options are also available.

Features

  • Base64, URL and HTML encode/decode

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

Invalid input is shown.

Check the line:column position next to the message. Common causes are trailing commas, single quotes, and comments, which JSON does not allow.

Base64 decoding shows hex bytes instead of text.

The decoded data is not UTF-8 text, such as an image or compressed data. The bytes are shown as hex so nothing is lost.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

How do I change the app language?

The app follows the Windows display language. Change it in Settings > Time & language > Language & region, then restart the app.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
