How-to

View PDFs and images

  1. Set Paperwise PDF as the default app, then double-click a file. Files opened while the app is running open in new tabs.
  2. Use the view menu for single page, two pages, reading mode, or presentation. Find lists every match with context.

Mark up, sign, and fill forms

  1. Use the markup toolbar for highlight, notes, shapes, ink, and text boxes.
  2. Select Sign to draw, type, or import a signature. Form fields can be filled from a profile saved on this PC.

Organize, merge, and convert

  1. Open the page thumbnails to reorder, rotate, delete, or insert pages and other PDFs.
  2. Tools such as OCR, redaction, compare, compress, password, and PDF to Word are in the Tools menu. Saving writes a verified copy first and keeps a backup of the previous version.

Convert PDF to Office and e-book formats

  1. Tools → Convert: choose PDF to Word, Excel, PowerPoint, text, HTML, EPUB or RTF, add files and press Convert. Tables become Excel cells and each page becomes an editable slide. The new file is saved next to the original.
  2. PDF to text is free without limits. The other formats convert the first 3 pages of each file for free; Pro converts whole documents. Scanned PDFs have no text: run OCR first.
  3. Office & text to PDF turns .docx, .xlsx, .csv and .txt into PDF with the built-in engine, no Microsoft Office needed. PowerPoint and older formats (.doc, .xls, .ppt) use Microsoft Office if it is installed.
  4. Flatten locks markups and form fields into the page. Page labels name pages i, ii, 1, 2… Bates numbering (Pro) stamps one running number across many files in list order.

Features

  • Opens PDFs and photos in about half a second, browse a whole folder of pictures with the arrow keys
  • Annotate, sign, fill forms with autofill, and edit existing PDF text directly
  • Convert PDF to Word, Excel, PowerPoint, text, HTML and EPUB, and Word or Excel to PDF without Office; OCR, redaction, compare, compress
  • Crop, resize, rotate, color-adjust and mark up pictures; convert to JPG, PNG, WebP, TIFF, PDF and more
  • Slideshow, animated GIF frames, info panel with camera data and GPS, scanner import
  • Safe saving: the original is replaced only after the new file is checked, with backup and restore

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

Which file formats are supported?

PDF; images: JPG, PNG, GIF, BMP, ICO, TIFF, WebP, SVG, PSD (HEIC, AVIF, JPEG XL, and RAW with the free Windows extensions); XPS and OXPS open as PDF copies. Office, HTML, and images can be converted to PDF; PDFs convert to Word, Excel, PowerPoint, text, HTML, EPUB, RTF, and images.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

HEIC, AVIF, or RAW photos don’t open.

Install the free HEIF Image Extensions, AV1 Video Extension, or Raw Image Extension from the Microsoft Store, then reopen the file.

A file won’t open.

The file may be open in another app, damaged, or in an unsupported format. Close other apps that use it and try again. See the supported formats above.

The app can’t save or export.

The folder may be read-only or the disk may be full. Choose another folder, such as Documents. If Controlled folder access is on in Windows Security, allow this app.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
