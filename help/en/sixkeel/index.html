How-to

Add an account

  1. On the website, turn on two-step verification with an authenticator app. The site shows a QR code and a key.
  2. In Sixkeel select Add. Choose Image file or Clipboard for a saved QR picture, Screen area to read the QR code shown on screen (Pro), Setup link for an otpauth:// link, or Enter key to type the key.
  3. Type the 6-digit code shown in Sixkeel on the website to finish.

Copy a code

  1. Select the code or the copy button. The ring shows the seconds left; the next code is shown below.
  2. The copied code is kept out of clipboard history and cloud clipboard, and is cleared after 30 seconds (Settings > Clear clipboard).

Lock with a password or Windows Hello

  1. Accounts are always encrypted on this PC for your Windows user. Settings > Set password adds a password that is needed to open the codes.
  2. With a password set, turn on Windows Hello (Pro) to unlock with face, fingerprint or PIN. Auto-lock locks after the chosen minutes and when Windows locks.

Back up and restore

  1. Backup > Export backup saves one .sixkeel file encrypted with a backup password (scrypt + AES-256-GCM). Keep it on a USB drive or another PC.
  2. Restore reads a .sixkeel file and adds the accounts that are not in the list yet. Automatic backups to a folder with versions are part of Pro.

Move from another authenticator app

  1. In the other app, export the accounts as a file (Aegis, 2FAS, andOTP) or as export QR codes.
  2. Import > Choose file (Pro) reads the file; encrypted files ask for their password. For export QR codes use Add > Image file or Screen area.

Features

  • Unlimited accounts, time-based and counter-based codes
  • Add from a QR picture, the clipboard, a setup link or a key
  • Encrypted on this PC, optional password, auto-lock
  • Copied codes stay out of clipboard history and are cleared
  • Encrypted backup and restore, no internet connection
  • Windows Hello, screen-area QR, import, folders, automatic backups (Pro)

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

The website rejects the code.

Time-based codes need the PC clock to be right. In Windows Settings > Time & language > Date & time, turn on Set time automatically and select Sync now. If the code is about to change, wait for the next one.

The QR code isn’t found.

Use a sharp image with the whole code visible, or select only the code with Screen area. If it still fails, use the key the website shows next to the QR code (Enter key).

I forgot the password.

The password can’t be recovered or reset; it is not stored anywhere. If Windows Hello is on, unlock with Windows Hello and set a new password. Otherwise restore a backup on a new vault.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

How do I change the app language?

The app follows the Windows display language. Change it in Settings > Time & language > Language & region, then restart the app.

Contact support doesn’t open my email app.

If no default email app is set, select Copy info and send the text to hello@earntolink.com from any email service.

Contact support

Email hello@earntolink.com with the app name and version. In the app, Help > Contact support adds this information automatically.
