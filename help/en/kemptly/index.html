How-to

Open a tool

  1. On Home, choose a category or type in the search box to find a tool.
  2. Drag files into the tool, adjust options, and run. Results go to Documents\Kemptly unless you choose another folder.

Free up disk space

  1. Use the space map, duplicates, similar photos, or large and old files to review what takes space.
  2. Selected files go to the Recycle Bin. The free version cleans 20 items a day.

Undo moves and renames

  1. Open History. Every move and rename is listed and can be undone.

Sort new downloads automatically

  1. In Folder rules, add a rule with a condition (name, type, size) and an action (move, rename, Recycle Bin).
  2. The free version keeps 3 rules.

Features

  • Clean up, dedupe and organize files, undo anytime
  • Compress, convert and edit images and photos
  • Merge, split, sign, OCR and redact PDFs
  • Convert and trim video, transcribe to subtitles
  • Search inside documents, find photos by face or words (Pro)
  • Workflows and watch folders, offline, no account (watch folders: Pro)

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

Files and input are processed only on this PC and are never uploaded. Some features download a model or component once, the first time you use them; after that they work offline. There are no accounts, ads, or tracking.

Which file formats are supported?

Images: JPG, PNG, WEBP, BMP, TIFF, GIF, ICO (HEIC and AVIF with the free Windows extensions). Documents: PDF; Word, Excel, and PowerPoint to PDF uses the installed Microsoft Office. Mail: EML, MBOX. Audio and video: common formats such as MP4, MOV, MKV, MP3, WAV, M4A.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

Word, Excel, or PowerPoint to PDF doesn’t work.

This conversion uses the Microsoft Office installed on the PC. Install the desktop version of Office and open it once, then try again.

A file won’t open.

The file may be open in another app, damaged, or in an unsupported format. Close other apps that use it and try again. See the supported formats above.

Processing is slow.

Large or many files take longer. Close other heavy apps, keep the laptop plugged in, and keep the PC from sleeping until the task finishes.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
