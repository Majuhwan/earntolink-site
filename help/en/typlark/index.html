How-to

Choose your keyboard

  1. Pick one of 42 keyboard layouts, or take the 1-minute test to get a recommended starting lesson.

Practice lessons

  1. Follow the on-screen keyboard and hands; the next key and finger are highlighted.
  2. Speed and accuracy update as you type. Earn stars for each lesson and keep a daily streak.

Take a timed test

  1. Choose 1, 3, or 5 minutes. After the test, the key error map shows which keys to practice.

Features

  • 38 languages, 42 layouts incl. Korean, Japanese, Chinese, Arabic, Hindi, Thai
  • Lessons from home row to numbers, symbols and accents
  • On-screen keyboard with next key, finger and hands guide
  • Live WPM, keystrokes or characters per minute and accuracy
  • Timed tests, placement test, key error map, daily goal and streak
  • Games, history charts, own text, code, profiles, certificates (Pro, 1 game free)

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

The keys I press don’t match the screen.

The layout chosen in the app must match the Windows keyboard in use. Switch the Windows input language (Win + Space) or choose the matching layout in the app. Japanese uses romaji input and Chinese uses pinyin.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

How do I change the app language?

The app follows the Windows display language. Change it in Settings > Time & language > Language & region, then restart the app.

Contact support doesn’t open my email app.

If no default email app is set, select Copy info and send the text to hello@earntolink.com from any email service.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.

Contact support

Email hello@earntolink.com with the app name and version. In the app, Help > Contact support adds this information automatically.
