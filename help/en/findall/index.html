How-to

Find files by name

  1. Choose the drives and folders to index once. New, renamed, and deleted files are reflected automatically.
  2. Type to see results instantly. Filter by type, size, or date, and use syntax such as ext:pdf, size:>100mb, dm:2025-06, "exact phrase", or !exclude.

Search from anywhere

  1. Press the global shortcut to open a small search window. The app can wait in the notification area.
  2. Use ↑ ↓ and Enter to open, Ctrl+Enter to show in folder, and Ctrl+Shift+C to copy the path.

Search inside files (Pro)

  1. Turn on content indexing for PDF, Word, Excel, PowerPoint, text, and code. The free version shows how many files contain the words.
  2. Pro shows the matching files with highlighted excerpts, text in images (OCR), photo search by description, and people.

Features

  • File names as you type: a million files in milliseconds, updated live
  • Filters, wildcards, regex, size and date; sort, preview and drag out
  • Global shortcut opens a small search box over any app
  • Search inside PDF, Word, Excel, PowerPoint, text and code (Pro)
  • Find photos by describing them or by the people in them (Pro)
  • Offline, no account, no administrator rights

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

Files and input are processed only on this PC and are never uploaded. Some features download a model or component once, the first time you use them; after that they work offline. There are no accounts, ads, or tracking.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

Troubleshooting

A file I know exists isn’t found.

Check that its drive or folder is included in the index settings. Network drives and folders Windows doesn’t let apps read are skipped.

Processing is slow.

Large or many files take longer. Close other heavy apps, keep the laptop plugged in, and keep the PC from sleeping until the task finishes.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

How do I change the app language?

The app follows the Windows display language. Change it in Settings > Time & language > Language & region, then restart the app.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
