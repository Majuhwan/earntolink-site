How-to

Start from Home

  1. Under New, choose Document, Spreadsheet or Presentation.
  2. Or pick a template: switch between Documents, Spreadsheets and Presentations above the gallery.
  3. Recent lists the files you opened last, of every type. Open… opens any supported file.

Work in tabs

  1. Each file opens in its own tab at the top; the icon color shows the type.
  2. Ctrl+Tab and Ctrl+Shift+Tab move between tabs and Home. Select × on a tab to close the file.
  3. Menus, toolbars and shortcuts inside a tab are those of the editor for that file type (the same as Folios, Spreadwell and Stagelit).

Open files from File Explorer

  1. Right-click a file, select Open with and choose Docfern. To make it the default, go to Settings > Apps > Default apps.
  2. You can also drag files onto Home. Each opens in the right editor.

Free and Pro

  1. Free includes everything the free versions of Folios, Spreadwell and Stagelit include.
  2. Pro is a one-time purchase on Home (Get Pro) and turns on the Pro features of all three editors.
  3. Pro bought in the separate Folios, Spreadwell or Stagelit apps is a different product and does not unlock Pro here (and the other way round).

Features

  • Documents, spreadsheets and presentations in tabs of one window
  • Opens and saves docx, xlsx and pptx; also opens doc, odt, rtf, HWPX, xls, csv, ods, ppt and odp
  • Home with new files, templates, themes and recent files of every type
  • Track changes, comments, tables with formulas, table of contents
  • Formula bar with function help, conditional formatting and charts
  • Magic move, presenter display and narration that plays in the slide show
  • PDF export for every file type
  • Free to use; Pro is a one-time purchase

FAQ

What is Pro?

Pro is a one-time add-on purchase in the Microsoft Store, not a subscription. It works on Windows PCs signed in with the same Microsoft account.

How do I get Pro back on another PC or after reinstalling?

Sign in to the Microsoft Store with the account used for the purchase, then select Help > Restore purchase.

How do I get a refund?

Payments and refunds are handled by Microsoft. Go to account.microsoft.com > Order history, select the order, and request a refund. Microsoft’s refund policy applies.

Does the app need the internet? Is my data sent anywhere?

No. Files and input are processed only on this PC and are never uploaded. There are no accounts, ads, or tracking. The internet is used only for Microsoft Store purchases and updates.

Which file formats are supported?

Documents – open: .docx .dotx .docm .doc .rtf .odt .hwpx .hwp .md .txt .html; save: .docx .dotx .rtf .md .html .txt; export PDF. Spreadsheets – open: .xlsx .xlsm .xls .csv .tsv .ods; save: .xlsx .csv; PDF. Presentations – open: .pptx .potx .ppsx .pptm .ppt .odp; save: .pptx; export PDF, images, MP4.

How do I update the app?

The Microsoft Store installs updates automatically. To check now, open Microsoft Store > Library and select Get updates.

A file won’t open.

The file may be open in another app, damaged, or in an unsupported format. Close other apps that use it and try again. See the supported formats above.

The app can’t save or export.

The folder may be read-only or the disk may be full. Choose another folder, such as Documents. If Controlled folder access is on in Windows Security, allow this app.

I bought Pro, but features are still locked.

Select Help > Restore purchase. Make sure the Microsoft Store is signed in with the account used for the purchase. Right after buying, confirmation can take a few minutes.

The app doesn’t start or stops responding.

Close and reopen the app. If it continues, go to Settings > Apps > Installed apps, open the app’s Advanced options, and select Repair. Reset also clears app settings.
