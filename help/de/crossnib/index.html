Anleitungen

Fadenkreuz gestalten

  1. Wählen Sie eine Form (Kreuz, T, Punkt, Kreis, Winkel, Dreieck, Quadrat, Bögen, Strahlen) und passen Sie Länge, Stärke, Abstand, Farbe, Drehung, Kontur, Ring und Mittelpunkt an.
  2. Prüfen Sie es auf dunklem, hellem und Beispielhintergrund und speichern Sie es als Vorgabe. Kostenlos 3 Vorgaben.

Aus 10.000 Fadenkreuzen wählen

  1. Öffnen Sie die Bibliothek. Grenzen Sie nach Kategorie, Farbe, Größe oder Form ein oder geben Sie einen Tag wie „grün kreis“ oder eine Nummer wie #1234 ein. Zufall wählt eines aus.
  2. Klicken Sie auf ein Fadenkreuz, um es sofort zu verwenden. Mit dem Stern landet es in den Favoriten; „Kopie bearbeiten“ öffnet es im Editor. Kostenlos sind #1–#500 (alle Kategorien), Pro schaltet alle 10.000 frei.

Codes und PNG

  1. Wählen Sie „Code importieren“ und fügen Sie einen Crossnib-Code, einen Fadenkreuz-Code aus Counter-Strike 2 (CSGO-…) oder einen Valorant-Profilcode (0;P;…) ein. Spielcodes sind Näherungen (für 1080p umgerechnet). Der Import ist kostenlos.
  2. „Code kopieren“ erzeugt einen Code, den andere importieren können. „Als PNG exportieren“ (Pro) speichert das Fadenkreuz als transparentes Bild in 1×, 2× oder 4×.

Im Spiel anzeigen

  1. Beim ersten Start ist das Overlay aus. Schalten Sie es auf der Seite „Fadenkreuz“ ein oder drücken Sie Strg + Alt + H. Es sitzt pixelgenau in der Mitte des gewählten Monitors.
  2. Fügen Sie Spiele zur Spieleliste hinzu, damit das Overlay nur bei diesen im Vordergrund erscheint.

Funktionen

  • 10.000 eingebaute Fadenkreuze in 11 Kategorien mit Filtern, Tag-Suche, Favoriten und Zufall (kostenlos: 500)
  • Klick-durchlässiges Fadenkreuz-Overlay über Spielen im Fenster- und randlosen Modus
  • Editor: Kreuz, T, Punkt, Kreis, Winkel, Dreieck, Quadrat, Bögen, Strahlen, Drehung, Kontur, Ring; PNG-Bild (Pro)
  • Freigabecodes, Import von Counter-Strike-2- und Valorant-Codes, PNG-Export (Pro)
  • Globale Tastenkürzel, Monitorwahl, Spieleliste, Vorlagen pro Spiel (Pro); Uhr, Systemwerte, Text- und Bild-Overlays (Pro)
  • Keine Injektion, keine Hooks, kein Speicherlesen; Infobereich-App, unter 1 % CPU

Häufige Fragen

Was ist Pro?

Pro ist ein einmaliger Add-on-Kauf im Microsoft Store, kein Abonnement. Es gilt auf Windows-PCs, die mit demselben Microsoft-Konto angemeldet sind.

Wie erhalte ich Pro auf einem anderen PC oder nach einer Neuinstallation zurück?

Melden Sie sich mit dem Kaufkonto im Microsoft Store an und wählen Sie dann Hilfe > Kauf wiederherstellen.

Wie erhalte ich eine Erstattung?

Zahlungen und Erstattungen wickelt Microsoft ab. Öffnen Sie account.microsoft.com > Bestellverlauf, wählen Sie die Bestellung und beantragen Sie eine Erstattung. Es gelten die Erstattungsrichtlinien von Microsoft.

Braucht die App Internet? Werden meine Daten gesendet?

Nein. Dateien und Eingaben werden nur auf diesem PC verarbeitet und nie hochgeladen. Keine Konten, Werbung oder Tracking. Das Internet wird nur für Käufe und Updates im Microsoft Store genutzt.

Wie aktualisiere ich die App?

Der Microsoft Store installiert Updates automatisch. Zum sofortigen Prüfen öffnen Sie Microsoft Store > Bibliothek und wählen Updates abrufen.

Problembehandlung

Das Fadenkreuz erscheint im Spiel nicht.

Exklusiver Vollbildmodus verdeckt Overlays. Stellen Sie das Spiel auf randloses Fenster oder Fenster-Vollbild. Manche Anti-Cheat-Systeme blockieren Overlays.

Ich habe Pro gekauft, aber die Funktionen sind gesperrt.

Wählen Sie Hilfe > Kauf wiederherstellen. Prüfen Sie, ob der Microsoft Store mit dem Kaufkonto angemeldet ist. Direkt nach dem Kauf kann die Bestätigung einige Minuten dauern.

Wie ändere ich die Sprache der App?

Die App verwendet die Windows-Anzeigesprache. Ändern Sie sie unter Einstellungen > Zeit und Sprache > Sprache und Region und starten Sie die App neu.

Support kontaktieren öffnet keine E-Mail-App.

Ist keine Standard-E-Mail-App festgelegt, wählen Sie Infos kopieren und senden Sie den Text mit einem beliebigen E-Mail-Dienst an hello@earntolink.com.

Die App startet nicht oder reagiert nicht mehr.

Schließen und öffnen Sie die App erneut. Wenn das Problem bleibt, öffnen Sie Einstellungen > Apps > Installierte Apps > Erweiterte Optionen der App und wählen Reparieren. Zurücksetzen löscht auch die App-Einstellungen.

Support kontaktieren

Senden Sie eine E-Mail mit App-Name und Version an hello@earntolink.com. In der App fügt Hilfe > Support kontaktieren diese Angaben automatisch hinzu.
