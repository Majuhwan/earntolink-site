Anleitungen

JSON formatieren und prüfen

  1. Wählen Sie in der Seitenleiste JSON und fügen Sie Text in die Eingabe ein.
  2. Wählen Sie Formatieren oder Minimieren.
  3. Ist das JSON ungültig, werden Zeile und Spalte des Fehlers angezeigt.
  4. Wählen Sie Kopieren, um das Ergebnis zu kopieren.

Base64, URL und HTML kodieren und dekodieren

  1. Wählen Sie in der Seitenleiste Base64, URL-Kodierung oder HTML.
  2. Wählen Sie Kodieren oder Dekodieren und fügen Sie Text in die Eingabe ein.
  3. Für Base64 in URLs oder Tokens aktivieren Sie URL-sicher.

Text hashen und Prüfsummen vergleichen

  1. Wählen Sie Hash und geben Sie Text ein. MD5, SHA-1, SHA-256 und SHA-512 erscheinen sofort.
  2. Fügen Sie den erwarteten Wert in „Mit Hash vergleichen“ ein. Die passende Zeile wird markiert.
  3. Pro: Aktivieren Sie HMAC und geben Sie einen Schlüssel ein, um HMAC-SHA256 und HMAC-SHA512 zu erhalten.

Heruntergeladene Dateien prüfen (Pro)

  1. Wählen Sie unter Hash „Dateien hashen“ und eine oder mehrere Dateien. Es gibt keine Größenbeschränkung.
  2. Fügen Sie die Prüfsumme der Download-Seite in „Mit Hash vergleichen“ ein.

JWT lesen

  1. Wählen Sie JWT und fügen Sie das Token ein.
  2. Header und Payload werden angezeigt. Enthält das Token exp, wird die Ablaufzeit angezeigt.
  3. Die Signatur wird nicht geprüft.

Unix-Zeitstempel umrechnen

  1. Wählen Sie Zeitstempel und geben Sie Sekunden, Millisekunden oder ein ISO-8601-Datum ein. Jetzt fügt die aktuelle Zeit ein.
  2. Unix-Sekunden, Millisekunden, UTC und Ortszeit werden angezeigt.

UUIDs erzeugen

  1. Wählen Sie UUID, legen Sie mit − und + die Anzahl (1–100) fest und wählen Sie Erzeugen.
  2. Kopieren kopiert die gesamte Liste.

Reguläre Ausdrücke testen

  1. Wählen Sie Regex, geben Sie ein Muster ein und fügen Sie Testtext in die Eingabe ein.
  2. Treffer und Gruppen werden mit der Trefferanzahl aufgelistet.
  3. Pro: Aktivieren Sie Ersetzen und geben Sie z. B. $1 ein, um das Ergebnis zu sehen. Mehrzeilig und Dot-All sind ebenfalls verfügbar.

Funktionen

  • JSON formatieren, minimieren und prüfen mit Fehlerposition
  • Base64, URL und HTML kodieren/dekodieren

Häufige Fragen

Was ist Pro?

Pro ist ein einmaliger Add-on-Kauf im Microsoft Store, kein Abonnement. Es gilt auf Windows-PCs, die mit demselben Microsoft-Konto angemeldet sind.

Wie erhalte ich Pro auf einem anderen PC oder nach einer Neuinstallation zurück?

Melden Sie sich mit dem Kaufkonto im Microsoft Store an und wählen Sie dann Hilfe > Kauf wiederherstellen.

Wie erhalte ich eine Erstattung?

Zahlungen und Erstattungen wickelt Microsoft ab. Öffnen Sie account.microsoft.com > Bestellverlauf, wählen Sie die Bestellung und beantragen Sie eine Erstattung. Es gelten die Erstattungsrichtlinien von Microsoft.

Braucht die App Internet? Werden meine Daten gesendet?

Nein. Dateien und Eingaben werden nur auf diesem PC verarbeitet und nie hochgeladen. Keine Konten, Werbung oder Tracking. Das Internet wird nur für Käufe und Updates im Microsoft Store genutzt.

Wie aktualisiere ich die App?

Der Microsoft Store installiert Updates automatisch. Zum sofortigen Prüfen öffnen Sie Microsoft Store > Bibliothek und wählen Updates abrufen.

Problembehandlung

„Ungültige Eingabe“ wird angezeigt.

Prüfen Sie die Position Zeile:Spalte neben der Meldung. Häufige Ursachen sind nachgestellte Kommas, einfache Anführungszeichen und Kommentare, die JSON nicht erlaubt.

Die Base64-Dekodierung zeigt Hex-Bytes statt Text.

Die dekodierten Daten sind kein UTF-8-Text, z. B. ein Bild oder komprimierte Daten. Die Bytes werden verlustfrei als Hex angezeigt.

Ich habe Pro gekauft, aber die Funktionen sind gesperrt.

Wählen Sie Hilfe > Kauf wiederherstellen. Prüfen Sie, ob der Microsoft Store mit dem Kaufkonto angemeldet ist. Direkt nach dem Kauf kann die Bestätigung einige Minuten dauern.

Wie ändere ich die Sprache der App?

Die App verwendet die Windows-Anzeigesprache. Ändern Sie sie unter Einstellungen > Zeit und Sprache > Sprache und Region und starten Sie die App neu.

Die App startet nicht oder reagiert nicht mehr.

Schließen und öffnen Sie die App erneut. Wenn das Problem bleibt, öffnen Sie Einstellungen > Apps > Installierte Apps > Erweiterte Optionen der App und wählen Reparieren. Zurücksetzen löscht auch die App-Einstellungen.
