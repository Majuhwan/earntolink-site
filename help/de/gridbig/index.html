Anleitungen

Große Datei öffnen

  1. Öffnen Sie eine Datei oder ziehen Sie sie ins Fenster. Trennzeichen, Kopfzeile, Spaltentypen und Codierung werden erkannt.
  2. Die ersten Zeilen erscheinen sofort, der Rest wird im Hintergrund mit Fortschritt und Abbrechen vorbereitet.

Sortieren, filtern, suchen

  1. Wählen Sie einen Spaltenkopf zum Sortieren oder fügen Sie einen Filter hinzu (enthält, gleich, größer/kleiner, leer, Regex).
  2. Mit Suchen durchsuchen Sie alle Spalten samt Trefferzahl. Spaltenstatistiken stehen im Seitenbereich.

Spalten bereinigen

  1. Mit Spaltenwerkzeugen teilen, verbinden, Leerzeichen entfernen, Groß-/Kleinschreibung oder Typ ändern, Lücken füllen, ersetzen oder per SQL eine Spalte hinzufügen.
  2. Jede Änderung lässt sich rückgängig machen und wiederholen.

Aktuelle Ansicht exportieren

  1. Wählen Sie Exportieren, Format und Codierung (für Excel UTF-8 mit BOM) und speichern Sie. Kostenlos bis 100.000 Zeilen.

Funktionen

  • CSV, Excel, Parquet und JSON ab 10 GB öffnen, ohne alles in den RAM
  • Trennzeichen, Typen und Kodierungen automatisch erkennen
  • Flüssiges virtuelles Raster für Millionen Zeilen, mit Rückgängig
  • Sortieren, Filter-Baukasten, Suchen & Ersetzen, Statistik
  • Teilen, zusammenführen, bereinigen, Duplikate, Pivot, SQL (Verknüpfen, Dateien teilen, Pivot und SQL: Pro)
  • Export nach CSV (jede Kodierung), Excel, Parquet und JSON (gratis: bis 100.000 Zeilen)

Häufige Fragen

Was ist Pro?

Pro ist ein einmaliger Add-on-Kauf im Microsoft Store, kein Abonnement. Es gilt auf Windows-PCs, die mit demselben Microsoft-Konto angemeldet sind.

Wie erhalte ich Pro auf einem anderen PC oder nach einer Neuinstallation zurück?

Melden Sie sich mit dem Kaufkonto im Microsoft Store an und wählen Sie dann Hilfe > Kauf wiederherstellen.

Wie erhalte ich eine Erstattung?

Zahlungen und Erstattungen wickelt Microsoft ab. Öffnen Sie account.microsoft.com > Bestellverlauf, wählen Sie die Bestellung und beantragen Sie eine Erstattung. Es gelten die Erstattungsrichtlinien von Microsoft.

Braucht die App Internet? Werden meine Daten gesendet?

Nein. Dateien und Eingaben werden nur auf diesem PC verarbeitet und nie hochgeladen. Keine Konten, Werbung oder Tracking. Das Internet wird nur für Käufe und Updates im Microsoft Store genutzt.

Welche Dateiformate werden unterstützt?

Öffnen: CSV, TSV, TXT, Excel (.xlsx), Parquet, JSON. Codierung wird erkannt (UTF-8/16, CP949/EUC-KR, Shift-JIS, GBK, Big5, Windows-1252). Export: CSV/TSV mit wählbarer Codierung, .xlsx, Parquet, JSON.

Wie aktualisiere ich die App?

Der Microsoft Store installiert Updates automatisch. Zum sofortigen Prüfen öffnen Sie Microsoft Store > Bibliothek und wählen Updates abrufen.

Problembehandlung

Der Text ist unleserlich.

Wählen Sie die Codierung im Codierungsmenü manuell, z. B. Windows-1252 für ältere westeuropäische Dateien.

Das Sortieren einer sehr großen Datei schlägt fehl.

Große Sortierungen brauchen temporären Speicher etwa in Datengröße. Schaffen Sie Platz auf dem Systemlaufwerk.

Speichern oder Exportieren schlägt fehl.

Der Ordner ist möglicherweise schreibgeschützt oder der Datenträger voll. Wählen Sie einen anderen Ordner, z. B. Dokumente. Ist in Windows-Sicherheit der überwachte Ordnerzugriff aktiv, lassen Sie diese App zu.

Ich habe Pro gekauft, aber die Funktionen sind gesperrt.

Wählen Sie Hilfe > Kauf wiederherstellen. Prüfen Sie, ob der Microsoft Store mit dem Kaufkonto angemeldet ist. Direkt nach dem Kauf kann die Bestätigung einige Minuten dauern.

Die App startet nicht oder reagiert nicht mehr.

Schließen und öffnen Sie die App erneut. Wenn das Problem bleibt, öffnen Sie Einstellungen > Apps > Installierte Apps > Erweiterte Optionen der App und wählen Reparieren. Zurücksetzen löscht auch die App-Einstellungen.
