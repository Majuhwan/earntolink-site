使用方式

匯入遊戲

  1. 自動尋找 Steam、Epic、GOG、EA app、Ubisoft Connect、Battle.net、Riot、Xbox 和 itch.io 的遊戲。僅讀取啟動器檔案，不會修改。
  2. 其他程式或模擬器 ROM 資料夾可手動新增。

尋找和啟動

  1. 搜尋、排序或依啟動器、類型、狀態、遊戲時數分組，然後選取「開始遊戲」。
  2. 透過每 5 秒檢查執行中的程式記錄遊戲時數，從不讀取遊戲記憶體。

功能

  • 一個遊戲庫集中 Steam、Epic Games、GOG、EA app、Ubisoft Connect、Battle.net、Riot、Xbox/Microsoft Store、itch.io
  • 無需登入：讀取啟動器本機檔案；可新增任意程式和模擬器 ROM 資料夾
  • 透過啟動器啟動；遊戲時間記錄並與 Steam 合併，不讀取記憶體
  • 狀態、評分、備註、標籤、最愛、搜尋、排序、自動分組、隨機選擇
  • 每款遊戲和磁碟的佔用空間，開啟資料夾，透過啟動器解除安裝
  • Pro：智慧收藏集、統計、支援手把的大螢幕、圖片編輯、備份匯出

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

遊戲庫、遊戲時數和備註僅儲存在此電腦上。如果開啟從 Steam 商店取得資訊，應用程式僅使用每款遊戲的 Steam ID 要求公開商店資訊，不使用帳戶。沒有廣告或追蹤。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

清單中缺少某個遊戲。

先開啟一次啟動器以更新本機遊戲庫，然後重新整理。不支援的啟動器中的遊戲可手動新增。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

「聯絡支援」無法開啟郵件應用程式。

如果沒有設定預設郵件應用程式，請選取「複製資訊」，並透過任何郵件服務傳送至 hello@earntolink.com。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
