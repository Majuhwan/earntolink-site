使用方式

隱藏相片中的人臉和個人資訊

  1. 新增相片。會自動找到人臉、電話號碼、電子郵件、卡號、帳號和證件號碼。
  2. 開啟或關閉方框、移動或繪製新方框。選擇模糊、馬賽克或純色塊後儲存。原始檔案不會被修改。

模糊影片中的人臉

  1. 開啟影片。人臉會跨影格追蹤；在時間軸上開關軌道並設定起訖時間。
  2. 繪製方框可追蹤其他物體。匯出保留原音訊的新 MP4；免費版限 1 分鐘以內的影片。

塗黑 PDF

  1. 開啟 PDF，檢查找到的個人資訊，並在頁面上拖曳以新增區域。
  2. 儲存。方框下的文字會從檔案中刪除並再次檢查，隱藏的內容無法被複製出來。

功能

  • 自動模糊相片中的人臉，並在影片中追蹤遮蔽
  • 尋找圖片中的電話、郵件、卡號和銀行帳號
  • 真正的 PDF 塗黑：從檔案中刪除文字並驗證結果
  • 影片時間軸：裁剪和分割軌跡、跟隨移動的框、嗶聲
  • 刪除 EXIF 和 GPS；資料夾批次處理和監看資料夾（批次和監看資料夾：Pro）
  • 含校驗值的稽核紀錄；離線，無需帳戶，不上傳（匯出 CSV：Pro）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

相片：JPG、PNG、WebP、HEIC（需 Windows 擴充功能）。影片：MP4、MOV 等 Windows 可播放的格式，輸出為 MP4。文件：PDF。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

未偵測到某張人臉或號碼。

較小、側臉或模糊的人臉以及手寫號碼可能被漏偵測。請務必檢查結果，並為遺漏處繪製方框。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

處理速度慢。

大型檔案或大量檔案需要更長時間。請關閉其他佔用資源的應用程式，筆電請接上電源，並在工作完成前避免電腦進入睡眠。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
