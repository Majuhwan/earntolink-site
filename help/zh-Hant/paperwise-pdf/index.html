使用方式

檢視 PDF 和影像

  1. 將 Paperwise PDF 設為預設應用程式後按兩下檔案。應用程式執行時開啟的檔案會在新索引標籤中開啟。
  2. 在檢視功能表中選擇單頁、雙頁、閱讀模式或簡報。尋找會列出所有相符項目及上下文。

標註、簽名和填寫表單

  1. 使用標註工具列進行醒目提示、附註、圖形、手寫和文字方塊。
  2. 選取「簽名」以手繪、輸入或匯入簽名。表單可使用本機儲存的設定檔自動填寫。

整理頁面、合併和轉換

  1. 開啟頁面縮圖以重新排序、旋轉、刪除或插入頁面和其他 PDF。
  2. OCR、塗黑、比較、壓縮、密碼、PDF 轉 Word 等工具位於「工具」功能表。儲存時會先寫入經驗證的副本並保留舊版本備份。

將 PDF 轉換為 Office 與電子書格式

  1. 在「工具 → 轉換」中選擇 PDF 轉 Word、Excel、PowerPoint、文字、HTML、EPUB 或 RTF，加入檔案後按「轉換」。表格會變成 Excel 儲存格，每頁會變成可編輯的投影片。新檔案會儲存在原始檔旁邊。
  2. PDF 轉文字免費且不限次數。其他格式每個檔案免費轉換前 3 頁，Pro 可轉換整份文件。掃描的 PDF 沒有文字，請先執行 OCR。
  3. 「Office 和文字轉 PDF」使用內建引擎將 .docx、.xlsx、.csv 和 .txt 轉為 PDF，不需要 Microsoft Office。PowerPoint 和舊格式（.doc、.xls、.ppt）在已安裝 Microsoft Office 時使用它。
  4. 平面化會將標註和表單欄位固定到頁面。頁碼標籤可將頁面命名為 i、ii、1、2……貝茨編號（Pro）會依清單順序為多個檔案加上連續編號。

功能

  • 約 0.5 秒開啟 PDF 與相片，以方向鍵瀏覽資料夾中的圖片
  • 註解、簽名、自動填入表單，直接編輯 PDF 中的文字
  • PDF 轉 Word、Excel、PowerPoint、文字、HTML、EPUB，不需 Office 將 Word 和 Excel 轉 PDF；OCR、塗黑、比較、壓縮
  • 裁剪、調整大小、旋轉、調色與標記圖片，轉換為 JPG、PNG、WebP、TIFF、PDF 等
  • 投影片放映、GIF 逐格、顯示相機資訊與 GPS 的資訊面板、掃描器匯入
  • 安全儲存：檢查新檔案後才取代原始檔案，支援備份與還原

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

PDF；影像：JPG、PNG、GIF、BMP、ICO、TIFF、WebP、SVG、PSD（HEIC、AVIF、JPEG XL、RAW 需免費 Windows 擴充功能）；XPS 和 OXPS 以 PDF 副本開啟。可將 Office、HTML 和影像轉為 PDF，並可將 PDF 轉為 Word、Excel、PowerPoint、文字、HTML、EPUB、RTF 和影像。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

HEIC、AVIF 或 RAW 相片無法開啟。

從 Microsoft Store 安裝免費的 HEIF 影像擴充功能、AV1 視訊擴充功能或 Raw 影像擴充功能，然後重新開啟檔案。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
