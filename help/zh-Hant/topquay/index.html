使用方式

使用瀏海

  1. 選取「顯示瀏海」。螢幕頂端中央會出現小列，按一下會直接傳到下方的視窗。
  2. 將指標移到列上即可展開：正在播放的媒體及控制、計時器和碼錶、電池。移開即收合。
  3. 關閉設定視窗後瀏海會繼續執行。可從通知區域圖示再次開啟設定。

媒體控制

  1. 支援 Windows 媒體控制的應用程式（音樂播放器、瀏覽器、影片應用程式）會顯示標題、演出者、封面和進度。
  2. 在展開的瀏海中使用上一首、播放/暫停和下一首。

大小、位置與色彩

  1. 在「外觀」中變更大小並左右移動瀏海（例如對準筆電相機）。
  2. 色彩主題、大尺寸、其他顯示器、剪貼簿與 CPU/記憶體小工具以及番茄鐘屬於 Pro。

功能

  • 螢幕頂端細列，收合時按一下穿透
  • 含封面與上一首/播放/下一首的播放資訊
  • 含快速開始與提醒的計時器，含計圈的碼錶
  • 電池電量與剩餘時間，日期與時間
  • 全螢幕應用程式時隱藏，位置可調，依顯示器縮放
  • 色彩主題、剪貼簿與 CPU/記憶體小工具、番茄鐘、其他顯示器（Pro）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

瀏海消失了。

當該顯示器上執行全螢幕遊戲、影片或簡報時，瀏海會隱藏，結束後恢復。若要保持顯示，請關閉「設定 > 全螢幕應用程式執行時隱藏」。獨佔全螢幕遊戲一律會遮住瀏海。

不顯示媒體。

只顯示向 Windows 媒體控制回報資訊的應用程式（與 Windows 音量飛出視窗相同）。在應用程式中開始播放後，將指標移到瀏海上。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

「聯絡支援」無法開啟郵件應用程式。

如果沒有設定預設郵件應用程式，請選取「複製資訊」，並透過任何郵件服務傳送至 hello@earntolink.com。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
