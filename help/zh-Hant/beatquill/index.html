使用方式

開始創作歌曲

  1. 選擇風格範本或示範歌曲，或從空白開始。
  2. 從瀏覽器將循環拖到軌道上，它們會始終跟隨歌曲的速度和調性播放。

錄製音訊或 MIDI

  1. 將軌道設為錄音準備，選擇輸入並按「錄音」。先播放預備拍；循環錄音會保留每次錄製。

混音和匯出

  1. 在混音器中設定音量、聲像和傳送，並為每個軌道新增效果。
  2. 選取「匯出」，選擇 WAV、MP3 或 MIDI。

功能

  • CC0 錄音的 47 種取樣樂器、12 種合成引擎、8 種曲風的 1,008 個循環
  • 一起演奏的鼓手：8 種曲風 × 3 種方式，複雜度與力度觸控板，加花，跟隨貝斯
  • 含場景的現場循環、歌曲編排、鋼琴捲簾、步進音序器和可列印的樂譜檢視
  • 錄音片段與合成、淡入淡出、時間伸縮、節拍對齊和音高校正
  • 8 種吉他和貝斯音箱、14 種踏板、調音器、28 種效果、響度表、VST3 和 CLAP
  • 匯出 WAV、MP3、M4A、FLAC、分軌、MIDI 和 DAWproject；獨佔模式低延遲

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

匯入：WAV、MP3、FLAC 等常見音訊及 MIDI。匯出：WAV、MP3、MIDI；FLAC、M4A、分軌和 DAWproject 需 Pro。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

錄音有延遲或爆音。

在音訊設定中選擇音訊介面並調整緩衝區大小：減小可降低延遲，有爆音則增大。關閉其他音訊應用程式。

沒有聲音。

在 Windows 音效設定和音量混音程式中檢查輸出裝置和音量。如果其他應用程式獨佔使用音訊裝置，請關閉該應用程式。

麥克風無法使用。

在「設定」>「隱私權與安全性」>「麥克風」中，開啟「麥克風存取」和「允許桌面應用程式存取您的麥克風」。然後在應用程式中選取正確的輸入裝置。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
