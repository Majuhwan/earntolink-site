使用方式

剪掉靜音

  1. 開啟錄製檔案。會自動找到靜音。
  2. 選擇預設（緊湊、一般、寬鬆）或設定臨界值、最短靜音和前後留白。節省的時間會立即更新。

檢查和調整剪輯

  1. 播放預覽時會跳過剪掉的部分。J/K/L 播放，C 剪下或保留，I/O/X 剪下範圍。
  2. Pro：還可尋找 9 種語言的贅詞（嗯、呃）。語音辨識在本機進行。

匯出

  1. 選取「匯出」，選擇 MP4、僅音訊或 SRT 字幕。免費版最多 15 分鐘的檔案。
  2. Pro：匯出 Final Cut Pro、DaVinci Resolve (FCPXML)、Premiere Pro (XML) 或 EDL 剪輯清單，並批次處理多個錄製。

功能

  • 立即找到靜音，用本機語音辨識找到贅詞（贅詞：Pro）
  • 波形時間軸：保留、剪切、調整、手動新增，復原重做
  • 跳過剪切處的預覽，J/K/L 鍵盤編輯
  • 匯出 MP4（逐格精確或智慧剪切）、音訊和 SRT 字幕（免費：15 分鐘以內的檔案）
  • Final Cut、DaVinci Resolve、Premiere Pro 和 EDL 剪輯清單（Pro）
  • 批次處理，離線，無需帳戶，Pro 一次買斷（批次處理：Pro）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

檔案和輸入內容僅在此電腦上處理，不會上傳。部分功能首次使用時會下載一次模型或元件，之後可離線使用。沒有帳戶、廣告或追蹤。

支援哪些檔案格式？

開啟：MP4、MOV、MKV、MP3、WAV、M4A 等 Windows 可播放的影音。匯出：MP4、M4A、MP3、WAV、FLAC、SRT，FCPXML、Premiere XML、EDL 需 Pro。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

預覽沒有畫面。

預覽使用 Windows Media Foundation。HEVC 等部分轉碼器需要 Microsoft Store 中的擴充功能。匯出不受影響。

預覽卡頓或畫面異常。

從電腦或顯示卡製造商處將顯示卡驅動程式更新至最新版本。筆電請連接電源變壓器，並將電源模式設為「最佳效能」。

處理速度慢。

大型檔案或大量檔案需要更長時間。請關閉其他佔用資源的應用程式，筆電請接上電源，並在工作完成前避免電腦進入睡眠。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
