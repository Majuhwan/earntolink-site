使用方式

開啟郵件封存

  1. 開啟 PST、OST、MBOX 或 EML 檔案，或將其拖入視窗。會顯示原始資料夾樹狀結構和郵件數量。

搜尋郵件

  1. 在搜尋方塊中輸入，可搜尋主旨、連絡人、內文和附件名稱。
  2. 依日期範圍、寄件者或有附件篩選，並依日期、寄件者、主旨或大小排序。

匯出郵件和附件

  1. 選取郵件、資料夾或搜尋結果，然後匯出為 EML、MBOX、PDF 或 CSV。
  2. 免費版一次最多匯出 50 封。Pro 可無限匯出、批次產生 PDF，並依資料夾結構擷取所有附件。

功能

  • 不需 Outlook 開啟 PST/OST、MBOX、EML 封存檔（唯讀）
  • 快速全文搜尋主旨、聯絡人、內文與附件名稱
  • 虛擬清單，10 萬封以上的封存檔也流暢
  • 安全 HTML 檢視：封鎖指令碼與遠端圖片，完全離線
  • 匯出為 EML、MBOX、PDF（內嵌附件）與 CSV（免費：每次 50 封；批次 PDF：Pro）
  • 檢視聯絡人與行事曆，匯出 vCard、iCalendar（免費：每次 50 個）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

開啟：Outlook PST 和 OST（ANSI 和 Unicode）、EML、MBOX、vCard、iCalendar。不支援 Outlook 2013 及更新版本的 OST 快取，請先在 Outlook 中另存為 PST。匯出：EML、MBOX、PDF、CSV、vCard、iCalendar。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

OST 檔案無法開啟。

尚不支援 Outlook 2013 及更新版本的 OST 快取格式，也無法讀取 Exchange 加密的 OST。請在 Outlook 中將信箱匯出為 PST 後開啟。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
