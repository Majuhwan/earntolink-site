使用方式

使用掃描器掃描

  1. 開啟「掃描器」並選擇裝置。會列出有 WIA 驅動程式的掃描器；網路掃描器需先在「設定 > 藍牙與裝置 > 印表機與掃描器」新增。
  2. 選擇平台或進紙器（雙面進紙器可選雙面）、解析度和色彩模式，然後選擇「掃描」。再次掃描可新增頁面；600 dpi 以上需 Pro。
  3. 開啟「掃描後列印」即可把掃描器和印表機當作影印機使用。

手機相片和相機

  1. 將相片拖入視窗或選擇「匯入」。「相機」使用網路攝影機拍照。
  2. 會自動找到頁面邊緣並拉直。在「裁剪」中拖曳角點調整；「自動」重新尋找邊緣，「整張圖片」使用整張相片。
  3. 選擇彩色、灰階、黑白或原圖。彩色會去除陰影並使紙張變白。

儲存 PDF

  1. 整理頁面（上移/下移、旋轉、刪除），選擇格式、紙張大小和檔案大小，然後選擇「儲存」。所有頁面合成一個 PDF。
  2. Pro：可搜尋 PDF 加入不可見文字層（Windows OCR），可搜尋和複製；「密碼」保護 PDF；「刪除空白頁」和「依空白頁分割」整理進紙器批次掃描。

從頁面複製文字

  1. 選擇頁面並選擇「複製文字」。使用 Windows 中安裝的 OCR 語言在本機辨識；可在「設定」中選擇語言或保持「自動」。

匯入資料夾（Pro）

  1. 開啟「資料夾匯入」，選擇資料夾並選擇「新增到文件」。圖片依名稱順序新增，並自動尋找頁面邊緣。

功能

  • WIA 掃描器：平台、進紙器、雙面
  • 手機相片：自動尋找邊緣並校正透視
  • 無陰影的彩色、灰階和黑白頁面
  • 多頁 PDF、JPG、PNG、TIFF 和列印（免費）
  • Windows OCR 可搜尋 PDF、刪除空白頁（Pro）
  • 離線、不需帳戶、一次購買 Pro

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

清單中沒有我的掃描器。

Platenwise 使用 Windows 內建的掃描介面（WIA）。請安裝掃描器廠商的驅動程式，確認「Windows 掃描」或「Windows 傳真和掃描」能辨識後選擇「重新整理」。網路掃描器需先在「設定 > 藍牙與裝置 > 印表機與掃描器」新增。

頁面邊緣不正確。

當頁面放在較深色的表面上且四個角都可見時辨識效果最好。可在「裁剪」中將各角拖曳到頁面角上，或選擇「整張圖片」。

無法辨識文字或辨識為錯誤的語言。

辨識使用 Windows 中安裝的 OCR 語言。請在「設定 > 時間與語言 > 語言與地區」新增該語言（含光學字元辨識），然後在 Platenwise 設定的「OCR 語言」中選擇它。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

「聯絡支援」無法開啟郵件應用程式。

如果沒有設定預設郵件應用程式，請選取「複製資訊」，並透過任何郵件服務傳送至 hello@earntolink.com。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
