使用方式

開始繪畫

  1. 建立畫布，從筆刷庫中選擇筆刷並繪畫。筆壓和傾斜透過 Windows Ink 運作。
  2. 畫完一筆後停住可變為直線或圓。使用防手震使線條更平滑。

筆刷、素材與字型

  1. 從功能表列的「素材庫」或筆刷清單下方的素材庫按鈕開啟。依類別瀏覽 10,308 種筆刷，可搜尋、篩選（紋理、濕邊、壓力等）並收藏，最近使用的筆刷也會保留。免費版包含每個類別共 300 種筆刷。
  2. 素材（網點、圖案、日式紋樣、背景、紙張、效果線、邊框、對話框、形狀）依畫布解析度產生並作為新圖層插入：選取後按「作為圖層插入」或連按兩下。500 個免費，全部 5,020 個需 Pro。
  3. 字型：來自 Google Fonts 集合的 2,027 款免費字型家族（SIL 開放字型授權或 Apache 2.0），包含中文、日文和韓文。下載所需字型（僅此時需要網路）後儲存在應用程式資料夾中，並出現在文字工具裡。字型在免費版和 Pro 中都免費。

使用圖層

  1. 新增圖層，設定混合模式，並使用剪裁遮色片、圖層遮色片或鎖定透明像素。免費版 15 個圖層。

儲存和匯出

  1. 儲存為專案以保留圖層，然後匯出 PNG、JPG、WebP 或列印。可重播縮時攝影查看繪製過程。

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

匯出：PNG、JPG、WebP；PSD、OpenRaster、TIFF 和 PDF 需 Pro。筆刷：匯入 MyPaint (.myb) 和 GIMP (.gbr, .gih) 筆刷需 Pro。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

筆壓沒有作用。

請確認繪圖板驅動程式已啟用 Windows Ink，然後重新啟動應用程式。並檢查所選筆刷是否將筆壓用於大小或不透明度。

預覽卡頓或畫面異常。

從電腦或顯示卡製造商處將顯示卡驅動程式更新至最新版本。筆電請連接電源變壓器，並將電源模式設為「最佳效能」。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
