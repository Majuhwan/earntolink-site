使用方式

擷取螢幕畫面

  1. 按擷取快速鍵，或選擇區域、視窗、使用中視窗或全螢幕模式。
  2. 在區域模式下，按一下可貼齊視窗、面板或按鈕，拖曳可自行選取。放大鏡可協助精確定位邊緣。

標註擷取畫面

  1. 使用箭頭、圖形、螢光筆、文字、編號步驟、模糊或聚光燈。復原和重做不限次數。
  2. 複製、儲存或拖曳到其他應用程式中。

複製螢幕上的文字

  1. 選取「複製文字」並拖曳選取區域。使用 Windows 文字辨識離線讀取，也能讀取 QR 碼。免費版每天 10 次。

功能

  • 區域、視窗、全螢幕與捲動截圖,附放大鏡與視窗/元素自動貼齊（捲動：Pro）
  • 箭頭、文字、編號步驟、螢光筆、模糊與馬賽克、聚光燈與放大鏡標註（步驟與樣式預設：Pro）
  • 以離線 Windows OCR 複製螢幕上任何文字,也能讀取 QR 碼（免費：每天 10 次）
  • 可搜尋的圖庫:連同標註重新開啟,依文字、標題或標籤尋找
  • 儲存為 PNG、JPG、WEBP 或 PDF,複製為圖片或檔案,拖到任何應用程式
  • 全域快速鍵、常駐系統匣、支援多螢幕與高 DPI — 不需帳戶,完全離線

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

儲存：PNG、JPG、WEBP、PDF。匯入：影像檔案或剪貼簿。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

按 Print Screen 鍵會開啟其他工具。

在 Windows「設定」>「協助工具」>「鍵盤」中關閉「使用 Print Screen 鍵開啟螢幕擷取」，然後在本應用程式中啟用 Print Screen。

擷取畫面部分區域為黑色。

部分應用程式（如受保護的影片播放器）會阻止擷取，這些區域無法擷取。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
