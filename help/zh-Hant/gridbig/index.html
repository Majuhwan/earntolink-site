使用方式

開啟大型檔案

  1. 開啟檔案或將其拖入視窗。會自動偵測分隔符號、標題列、欄類型和編碼。
  2. 前幾列立即顯示，其餘部分在背景準備，可查看進度並取消。

排序、篩選和尋找

  1. 選取欄標題進行排序或新增篩選（包含、等於、大於/小於、空白、規則運算式）。
  2. 使用「尋找」搜尋所有欄並顯示相符數。欄統計資訊顯示在側邊窗格中。

整理欄

  1. 使用欄工具分割、合併、移除空格、變更大小寫或類型、填入空白、取代，或用 SQL 運算式新增欄。
  2. 所有變更都可復原和重做。

匯出目前檢視

  1. 選取「匯出」，選擇格式和編碼（用於 Excel 選 UTF-8 BOM）後儲存。免費版最多 10 萬列。

功能

  • 開啟 10 GB 以上的 CSV、Excel、Parquet、JSON，不需全部載入記憶體
  • 自動偵測分隔符號、類型和編碼（含 Big5、GBK、Shift-JIS）
  • 數百萬列流暢捲動的虛擬表格，可編輯可復原
  • 排序、篩選、尋找與取代、欄統計
  • 分割、合併、清理、去除重複、樞紐、連接和 SQL（連接、分割檔案、樞紐和 SQL：Pro）
  • 匯出為 CSV（可選編碼）、Excel、Parquet、JSON（免費：最多 10 萬列）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

開啟：CSV、TSV、TXT、Excel (.xlsx)、Parquet、JSON。自動偵測編碼（UTF-8/16、CP949/EUC-KR、Shift-JIS、GBK、Big5、Windows-1252）。匯出：可選編碼的 CSV/TSV、.xlsx、Parquet、JSON。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

文字顯示亂碼。

從編碼選單手動選擇，例如繁體中文選 Big5，日文選 Shift-JIS。

超大型檔案排序失敗。

大型排序需要與資料大小相當的暫存磁碟空間。請釋放系統磁碟空間後重試。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
