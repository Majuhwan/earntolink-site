使用方式

錄製螢幕

  1. 選擇全螢幕、視窗或拖曳選取區域，並選擇系統聲音和麥克風。
  2. 開始錄製。隨時按 Ctrl+Shift+F9 停止。免費版最多 5 分鐘。

編輯縮放

  1. 在按一下或輸入的位置會自動新增縮放。在時間軸上新增、刪除、移動或拉伸。
  2. 設定背景、邊距、圓角和陰影，並修剪開頭和結尾。

匯出影片

  1. 選取「匯出」，選擇長寬比和解析度後儲存為 MP4。可用時使用顯示卡編碼器。

功能

  • 跟隨點擊和輸入平滑自動放大
  • 可編輯的縮放時間軸：倍數、時間、緩動、焦點
  • 更大更順滑的游標、點擊波紋和快速鍵提示
  • 背景、邊距、圓角、陰影和攝影機泡泡（自訂背景和網路攝影機：Pro）
  • 螢幕、電腦聲音、麥克風、攝影機分軌錄製（網路攝影機：Pro）
  • 匯出 MP4（最高 4K 60fps）或 GIF，離線，Pro 一次買斷（高於 1080p 30 fps 和 GIF：Pro）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

匯出：MP4（1080p；1440p、4K 和 60 fps 需 Pro）和 GIF (Pro)。背景圖片：PNG、JPG。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

錄製沒有聲音。

請確認錄製前已開啟系統聲音和麥克風並選擇了正確裝置。還需在 Windows 隱私權設定中允許麥克風存取。

預覽卡頓或畫面異常。

從電腦或顯示卡製造商處將顯示卡驅動程式更新至最新版本。筆電請連接電源變壓器，並將電源模式設為「最佳效能」。

無法儲存或匯出。

資料夾可能為唯讀，或磁碟空間不足。請選擇其他資料夾，例如「文件」。如果在 Windows 安全性中開啟了「受控資料夾存取權」，請允許此應用程式。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。
