使用方式

儲存網站上的食譜

  1. 在瀏覽器中複製食譜頁面的網址。
  2. 在「匯入」中將其貼到「網址」並選取「下載頁面」。僅下載該頁面及其食譜相片。
  3. 檢查標題、食材和步驟，然後選取「儲存」。來源網址會與食譜一起保存。

變更份數和單位

  1. 開啟食譜，使用「份數」旁的 + 和 −。用量會重新計算，適合時以分數顯示（1 1/2 杯）。
  2. 「單位」可在原始單位、公制（ml、g）和美制（杯、oz）之間切換。湯匙和茶匙保持不變。

烹調模式

  1. 烹調模式以大字逐步顯示步驟，旁邊列出食材。開啟期間螢幕保持開啟。
  2. 使用 ← 和 →（或「上一步」和「下一步」）。步驟中提到時間時，可用「計時器」按鈕倒數。

購物清單與餐點規劃

  1. 「新增到購物清單」會依目前份數將食譜食材加入清單。相同食材會合併，並依商店區域分組。
  2. 使用 Pro 可在「餐點規劃」中安排一週，然後選取「本週食材加入購物清單」一次新增。

列印、PDF 和其他應用程式的檔案

  1. 食譜的「…」功能表中有「列印」和「匯出 PDF」。購物清單可列印或複製為文字。
  2. 「匯入 > 從檔案」可讀取 JSON（schema.org）檔案；Paprika 與 MealMaster 檔案、多個網址一次匯入、匯出為 Paprika/MealMaster 以及食譜 PDF 屬於 Pro。

功能

  • 無廣告儲存網頁食譜（schema.org 食譜資料）
  • 調整份數與換算單位（公制、美制）
  • 大字步驟、計時器、螢幕常亮的烹調模式
  • 依商店區域合併食材的購物清單
  • 依現有食材搜尋、標籤、評分、列印與 PDF
  • 每週餐點規劃、食譜 PDF、批次匯入（Pro）

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

應用程式會使用網路嗎？

僅在選取「下載頁面」時下載該頁面及其食譜相片。食譜、相片、餐點規劃和購物清單只保存在本機，絕不上傳。沒有帳戶、廣告或追蹤；購買和更新由 Microsoft Store 處理。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

無法匯入某個網站。

有些網站會封鎖應用程式下載，或頁面中沒有食譜資料。請在瀏覽器中選取並複製食譜文字，貼到「貼上文字或 HTML」，Ladlewise 會將其分為食材和步驟。

杯的用量看起來不一樣。

各國的杯不同：韓國和日本食譜為 200 ml，德國、法國和義大利通常為 250 ml，美國為 236.6 ml。Ladlewise 會依食譜中使用的詞分別換算。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

「聯絡支援」無法開啟郵件應用程式。

如果沒有設定預設郵件應用程式，請選取「複製資訊」，並透過任何郵件服務傳送至 hello@earntolink.com。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
