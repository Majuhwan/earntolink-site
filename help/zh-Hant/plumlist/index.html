使用方式

快速新增工作

  1. 在快速輸入方塊中輸入。可辨識「明天下午3點」等日期和時間。
  2. 設定提醒或重複，拖曳工作可重新排序或移至其他專案。

使用智慧清單

  1. 「今天」「即將到來」等智慧清單依日期、標籤或專案彙整工作。免費版可有 3 個智慧清單。

使用鍵盤

  1. 按 Ctrl+Shift+P 開啟命令選擇區，按 Ctrl+/ 查看快速鍵清單。

功能

  • 今天、今晚、預定、隨時、某天、日誌
  • 開始日期與截止日期分開
  • Windows 排程通知，應用程式關閉時也會顯示
  • 在通知中完成或稍後提醒
  • 10 種語言的自然語言快速輸入（可移除的辨識標籤）
  • 全域快速鍵快速輸入（Ctrl+Alt+Space）
  • 領域、具進度的專案、標題與檢查清單
  • 重複：每天、工作日、每週、每月依日期或星期、自訂規則、完成後
  • 子標籤與智慧型清單
  • 週計畫拖放安排（Pro）
  • 每週回顧（Pro）
  • 顯示 .ics 檔案與訂閱的行事曆事件
  • 專注計時器
  • 所有命令皆有快速鍵，命令面板
  • 無限復原，每日自動備份
  • 匯入匯出：iCalendar、CSV、todo.txt、Markdown、JSON；列印為 PDF
  • 深色模式與主題色彩
  • 無帳戶、無同步、無廣告

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

不需要。檔案和輸入內容僅在此電腦上處理，不會上傳。沒有帳戶、廣告或追蹤。僅在 Microsoft Store 購買和更新時使用網路。

支援哪些檔案格式？

匯入和匯出：iCalendar (.ics)、CSV、JSON、Markdown 及用於列印的 PDF。依位址訂閱行事曆需 Pro。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

提醒沒有出現。

提醒需要應用程式至少在通知區域中執行。請在「設定」>「系統」>「通知」中確認 Plumlist 的通知已開啟，且「勿擾」已關閉。

檔案無法開啟。

檔案可能正被其他應用程式使用、已損毀或格式不受支援。關閉正在使用該檔案的應用程式後重試。支援的格式請見上方問題。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

如何變更應用程式語言？

應用程式會跟隨 Windows 顯示語言。在「設定」>「時間與語言」>「語言與地區」中變更，然後重新啟動應用程式。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
