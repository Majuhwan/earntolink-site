使用方式

在任意應用程式中聽寫

  1. 將游標放在要輸入文字的位置。按住 Ctrl + Win 說話，然後放開。
  2. 免持聽寫請按 Ctrl + Win + Space，停頓後自動結束。按 Esc 取消。

使用語音命令

  1. 說「換行」「新段落」「逗號」「句號」「問號」等。

選擇語言和模型

  1. 在「設定」中將語言設為自動偵測或固定語言，並選擇模型。模型越大越準確但越慢，首次使用時下載一次。

功能

  • 任何應用程式：按住快速鍵說話，放開即輸入
  • 免持模式，停頓後自動結束
  • 99 種語言離線 Whisper 語音辨識
  • 換行與標點的語音命令
  • 個人詞典、取代規則、依應用程式設定（Pro）
  • 可搜尋歷史、系統匣應用、隨 Windows 啟動

常見問題

什麼是 Pro？

Pro 是在 Microsoft Store 中一次性購買的附加元件，不是訂閱。可在使用同一 Microsoft 帳戶登入的 Windows 電腦上使用。

如何在其他電腦上或重新安裝後還原 Pro？

使用購買時的帳戶登入 Microsoft Store，然後選取「說明」>「還原購買」。

如何申請退款？

付款和退款由 Microsoft 處理。前往 account.microsoft.com >「訂單記錄」，選取訂單並申請退款。適用 Microsoft 退款政策。

需要連線嗎？我的資料會被傳送嗎？

檔案和輸入內容僅在此電腦上處理，不會上傳。部分功能首次使用時會下載一次模型或元件，之後可離線使用。沒有帳戶、廣告或追蹤。

如何更新應用程式？

Microsoft Store 會自動安裝更新。若要立即檢查，請開啟 Microsoft Store >「媒體櫃」，然後選取「取得更新」。

疑難排解

文字沒有輸入到應用程式中。

部分應用程式禁止貼上或以系統管理員身分執行。在「設定」中切換貼上與鍵入方式，或依應用程式分別設定。

麥克風無法使用。

在「設定」>「隱私權與安全性」>「麥克風」中，開啟「麥克風存取」和「允許桌面應用程式存取您的麥克風」。然後在應用程式中選取正確的輸入裝置。

處理速度慢。

大型檔案或大量檔案需要更長時間。請關閉其他佔用資源的應用程式，筆電請接上電源，並在工作完成前避免電腦進入睡眠。

已購買 Pro，但功能仍被鎖定。

選取「說明」>「還原購買」。請確認 Microsoft Store 已使用購買時的帳戶登入。剛購買後，確認可能需要幾分鐘。

應用程式無法啟動或沒有回應。

關閉並重新開啟應用程式。如果問題仍存在，請前往「設定」>「應用程式」>「已安裝的應用程式」，開啟此應用程式的「進階選項」並選取「修復」。「重設」也會清除應用程式設定。

聯絡支援

請傳送郵件至 hello@earntolink.com，並註明應用程式名稱和版本。在應用程式中使用「說明」>「聯絡支援」會自動填入這些資訊。
