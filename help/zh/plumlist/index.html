使用方法

快速添加任务

  1. 在快速输入框中输入。可识别“明天下午3点”等日期和时间。
  2. 设置提醒或重复，拖动任务可重新排序或移至其他项目。

使用智能列表

  1. “今天”“即将到来”等智能列表按日期、标签或项目汇集任务。免费版可有 3 个智能列表。

使用键盘

  1. 按 Ctrl+Shift+P 打开命令面板，按 Ctrl+/ 查看快捷键列表。

功能

  • 今天、今晚、计划、随时、某天、日志
  • 开始日期与截止日期分开
  • Windows 定时通知，应用关闭时也会显示
  • 在通知中完成或稍后提醒
  • 10 种语言的自然语言快速输入（可删除的识别标签）
  • 全局快捷键快速输入（Ctrl+Alt+Space）
  • 领域、带进度的项目、标题和清单
  • 重复：每天、工作日、每周、每月按日期或星期、自定义规则、完成后
  • 子标签与智能列表
  • 周计划拖放安排（Pro）
  • 每周回顾（Pro）
  • 显示 .ics 文件与订阅的日历事件
  • 专注计时器
  • 所有命令均有快捷键，命令面板
  • 无限撤销，每日自动备份
  • 导入导出：iCalendar、CSV、todo.txt、Markdown、JSON；打印为 PDF
  • 深色模式与主题颜色
  • 无账户、无同步、无广告

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

导入和导出：iCalendar (.ics)、CSV、JSON、Markdown 及用于打印的 PDF。按地址订阅日历需 Pro。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

提醒没有出现。

提醒需要应用至少在通知区域中运行。请在“设置”>“系统”>“通知”中确认 Plumlist 的通知已打开，且“请勿打扰”已关闭。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
