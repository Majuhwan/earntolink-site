使用方法

查看 PDF 和图像

  1. 将 Paperwise PDF 设为默认应用后双击文件。应用运行时打开的文件会在新标签页中打开。
  2. 在视图菜单中选择单页、双页、阅读模式或演示。查找会列出所有匹配及上下文。

标注、签名和填写表单

  1. 使用标注工具栏进行高亮、备注、形状、手写和文本框。
  2. 选择“签名”以手绘、输入或导入签名。表单可使用本机保存的个人资料自动填写。

整理页面、合并和转换

  1. 打开页面缩略图以重新排序、旋转、删除或插入页面和其他 PDF。
  2. OCR、涂黑、比较、压缩、密码、PDF 转 Word 等工具位于“工具”菜单。保存时会先写入经验证的副本并保留旧版本备份。

将 PDF 转换为 Office 和电子书格式

  1. 在“工具 → 转换”中选择 PDF 转 Word、Excel、PowerPoint、文本、HTML、EPUB 或 RTF，添加文件后按“转换”。表格会变成 Excel 单元格，每页会变成可编辑的幻灯片。新文件保存在原文件旁边。
  2. PDF 转文本免费且不限次数。其他格式每个文件免费转换前 3 页，Pro 可转换整个文档。扫描的 PDF 没有文字，请先进行 OCR。
  3. “Office 和文本转 PDF”使用内置引擎将 .docx、.xlsx、.csv 和 .txt 转为 PDF，无需 Microsoft Office。PowerPoint 和旧格式（.doc、.xls、.ppt）在安装了 Microsoft Office 时使用它。
  4. 拼合会将标注和表单字段固定到页面中。页码标签可将页面命名为 i、ii、1、2……贝茨编号（Pro）会按列表顺序为多个文件加盖连续编号。

功能

  • 约 0.5 秒打开 PDF 和照片，用方向键浏览文件夹中的图片
  • 批注、签名、自动填写表单，直接编辑 PDF 中的文字
  • PDF 转 Word、Excel、PowerPoint、文本、HTML、EPUB，无需 Office 将 Word 和 Excel 转 PDF；OCR、涂黑、比较、压缩
  • 裁剪、调整大小、旋转、调色和标注图片，转换为 JPG、PNG、WebP、TIFF、PDF 等
  • 幻灯片放映、GIF 逐帧、显示相机信息和 GPS 的信息面板、扫描仪导入
  • 安全保存：检查新文件后才替换原文件，支持备份和恢复

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

PDF；图像：JPG、PNG、GIF、BMP、ICO、TIFF、WebP、SVG、PSD（HEIC、AVIF、JPEG XL、RAW 需免费 Windows 扩展）；XPS 和 OXPS 以 PDF 副本打开。可将 Office、HTML 和图像转为 PDF，并可将 PDF 转为 Word、Excel、PowerPoint、文本、HTML、EPUB、RTF 和图像。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

HEIC、AVIF 或 RAW 照片无法打开。

从 Microsoft Store 安装免费的 HEIF 图像扩展、AV1 视频扩展或 Raw 图像扩展，然后重新打开文件。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
