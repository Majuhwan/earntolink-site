使用方法

查看电池电量

  1. 先在 Windows 蓝牙设置中配对耳机。
  2. 通知区域图标显示所选设备的电量。打开面板可查看每只耳机、充电盒和充电状态。

随 Windows 启动

  1. 在“设置”中打开“随 Windows 启动”，电量将始终显示在通知区域。

功能

  • 在 Windows 托盘中显示耳机电量
  • 左右耳和充电盒电量、充电与佩戴状态（兼容 AirPods 和 Beats）
  • 显示 Windows 报告的任意蓝牙耳机电量
  • 打开充电盒或连接耳机时弹出卡片
  • 取下耳机自动暂停、低电量提醒（Pro）
  • 电池历史图表和音频输出切换（Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

设备不显示电量。

仅当设备报告电量时才会显示。AirPods 和 Beats 通过蓝牙 LE 发送；其他耳机需在连接状态下向 Windows 报告电量。请确认蓝牙已打开且设备已连接。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

“联系支持”无法打开邮件应用。

如果没有设置默认邮件应用，请选择“复制信息”，并通过任意邮件服务发送至 hello@earntolink.com。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。

联系支持

请发送邮件至 hello@earntolink.com，并注明应用名称和版本。在应用中使用“帮助”>“联系支持”会自动填入这些信息。
