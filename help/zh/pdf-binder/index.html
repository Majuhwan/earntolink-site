使用方法

合并和整理 PDF

  1. 选择“合并与整理”，添加 PDF 或整个文件夹（… 菜单），或拖入窗口。每个 PDF 都有自己的页面缩略图区域。
  2. 拖动页面调整顺序或移到另一个文档。放下时按住 Ctrl 为复制。Shift/Ctrl+单击可选择多页一起拖动。拖到“用所选页新建文档”即可新建文档。
  3. 旋转（旋转按钮）或删除（Delete）页面。Ctrl+Z 撤销、Ctrl+Y 重做，最多 100 步。
  4. 选择保存方式：一个 PDF，或每个文档分别保存（每个区域一个文件），然后保存。免费：每次最多 3 个源 PDF；Pro：不限。页面中的链接、注释和表单字段会保留。

拆分 PDF

  1. 选择“拆分”并打开 PDF（或在资源管理器中右键 → Split with PDF Binder）。
  2. 免费预设：每页、每 N 页或 1-3, 5, 8- 等范围（每次最多 10 个文件）。Pro 预设：按书签（1–3 级）、按文件大小（如 10 MB）或按空白分隔页（空白页会去掉）。
  3. 列表显示将生成的文件。文件名默认为 {name}_{range}（如 Report_1-3.pdf）；Pro 可用 {name} {n} {range} {from} {to} {pages} {bookmark} {date} 自定义规则。不会覆盖已有文件（Report (2).pdf）。

书签与输出选项（Pro）

  1. 书签：“保留”会把原书签移到新页面位置；“每个文件一个”会为每个合并的文件添加书签，并把原书签放在其下。拆分时勾选“书签 · 保留”可让每部分带上书签。
  2. 输出选项：压缩（轻度、推荐、强力，仅在文件变小时采用）、使用 {n} 和 {total} 的页码或页眉/页脚文字、水印文字、用 Windows OCR 生成可搜索文字（使用 Windows 已安装的 OCR 语言）、打开密码（AES-256）。
  3. 所有选项都可免费选择并标有 Pro；只有在保存时才会询问 Pro，购买后会立即继续保存。

资源管理器、监视文件夹和命令行

  1. 资源管理器（免费）：选中 PDF，右键 → Merge with PDF Binder 或 Split with PDF Binder。Windows 11 中位于“显示更多选项”内；“打开方式 → PDF Binder”也可以。这样打开的文件会进入已打开的窗口。
  2. 监视文件夹（Pro）：在“自动化”中选择要监视的文件夹和另一个结果文件夹，选择操作（按当前拆分设置拆分、应用输出选项或合并同时到达的文件）并开始。PDF Binder 打开期间运行，不更改原文件。
  3. 命令行（Pro）：pdfbinder merge <文件或文件夹> -o out.pdf [--bookmarks perfile]，pdfbinder split in.pdf --bookmarks 1 | --size 10 | --blank | --every 2 | --ranges "1-3,5" [-o 文件夹] [--name "{n} {bookmark}"]，另有 --compress、--numbers、--watermark、--ocr、--password。运行 pdfbinder help 查看全部选项。退出码：0 成功，1 用法错误，2 失败，3 需要 Pro。

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

PDF（受密码保护的 PDF 需输入密码打开）。Pro 还可将图片（JPG、PNG、TIFF、HEIC…）作为页面加入。结果始终保存为新文件，原文件不会被更改。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

PDF 要求输入密码。

输入打开 PDF 的密码。不知道密码的文件无法打开。保存的结果没有密码（在输出选项中设置密码需 Pro）。

合并后的 PDF 中的链接无法跳转。

网页链接和指向页面的链接会保留，并跟随页面到新位置。指向已删除页面的链接无处可去。使用其他文件“命名目标”的链接可能失效；书签（Pro）会重建，始终指向正确页面。

OCR 后找不到文字或语言不对。

PDF Binder 使用 Windows 内置的文字识别及已安装的 OCR 语言。请在 Windows 设置 → 时间和语言 → 语言和区域中添加该语言（光学字符识别）。已有文字的页面会跳过。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
