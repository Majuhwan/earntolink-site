使用方法

打开大文件

  1. 打开文件或将其拖入窗口。会自动检测分隔符、标题行、列类型和编码。
  2. 前几行立即显示，其余部分在后台准备，可查看进度并取消。

排序、筛选和查找

  1. 选择列标题进行排序或添加筛选（包含、等于、大于/小于、为空、正则）。
  2. 使用“查找”搜索所有列并显示匹配数。列统计信息显示在侧面板中。

整理列

  1. 使用列工具拆分、合并、去除空格、更改大小写或类型、填充空白、替换，或用 SQL 表达式新建列。
  2. 所有更改都可撤销和重做。

导出当前视图

  1. 选择“导出”，选择格式和编码（用于 Excel 选 UTF-8 BOM）后保存。免费版最多 10 万行。

功能

  • 打开 10 GB 以上的 CSV、Excel、Parquet、JSON，无需全部载入内存
  • 自动识别分隔符、类型和编码（含 GBK、Big5、Shift-JIS）
  • 数百万行流畅滚动的虚拟表格，可编辑可撤销
  • 排序、筛选、查找替换、列统计
  • 拆分、合并、清理、去重、透视、连接和 SQL（连接、拆分文件、透视和 SQL：Pro）
  • 导出为 CSV（可选编码）、Excel、Parquet、JSON（免费：最多 10 万行）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

打开：CSV、TSV、TXT、Excel (.xlsx)、Parquet、JSON。自动检测编码（UTF-8/16、CP949/EUC-KR、Shift-JIS、GBK、Big5、Windows-1252）。导出：可选编码的 CSV/TSV、.xlsx、Parquet、JSON。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

文字显示乱码。

从编码菜单手动选择，例如简体中文选 GBK，日文选 Shift-JIS。

超大文件排序失败。

大型排序需要与数据大小相当的临时磁盘空间。请释放系统盘空间后重试。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
