使用方法

截图

  1. 按截图快捷键，或选择区域、窗口、活动窗口或全屏模式。
  2. 在区域模式下，单击可吸附到窗口、面板或按钮，拖动可自行选择。放大镜可帮助精确定位边缘。

标注截图

  1. 使用箭头、形状、荧光笔、文字、编号步骤、模糊或聚光灯。撤销和重做不限次数。
  2. 复制、保存或拖到其他应用中。

复制屏幕上的文字

  1. 选择“复制文字”并拖动选择区域。使用 Windows 文字识别离线读取，也能读取二维码。免费版每天 10 次。

功能

  • 区域、窗口、全屏和滚动截图,带放大镜与窗口/元素自动吸附（滚动：Pro）
  • 箭头、文字、编号步骤、荧光笔、模糊和马赛克、聚光灯与放大镜标注（步骤与样式预设：Pro）
  • 用离线 Windows OCR 复制屏幕上任何文字,也能读取二维码（免费：每天 10 次）
  • 可搜索的图库:连同标注重新打开,按文字、标题或标签查找
  • 保存为 PNG、JPG、WEBP 或 PDF,复制为图片或文件,拖到任意应用
  • 全局快捷键、托盘常驻、支持多显示器和高 DPI — 无需账户,完全离线

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

保存：PNG、JPG、WEBP、PDF。导入：图像文件或剪贴板。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

按 Print Screen 键会打开其他工具。

在 Windows“设置”>“辅助功能”>“键盘”中关闭“使用 Print Screen 键打开屏幕截图”，然后在本应用中启用 Print Screen。

截图部分区域为黑色。

部分应用（如受保护的视频播放器）会阻止截图，这些区域无法截取。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
