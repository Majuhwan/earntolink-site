使用方法

保存网站上的菜谱

  1. 在浏览器中复制菜谱页面的网址。
  2. 在“导入”中将其粘贴到“网址”并选择“下载页面”。仅下载该页面及其菜谱照片。
  3. 检查标题、食材和步骤，然后选择“保存”。来源网址会与菜谱一起保存。

更改份数和单位

  1. 打开菜谱，使用“份数”旁的 + 和 −。用量会重新计算，适合时以分数显示（1 1/2 杯）。
  2. “单位”可在原始单位、公制（ml、g）和美制（杯、oz）之间切换。汤匙和茶匙保持不变。

烹饪模式

  1. 烹饪模式以大字逐步显示步骤，旁边列出食材。打开期间屏幕保持开启。
  2. 使用 ← 和 →（或“上一步”和“下一步”）。步骤中提到时间时，可用“计时器”按钮倒计时。

购物清单和膳食计划

  1. “添加到购物清单”会按当前份数将菜谱食材加入清单。相同食材会合并，并按商店区域分组。
  2. 使用 Pro 可在“膳食计划”中安排一周，然后选择“本周食材加入购物清单”一次性添加。

打印、PDF 和其他应用的文件

  1. 菜谱的“…”菜单中有“打印”和“导出 PDF”。购物清单可打印或复制为文本。
  2. “导入 > 从文件”可读取 JSON（schema.org）文件；Paprika 和 MealMaster 文件、多个网址一次导入、导出为 Paprika/MealMaster 以及菜谱 PDF 属于 Pro。

功能

  • 无广告保存网页菜谱（schema.org 菜谱数据）
  • 调整份数和换算单位（公制、美制）
  • 大字步骤、计时器、屏幕常亮的烹饪模式
  • 按商店区域合并食材的购物清单
  • 按现有食材搜索、标签、评分、打印和 PDF
  • 每周膳食计划、菜谱 PDF、批量导入（Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

应用会使用网络吗？

仅在选择“下载页面”时下载该页面及其菜谱照片。菜谱、照片、膳食计划和购物清单只保存在本机，绝不上传。没有账户、广告或跟踪；购买和更新由 Microsoft Store 处理。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

无法导入某个网站。

有些网站会阻止应用下载，或页面中没有菜谱数据。请在浏览器中选择并复制菜谱文字，粘贴到“粘贴文本或 HTML”，Ladlewise 会将其分为食材和步骤。

杯的用量看起来不一样。

各国的杯不同：韩国和日本菜谱为 200 ml，德国、法国和意大利通常为 250 ml，美国为 236.6 ml。Ladlewise 会根据菜谱中使用的词分别换算。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

“联系支持”无法打开邮件应用。

如果没有设置默认邮件应用，请选择“复制信息”，并通过任意邮件服务发送至 hello@earntolink.com。

联系支持

请发送邮件至 hello@earntolink.com，并注明应用名称和版本。在应用中使用“帮助”>“联系支持”会自动填入这些信息。
