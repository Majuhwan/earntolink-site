使用方法

添加账户

  1. 在网站上开启使用验证器应用的两步验证。网站会显示二维码和密钥。
  2. 在 Sixkeel 中选择“添加”。已保存的二维码图片选“图像文件”或“剪贴板”，屏幕上的二维码选“屏幕区域”(Pro)，otpauth:// 链接选“设置链接”，手动输入选“输入密钥”。
  3. 在网站上输入 Sixkeel 显示的 6 位验证码完成设置。

复制验证码

  1. 选择验证码或复制按钮。圆环显示剩余秒数，下方显示下一个验证码。
  2. 复制的验证码不会进入剪贴板历史和云剪贴板，30 秒后清除（设置 > 清除剪贴板）。

使用密码或 Windows Hello 锁定

  1. 账户始终按此电脑的 Windows 用户加密。在“设置 > 设置密码”中添加密码后，打开验证码需要密码。
  2. 设置密码后，开启 Windows Hello (Pro) 即可用面部、指纹或 PIN 解锁。自动锁定会在所选时间后以及 Windows 锁定时生效。

备份和还原

  1. “备份 > 导出备份”会保存一个用备份密码加密的 .sixkeel 文件（scrypt + AES-256-GCM）。请保存在 U 盘或另一台电脑上。
  2. “还原”会读取 .sixkeel 文件并添加列表中没有的账户。自动按版本备份到文件夹属于 Pro 功能。

从其他验证器应用迁移

  1. 在其他应用中将账户导出为文件（Aegis、2FAS、andOTP）或导出二维码。
  2. “导入 > 选择文件”(Pro) 读取文件；加密文件会要求输入密码。导出二维码请使用“添加 > 图像文件”或“屏幕区域”。

功能

  • 账户数量不限，支持基于时间和基于计数器的验证码
  • 通过二维码图片、剪贴板、设置链接或密钥添加
  • 加密保存在本机，可选密码，自动锁定
  • 复制的验证码不进入剪贴板历史并会自动清除
  • 加密备份和还原，不连接网络
  • Windows Hello、屏幕区域二维码、导入、文件夹、自动备份（Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

网站拒绝验证码。

基于时间的验证码需要电脑时钟准确。在 Windows“设置 > 时间和语言 > 日期和时间”中打开“自动设置时间”并选择“立即同步”。验证码即将更换时请等待下一个。

找不到二维码。

使用能看到完整二维码的清晰图像，或用“屏幕区域”只选择二维码。仍然失败时，用“输入密钥”输入网站在二维码旁显示的密钥。

忘记了密码。

密码不会保存在任何地方，因此无法找回或重置。若已开启 Windows Hello，请用它解锁后设置新密码；否则请还原备份。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

“联系支持”无法打开邮件应用。

如果没有设置默认邮件应用，请选择“复制信息”，并通过任意邮件服务发送至 hello@earntolink.com。

联系支持

请发送邮件至 hello@earntolink.com，并注明应用名称和版本。在应用中使用“帮助”>“联系支持”会自动填入这些信息。
