使用方法

添加照片文件夹

  1. 添加存放照片的文件夹。照片不会被复制或移动，文件夹中的更改会自动反映。
  2. 按日、月或年浏览时间线，使用年份快捷方式跳转。

评分、标签和相册

  1. 在查看器中按 0–5 评分，F 收藏，I 查看信息。在信息面板中添加标签。
  2. 创建相册，将任意文件夹的照片加入其中而无需复制。

清理重复照片

  1. 打开“重复项”可查看完全相同的副本和连拍、仅调整大小等相似照片。保留最佳的一张，其余移到回收站。

功能

  • 直接使用现有文件夹，无需导入或移动
  • 按日、月、年的时间线与地点，查看器、幻灯片和视频
  • 按人脸分组人物，离线世界地图显示地点（为多于一人命名：Pro）
  • 用 10 种语言描述照片来查找（Pro）
  • 重复和相似照片、收藏、星级、标签、相册、XMP
  • 批量导出、调整大小、转换和修正日期，原图不变（免费：每次 5 张）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

文件和输入内容仅在此电脑上处理，不会上传。部分功能首次使用时会下载一次模型或组件，之后可离线使用。没有帐户、广告或跟踪。

支持哪些文件格式？

照片：JPG、PNG、GIF、BMP、TIFF、WebP；HEIC、AVIF 和相机 RAW 需免费 Windows 扩展。视频：MP4、MOV、AVI、WMV、MKV 等 Windows 可播放的格式。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

部分照片没有地点。

地点来自照片中的 GPS 数据。关闭定位拍摄或被聊天软件删除 GPS 的照片没有地点。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
