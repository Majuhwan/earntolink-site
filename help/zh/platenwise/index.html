使用方法

使用扫描仪扫描

  1. 打开“扫描仪”并选择设备。会列出带 WIA 驱动程序的扫描仪；网络扫描仪需先在“设置 > 蓝牙和其他设备 > 打印机和扫描仪”中添加。
  2. 选择平板或进纸器（双面进纸器可选双面）、分辨率和颜色模式，然后选择“扫描”。再次扫描可添加页面；600 dpi 及以上需 Pro。
  3. 打开“扫描后打印”即可把扫描仪和打印机当作复印机使用。

手机照片和摄像头

  1. 将照片拖入窗口或选择“导入”。“摄像头”使用网络摄像头拍照。
  2. 会自动找到页面边缘并拉直。在“裁剪”中拖动角点进行调整；“自动”重新查找边缘，“整张图片”使用整张照片。
  3. 选择彩色、灰度、黑白或原图。彩色会去除阴影并使纸张变白。

保存 PDF

  1. 整理页面（上移/下移、旋转、删除），选择格式、纸张大小和文件大小，然后选择“保存”。所有页面合成一个 PDF。
  2. Pro：可搜索 PDF 添加不可见文字层（Windows OCR），可搜索和复制；“密码”保护 PDF；“删除空白页”和“按空白页拆分”整理进纸器批量扫描。

从页面复制文本

  1. 选择页面并选择“复制文本”。使用 Windows 中安装的 OCR 语言在本机识别；可在“设置”中选择语言或保持“自动”。

导入文件夹（Pro）

  1. 打开“文件夹导入”，选择文件夹并选择“添加到文档”。图片按名称顺序添加，并自动查找页面边缘。

功能

  • WIA 扫描仪：平板、进纸器、双面
  • 手机照片：自动查找边缘并校正透视

  • 多页 PDF、JPG、PNG、TIFF 和打印（免费）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

列表中没有我的扫描仪。

Platenwise 使用 Windows 内置的扫描接口（WIA）。请安装扫描仪厂商的驱动程序，确认“Windows 扫描”或“Windows 传真和扫描”能识别后选择“刷新”。网络扫描仪需先在“设置 > 蓝牙和其他设备 > 打印机和扫描仪”中添加。

页面边缘不正确。

当页面放在较深色的表面上且四个角都可见时识别效果最好。可在“裁剪”中将各角拖到页面角上，或选择“整张图片”。

无法识别文本或识别为错误的语言。

识别使用 Windows 中安装的 OCR 语言。请在“设置 > 时间和语言 > 语言和区域”中添加该语言（含光学字符识别），然后在 Platenwise 设置的“OCR 语言”中选择它。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

“联系支持”无法打开邮件应用。

如果没有设置默认邮件应用，请选择“复制信息”，并通过任意邮件服务发送至 hello@earntolink.com。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。

联系支持

请发送邮件至 hello@earntolink.com，并注明应用名称和版本。在应用中使用“帮助”>“联系支持”会自动填入这些信息。
