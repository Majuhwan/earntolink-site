使用方法

打开工具

  1. 在主页选择类别或在搜索框中输入以查找工具。
  2. 将文件拖入工具，设置选项后运行。除非另选文件夹，结果保存在“文档\Kemptly”。

释放磁盘空间

  1. 使用空间地图、重复文件、相似照片或大而旧的文件查看占用空间的内容。
  2. 所选文件会移到回收站。免费版每天最多 20 个。

撤销移动和重命名

  1. 打开“历史记录”。所有移动和重命名都会记录，并可撤销。

自动整理新下载的文件

  1. 在“文件夹规则”中添加包含条件（名称、类型、大小）和操作（移动、重命名、回收站）的规则。
  2. 免费版最多 3 条规则。

功能

  • 清理、去重、整理文件,随时可撤销
  • 压缩、转换和编辑图片与照片
  • PDF 合并、拆分、签名、OCR 和涂黑
  • 视频转换与剪切,转写为字幕
  • 搜索文档内容,按人脸或描述查找照片（Pro）
  • 工作流和监视文件夹,离线可用,无需账号（监视文件夹：Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

文件和输入内容仅在此电脑上处理，不会上传。部分功能首次使用时会下载一次模型或组件，之后可离线使用。没有帐户、广告或跟踪。

支持哪些文件格式？

图像：JPG、PNG、WEBP、BMP、TIFF、GIF、ICO（HEIC 和 AVIF 需免费 Windows 扩展）。文档：PDF；Word、Excel、PowerPoint 转 PDF 需已安装 Microsoft Office。邮件：EML、MBOX。音视频：MP4、MOV、MKV、MP3、WAV、M4A 等。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

无法将 Word、Excel 或 PowerPoint 转为 PDF。

此转换使用电脑上安装的 Microsoft Office。请安装桌面版 Office 并启动一次后重试。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
