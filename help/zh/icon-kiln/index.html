使用方法

用图像制作图标

  1. 将图像拖入窗口或打开图像。1024 px 以上的正方形图像效果最好。
  2. 选择输出类型和尺寸，在浅色和深色背景上查看预览，然后创建。
  3. 每次都会保存到新文件夹，不会覆盖之前的结果。

适配非正方形图像

  1. “完整显示”以透明边距显示整张图像，“填充”则裁剪中间部分。

创建网站图标包 (Pro)

  1. 选择“网站图标”。包含 favicon.ico、16 和 32 px PNG、Apple 触控图标、Android 192 和 512 px、Web 清单以及可粘贴的 HTML。

功能

  • Windows .ico 与 ICNS 图标（.icns）（.icns：Pro）
  • 网站图标套装和 HTML（Pro）
  • 16–1024 px PNG
  • 完整显示或裁剪填充
  • 离线，不上传，无广告
  • 免费：Windows .ico 和各尺寸 PNG · Pro：ICNS 图标（.icns）和网站 favicon 套装

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

输入：PNG、JPG、WebP、BMP 等常见图像。输出：Windows 图标（.ico，16–256 px）、PNG（16–1024 px）、ICNS (Pro)、网站图标包 (Pro)。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

大尺寸图标模糊。

源图像小于输出尺寸。源图像过小时会显示警告。请使用至少 1024 px 的图像。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
