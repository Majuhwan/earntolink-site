使用方法

分离歌曲

  1. 打开歌曲，选择 2 轨（人声和伴奏）、4 轨或 6 轨 (Pro)。
  2. 选择质量并开始。免费版每天可用标准质量分离 3 首歌曲。

混音和保存

  1. 在混音器中设置每轨的音量、静音和独奏。一键预设：卡拉 OK、仅人声、去除鼓。
  2. 将每个轨道或当前混音保存为 WAV、FLAC、MP3 或 M4A。

功能

  • 把歌曲分成 2、4 或 6 轨：人声、鼓、贝斯、吉他、钢琴、其他（6 轨：Pro）
  • Demucs v4 AI 在显卡或 CPU 上运行，完全离线
  • 带波形的混音台：同步播放、静音、独奏、音量
  • 一键生成卡拉OK、仅人声、去鼓版本
  • 将音轨或自己的混音导出为 WAV、FLAC、MP3、M4A
  • 批量队列、速度与调性、一次购买 Pro，无订阅（批量处理：Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

文件和输入内容仅在此电脑上处理，不会上传。部分功能首次使用时会下载一次模型或组件，之后可离线使用。没有帐户、广告或跟踪。

支持哪些文件格式？

打开：MP3、WAV、FLAC、M4A、AAC、OGG、Opus、WMA、AIFF 及视频文件中的音频。保存：WAV（24 位）、FLAC（24 位）、MP3（320 kbps）、M4A (AAC)。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

伴奏中残留少量人声。

分离不可能完美。高质量和最佳质量 (Pro) 会多次处理以减少残留声音。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

没有声音。

在 Windows 声音设置和音量合成器中检查输出设备和音量。如果其他应用独占使用音频设备，请关闭该应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
