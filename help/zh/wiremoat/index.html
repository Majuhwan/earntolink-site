使用方法

查看哪些应用在联网

  1. 实时列表按应用分组显示远程地址、主机名、端口和签名发布者，每秒更新。
  2. 新应用首次对外连接时，可在通知中直接允许或阻止。

阻止或允许应用

  1. 选择应用并选择“阻止”或“允许”。规则是名称以 ETLNW- 开头的 Windows Defender 防火墙规则，打开应用后第一次更改时 Windows 会请求一次权限。
  2. 免费版最多同时阻止 5 个应用，允许不限数量。

查看被拦截的连接尝试

  1. 在设置中开启拦截记录。开启期间，Windows 会审核防火墙拦截的连接（安全审核“筛选平台连接”失败），历史记录中会列出已阻止应用的尝试。
  2. 关闭此项或退出应用时，会将 Windows 审核设置恢复为原来的值。如果应用意外退出而未能恢复，设置中会显示“恢复”。连接较多的电脑上，开启期间安全日志会更快写满。

功能

  • 按应用的实时连接：路径、发布者、地址、端口、主机、状态
  • 新应用首次连接时提醒，可直接允许或阻止
  • 用 Windows Defender 防火墙规则阻止或允许应用
  • 无需管理员权限运行，每次打开应用只需一次 UAC 确认
  • 可选：记录被拦截的连接尝试（Windows 审核）
  • 锁定模式和工作 / 游戏配置文件（Pro）
  • 按应用的连接历史、CSV 导出（Pro）、托盘应用

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

卸载后规则仍然存在。

删除应用后 Windows 会保留防火墙规则。卸载前请在“设置”中删除规则。以 ETLNW- 开头的规则也可在 Windows Defender 防火墙中删除。

出现权限提示。

部分操作会更改系统设置或其他程序，需要管理员权限。请在“用户帐户控制”提示中选择“是”。选择“否”只会跳过该操作。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
