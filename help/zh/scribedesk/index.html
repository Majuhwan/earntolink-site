使用方法

转写文件

  1. 将文件或文件夹拖入队列。语言会自动检测，也可手动选择。
  2. 选择模型。模型越大越准确但越慢。模型在首次使用时下载一次。

编辑转写文本

  1. 播放音频时当前词会高亮。选择任意词可跳到该时刻。
  2. 修改文本、重命名或合并说话人，并使用查找和替换。

录制会议或通话

  1. 选择“录音”。麦克风和电脑声音分两轨录制，并标记为“我”和“对方”。

导出文本和字幕

  1. 选择“导出”，选择 TXT、SRT 或 VTT。字幕规则（每行字数、行数、CPS）会在导出前提示。

功能

  • 批量转写音视频文件和整个文件夹（免费：一次 3 个）
  • 99 种语言离线 Whisper，逐词时间戳
  • 说话人区分，重命名与合并说话人（自动识别：Pro）
  • 随播放同步的编辑器、查找替换、全局搜索
  • 字幕规则，导出 SRT/VTT/DOCX/CSV/JSON，字幕烧录（Word、CSV、JSON：Pro）
  • 会议录音、监视文件夹，无需账户，不上传（监视文件夹：Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

文件和输入内容仅在此电脑上处理，不会上传。部分功能首次使用时会下载一次模型或组件，之后可离线使用。没有帐户、广告或跟踪。

支持哪些文件格式？

音视频：MP3、M4A、WAV、MP4、MOV、MKV 等。导出：TXT、SRT、VTT；Word (DOCX)、CSV、JSON 需 Pro。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

转写文本错误很多。

请手动选择所说语言而非自动检测，并使用更大的模型。背景噪音越少，效果越好。

麦克风无法使用。

在“设置”>“隐私和安全性”>“麦克风”中，打开“麦克风访问权限”和“允许桌面应用访问麦克风”。然后在应用中选择正确的输入设备。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
