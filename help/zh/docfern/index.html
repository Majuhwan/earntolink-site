使用方法

从主页开始

  1. 在“新建”下选择文档、电子表格或演示文稿。
  2. 或选择模板：在库上方切换文档、电子表格和演示文稿。
  3. “最近”列出你最近打开的各类文件。“打开”可打开任何支持的文件。

使用标签页

  1. 每个文件在顶部打开一个标签页，图标颜色表示类型。
  2. Ctrl+Tab 和 Ctrl+Shift+Tab 在标签页和主页之间切换。选择标签页上的 × 关闭文件。
  3. 标签页中的菜单、工具栏和快捷方式属于该文件类型的编辑器（与 Folios、Spreadwell 和 Stagelit 相同）。

从文件资源管理器打开

  1. 右键单击文件，选择“打开方式”并选择 Docfern。要设为默认，请转到“设置”>“应用”>“默认应用”。
  2. 也可以把文件拖到主页上，会在对应的编辑器中打开。

免费版和 Pro

  1. 免费版包含 Folios、Spreadwell 和 Stagelit 免费版的全部功能。
  2. Pro 在主页“获取 Pro”中一次性购买，会开启三个编辑器的全部 Pro 功能。
  3. 在单独的 Folios、Spreadwell 或 Stagelit 应用中购买的 Pro 是不同的产品，不会解锁此处的 Pro（反之亦然）。

功能

  • 文档、电子表格和演示文稿在一个窗口的标签页中
  • 打开和保存 docx、xlsx 和 pptx；还能打开 doc、odt、rtf、HWPX、xls、csv、ods、ppt 和 odp
  • 主页提供新建文件、模板、主题和各类最近文件
  • 修订、批注、带公式的表格、目录
  • 带函数帮助的编辑栏、条件格式和图表
  • 神奇移动、演示者视图和在放映中播放的旁白
  • 所有文件类型都能导出 PDF
  • 免费使用；Pro 为一次性购买

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

文档 – 打开：.docx .dotx .docm .doc .rtf .odt .hwpx .hwp .md .txt .html；保存：.docx .dotx .rtf .md .html .txt；导出 PDF。电子表格 – 打开：.xlsx .xlsm .xls .csv .tsv .ods；保存：.xlsx .csv；PDF。演示文稿 – 打开：.pptx .potx .ppsx .pptm .ppt .odp；保存：.pptx；导出 PDF、图片、MP4。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
