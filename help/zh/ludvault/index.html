使用方法

导入游戏

  1. 自动查找 Steam、Epic、GOG、EA app、Ubisoft Connect、Battle.net、Riot、Xbox 和 itch.io 的游戏。仅读取启动器文件，不会修改。
  2. 其他程序或模拟器 ROM 文件夹可手动添加。

查找和启动

  1. 搜索、排序或按启动器、类型、状态、游戏时长分组，然后选择“开始游戏”。
  2. 通过每 5 秒检查运行中的程序记录游戏时长，从不读取游戏内存。

功能

  • 一个游戏库集中 Steam、Epic Games、GOG、EA app、Ubisoft Connect、Battle.net、Riot、Xbox/Microsoft Store、itch.io
  • 无需登录：读取启动器本地文件；可添加任意程序和模拟器 ROM 文件夹
  • 通过启动器启动；游戏时间记录并与 Steam 合并，不读取内存
  • 状态、评分、备注、标签、收藏、搜索、排序、自动分组、随机选择
  • 每个游戏和驱动器的占用空间，打开文件夹，通过启动器卸载
  • Pro：智能合集、统计、支持手柄的大屏幕、图片编辑、备份导出

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

游戏库、游戏时长和备注仅保存在此电脑上。如果打开从 Steam 商店获取信息，应用仅使用每款游戏的 Steam ID 请求公开商店信息，不使用帐户。没有广告或跟踪。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

列表中缺少某个游戏。

先打开一次启动器以更新本地库，然后刷新。不支持的启动器中的游戏可手动添加。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

“联系支持”无法打开邮件应用。

如果没有设置默认邮件应用，请选择“复制信息”，并通过任意邮件服务发送至 hello@earntolink.com。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。

联系支持

请发送邮件至 hello@earntolink.com，并注明应用名称和版本。在应用中使用“帮助”>“联系支持”会自动填入这些信息。
