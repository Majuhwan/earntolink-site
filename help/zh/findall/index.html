使用方法

按名称查找文件

  1. 首次选择要索引的驱动器和文件夹。新建、重命名和删除的文件会自动更新。
  2. 输入即可立即显示结果。可按类型、大小、日期筛选，并使用 ext:pdf、size:>100mb、dm:2025-06、"精确短语"、!排除 等语法。

随处搜索

  1. 按全局快捷键可打开小型搜索窗口。应用可在通知区域中待命。
  2. 用 ↑ ↓ 和 Enter 打开，Ctrl+Enter 在文件夹中显示，Ctrl+Shift+C 复制路径。

搜索文件内容 (Pro)

  1. 为 PDF、Word、Excel、PowerPoint、文本和代码打开内容索引。免费版显示包含该词的文件数量。
  2. Pro 会显示带高亮摘录的匹配文件，并提供图片文字 (OCR)、按描述搜索照片和人物。

功能

  • 边输入边搜文件名：百万文件毫秒出结果，实时更新
  • 筛选、通配符、正则、大小和日期；排序、预览、拖出文件
  • 全局快捷键在任何应用上打开小搜索框
  • 搜索 PDF、Word、Excel、PowerPoint、文本和代码的内容（Pro）
  • 按文字描述或人物查找照片（Pro）
  • 离线使用，无需账户和管理员权限

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

文件和输入内容仅在此电脑上处理，不会上传。部分功能首次使用时会下载一次模型或组件，之后可离线使用。没有帐户、广告或跟踪。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

找不到确实存在的文件。

请确认该驱动器或文件夹已包含在索引设置中。网络驱动器和 Windows 不允许读取的文件夹会被跳过。

处理速度慢。

大文件或大量文件需要更长时间。请关闭其他占用资源的应用，笔记本电脑请接通电源，并在任务完成前防止电脑睡眠。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
