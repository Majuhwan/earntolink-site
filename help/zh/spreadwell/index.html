使用方法

输入数据和公式

  1. 在单元格中输入，或以 = 开始输入公式。函数助手会显示参数和示例；单击或拖动单元格插入引用。
  2. 支持 F2、F4、Ctrl+D、Ctrl+R、Alt+= 等 Excel 快捷键。拖动填充柄可延续数字和日期。

排序、筛选和格式

  1. 使用“数据”菜单排序、筛选 (Ctrl+Shift+L) 和删除重复项，使用“格式”菜单设置数字格式和条件格式。

插入图表

  1. 选择数据后选择“插入”>“图表”(Alt+F11)。可选 8 种图表，高级图表需 Pro。

打印或导出 PDF

  1. 打开“文件”>“页面设置”设置方向、边距和缩放为一页，然后打印或导出 PDF。

功能

  • 打开并保存 Excel xlsx，支持 xls、csv、tsv、ods
  • Excel 快捷键，带函数助手的编辑栏
  • 自由布局：表格、图表、文本和形状
  • 30 多种表格样式、条件格式、数据验证
  • 打印预览和 PDF 导出、自动保存和恢复
  • 数据透视表、大型 CSV/Parquet 数据模式、高级图表（Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

打开和保存：Excel (.xlsx) 和 CSV。导出：PDF。现有 Excel 文件中的图表、图片和数据透视表保存时暂不保留，保存前会提示。数据模式 (Pro) 可打开数百万行的 CSV 和 Parquet。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

保存后 Excel 文件中的图表或数据透视表消失了。

现有 Excel 文件中的这些对象保存时暂不保留，保存前会显示警告。请使用“另存为”保留原文件，并从版本历史恢复旧版本。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
