使用方法

快速记录笔记

  1. 在任意位置按 Ctrl+Alt+N 打开小型快速笔记窗口，应用仅在通知区域时也可使用。

书写和格式

  1. 输入 #、-、[ ]、** 等 Markdown 快捷方式，或使用工具栏添加标题、列表、清单、表格和代码。
  2. 输入 [[ 链接另一条笔记。标题更改时链接会自动更新。

在其他电脑上使用

  1. Jottings 没有自己的同步服务。请在“设置”中将笔记文件夹放在 OneDrive 等云盘文件夹中。

功能

  • 全局快捷键快速笔记、通知区域图标、桌面便笺
  • 以普通 Markdown 文件保存在你的文件夹，原子保存、回收站和版本历史
  • 清单、表格、代码块、笔记链接、计算行
  • 压感手写、文档扫描、图片/PDF/录音附件
  • 智能文件夹、嵌套标签、所有语言快速搜索
  • 导入 Markdown 文件夹、ENEX、TextBundle、Takeout 和 Simplenote JSON

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

支持哪些文件格式？

笔记是 Markdown (.md) 文件，附件位于旁边的 _attachments 文件夹。导入：Markdown、文本、ENEX 等；笔记本文件（.one、.onepkg）需 Pro。导出：md、txt、html、rtf、pdf、ENEX、TextBundle；Word 和 EPUB 需 Pro。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

出现了笔记的冲突副本。

编辑期间笔记在磁盘上被更改（例如来自其他电脑）。两个版本都会保留，请比较后删除不需要的一个。

文件无法打开。

文件可能正在被其他应用使用、已损坏或格式不受支持。关闭正在使用该文件的应用后重试。支持的格式见上方问题。

无法保存或导出。

文件夹可能为只读，或磁盘空间不足。请选择其他文件夹，例如“文档”。如果在 Windows 安全中心开启了“受控制文件夹的访问权限”，请允许此应用。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

应用无法启动或无响应。

关闭并重新打开应用。如果问题仍存在，请前往“设置”>“应用”>“安装的应用”，打开此应用的“高级选项”并选择“修复”。“重置”会同时清除应用设置。
