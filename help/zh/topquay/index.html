使用方法

使用刘海

  1. 选择“显示刘海”。屏幕顶部中央会出现一个小栏，点击会直接传到下方的窗口。
  2. 将指针移到栏上即可展开：正在播放的媒体及控制、计时器和秒表、电池。移开即收起。
  3. 关闭设置窗口后刘海继续运行。可从通知区域图标再次打开设置。

媒体控制

  1. 支持 Windows 媒体控制的应用（音乐播放器、浏览器、视频应用）会显示标题、艺术家、封面和进度。
  2. 在展开的刘海中使用上一首、播放/暂停和下一首。

大小、位置和颜色

  1. 在“外观”中更改大小并左右移动刘海（例如对准笔记本摄像头）。
  2. 颜色主题、大尺寸、其他显示器、剪贴板与 CPU/内存小组件以及番茄钟属于 Pro。

功能

  • 屏幕顶部细栏，收起时点击穿透
  • 带封面和上一首/播放/下一首的播放信息
  • 带快速开始和提醒的计时器，带计圈的秒表
  • 电池电量和剩余时间，日期和时间
  • 全屏应用时隐藏，位置可调，按显示器缩放
  • 颜色主题、剪贴板与 CPU/内存小组件、番茄钟、其他显示器（Pro）

常见问题

什么是 Pro？

Pro 是在 Microsoft Store 中一次性购买的附加组件，不是订阅。可在使用同一 Microsoft 帐户登录的 Windows 电脑上使用。

如何在其他电脑上或重新安装后恢复 Pro？

使用购买时的帐户登录 Microsoft Store，然后选择“帮助”>“恢复购买”。

如何申请退款？

付款和退款由 Microsoft 处理。前往 account.microsoft.com >“订单历史记录”，选择订单并申请退款。适用 Microsoft 退款政策。

需要联网吗？我的数据会被发送吗？

不需要。文件和输入内容仅在此电脑上处理，不会上传。没有帐户、广告或跟踪。仅在 Microsoft Store 购买和更新时使用网络。

如何更新应用？

Microsoft Store 会自动安装更新。要立即检查，请打开 Microsoft Store >“库”，然后选择“获取更新”。

疑难解答

刘海消失了。

当该显示器上运行全屏游戏、视频或演示时，刘海会隐藏，结束后恢复。若要保持显示，请关闭“设置 > 全屏应用运行时隐藏”。独占全屏游戏始终会遮住刘海。

不显示媒体。

只显示向 Windows 媒体控制报告信息的应用（与 Windows 音量弹出窗口相同）。在应用中开始播放后，将指针移到刘海上。

已购买 Pro，但功能仍被锁定。

选择“帮助”>“恢复购买”。请确认 Microsoft Store 已使用购买时的帐户登录。刚购买后，确认可能需要几分钟。

如何更改应用语言？

应用跟随 Windows 显示语言。在“设置”>“时间和语言”>“语言和区域”中更改，然后重新启动应用。

“联系支持”无法打开邮件应用。

如果没有设置默认邮件应用，请选择“复制信息”，并通过任意邮件服务发送至 hello@earntolink.com。

联系支持

请发送邮件至 hello@earntolink.com，并注明应用名称和版本。在应用中使用“帮助”>“联系支持”会自动填入这些信息。
