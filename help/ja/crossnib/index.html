使い方

クロスヘアを作る

  1. 形 (十字・T 字・ドット・円・山形・三角・四角・円弧・放射) を選び、長さ、太さ、隙間、色、回転、縁取り、リング、中心ドットを調整します。
  2. 暗い・明るい・サンプル背景で確認し、プリセットとして保存します。無料版は 3 個まで保存できます。

10,000 個から選ぶ

  1. ライブラリを開きます。カテゴリ・色・サイズ・形で絞り込むか、「緑 円」のようなタグや #1234 のような番号を入力します。ランダムで 1 つ選ばれます。
  2. クロスヘアをクリックするとすぐに適用されます。星を付けるとお気に入りに入り、「コピーして編集」でデザイナーで調整できます。無料版は #1–#500(全カテゴリを含む)、Pro は 10,000 個すべてを使えます。

共有コードと PNG

  1. 「コードを読み込む」を選び、Crossnib コード、Counter-Strike 2 のクロスヘアコード(CSGO-…)、Valorant のクロスヘアプロファイルコード(0;P;…)を貼り付けます。ゲームのコードは 1080p 画面向けの近似です。読み込みは無料です。
  2. 「コードをコピー」で他の人が読み込めるコードを作れます。「PNG を書き出す」(Pro) はクロスヘアを 1×・2×・4× の透過画像として保存します。

ゲームで表示する

  1. 初回起動時はオーバーレイがオフです。クロスヘア画面のスイッチをオンにするか、Ctrl + Alt + H を押します。選んだモニターの中央にピクセル単位で正確に表示されます。
  2. ゲーム一覧にゲームを追加すると、そのゲームが前面にあるときだけ表示されます。

機能

  • 内蔵クロスヘア 10,000 個、11 カテゴリ、絞り込み・タグ検索・お気に入り・ランダム(無料版: 500 個)
  • ウィンドウ/ボーダーレスのゲームに重なる、クリック通過のクロスヘア
  • デザイナー: 十字・T 字・ドット・円・山形・三角・四角・円弧・放射、回転・縁取り・リング、PNG 画像(Pro)
  • 共有コード、Counter-Strike 2・Valorant コードの読み込み、PNG 書き出し(Pro)
  • グローバルショートカット、モニター選択、ゲームリスト、ゲーム別プリセット(Pro)、時計・システム情報・テキスト・画像オーバーレイ(Pro)
  • 注入・フック・メモリ読み取りなし、通知領域アプリ、CPU 1% 未満

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

ゲームでクロスヘアが表示されません。

排他的フルスクリーンではオーバーレイが隠れます。ゲームをボーダーレスまたはウィンドウ フルスクリーンにしてください。一部のアンチチートもオーバーレイを禁止します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

[お問い合わせ] でメール アプリが開きません。

既定のメール アプリがない場合は、[情報をコピー] を選択し、お使いのメール サービスから hello@earntolink.com に送信してください。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
