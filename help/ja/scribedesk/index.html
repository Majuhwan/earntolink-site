使い方

ファイルを文字起こしする

  1. ファイルまたはフォルダーをキューにドラッグします。言語は自動検出するか手動で選びます。
  2. モデルを選びます。大きいモデルほど正確ですが遅くなります。モデルは初回使用時に 1 回ダウンロードします。

文字起こしを編集する

  1. 音声を再生すると現在の語が強調表示されます。任意の語を選択するとその位置に移動します。
  2. テキストを修正し、話者名の変更や統合、検索と置換を行います。

会議や通話を録音する

  1. [録音] を選択します。マイクと PC の音声を 2 トラックで録音し、「自分」と「相手」として表示します。

テキストと字幕をエクスポートする

  1. [エクスポート] を選択し、TXT、SRT、VTT から選びます。字幕ルール (1 行の文字数・行数・CPS) はエクスポート前に警告します。

機能

  • 音声・動画ファイルやフォルダーを一括文字起こし(無料:一度に 3 件)
  • 99 言語のオフライン Whisper、単語タイムスタンプ
  • 話者識別、話者名の変更・統合(自動識別:Pro)
  • 再生連動エディター、検索と置換、全体検索
  • 字幕ルール、SRT・VTT・DOCX・CSV・JSON 書き出し、焼き込み(Word・CSV・JSON:Pro)
  • 会議録音、監視フォルダー、アカウント・アップロード不要(監視フォルダー:Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。一部の機能は初回使用時にモデルやコンポーネントを 1 回ダウンロードし、その後はオフラインで動作します。アカウント、広告、トラッキングはありません。

対応しているファイル形式は?

音声・動画: MP3、M4A、WAV、MP4、MOV、MKV など。エクスポート: TXT、SRT、VTT、Word (DOCX)・CSV・JSON (Pro)。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

文字起こしに誤りが多いです。

自動検出ではなく話した言語を選び、より大きなモデルを使ってください。雑音の少ない録音ほど結果が良くなります。

マイクが動作しません。

[設定] > [プライバシーとセキュリティ] > [マイク] で [マイクへのアクセス] と [デスクトップ アプリにマイクへのアクセスを許可する] をオンにします。その後、アプリで正しい入力デバイスを選択します。

処理が遅いです。

大きなファイルや多数のファイルは時間がかかります。ほかの重いアプリを閉じ、ノート PC は電源につなぎ、作業が終わるまでスリープしないようにしてください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
