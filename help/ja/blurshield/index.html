使い方

写真の顔と個人情報を隠す

  1. 写真を追加します。顔、電話番号、メール、カード・口座番号、ID 番号を自動で検出します。
  2. ボックスのオン/オフ、移動、新規描画を行います。ぼかし・モザイク・塗りつぶしを選んで保存します。元のファイルは変更されません。

動画の顔をぼかす

  1. 動画を開きます。顔はフレーム間で追跡され、タイムラインでトラックのオン/オフや開始・終了を設定します。
  2. ほかの物はボックスを描くと追跡します。元の音声付きの新しい MP4 にエクスポートします。無料版は 1 分以下の動画までです。

PDF を墨消しする

  1. PDF を開き、検出された個人情報を確認し、ページ上をドラッグして範囲を追加します。
  2. 保存します。ボックス下の文字はファイルから削除され、結果を再確認するため、隠した内容はコピーできません。

機能

  • 写真の顔を自動でぼかし、動画では顔を追跡して隠す
  • 画像内の電話番号・メール・カード・口座番号を検出
  • PDF の本物の墨消し: 文字を削除し結果を検証
  • 動画タイムライン: トラックの調整・分割、追従する枠、ピー音
  • EXIF・GPS の削除、フォルダー一括処理と監視フォルダー(一括・監視フォルダー:Pro)
  • チェックサム付き監査ログ、オフライン、アカウント不要(CSV 書き出し:Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

写真: JPG、PNG、WebP、HEIC (Windows 拡張機能が必要)。動画: MP4、MOV など Windows で再生できる形式、出力は MP4。文書: PDF。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

顔や番号が検出されませんでした。

小さい顔、横向きやぼやけた顔、手書きの番号は見逃すことがあります。結果を必ず確認し、残った部分にボックスを描いてください。

ファイルが開きません。

ファイルが別のアプリで開かれている、破損している、または対応していない形式の可能性があります。ファイルを使用しているアプリを閉じて再試行してください。対応形式は上の質問をご覧ください。

処理が遅いです。

大きなファイルや多数のファイルは時間がかかります。ほかの重いアプリを閉じ、ノート PC は電源につなぎ、作業が終わるまでスリープしないようにしてください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ
