使い方

ホームから始める

  1. [新規] で文書、スプレッドシート、プレゼンテーションのいずれかを選びます。
  2. またはテンプレートを選びます: ギャラリーの上で文書、スプレッドシート、プレゼンテーションを切り替えます。
  3. [最近使ったファイル] には最後に開いたすべての種類のファイルが表示されます。[開く] で対応するファイルを開きます。

タブで作業する

  1. ファイルごとに上部にタブが開き、アイコンの色で種類がわかります。
  2. Ctrl+Tab と Ctrl+Shift+Tab でタブとホームを移動します。タブの × で閉じます。
  3. タブ内のメニュー、ツール バー、ショートカットはそのファイルの種類のエディター (Folios、Spreadwell、Stagelit と同じ) のものです。

エクスプローラーから開く

  1. ファイルを右クリックし、[プログラムから開く] で Docfern を選びます。既定にするには [設定] > [アプリ] > [既定のアプリ] に移動します。
  2. ファイルをホームにドラッグすることもできます。それぞれ適切なエディターで開きます。

無料版と Pro

  1. 無料版には Folios、Spreadwell、Stagelit の無料版の機能がすべて含まれます。
  2. Pro はホームの [Pro を入手] から買い切りで購入でき、3 つのエディターの Pro 機能がすべて有効になります。
  3. 単体の Folios、Spreadwell、Stagelit アプリで購入した Pro は別の製品で、ここの Pro は有効になりません (逆も同じです)。

機能

  • 文書・スプレッドシート・プレゼンテーションを 1 つのウィンドウのタブで
  • docx、xlsx、pptx の表示と保存。doc、odt、rtf、HWPX、xls、csv、ods、ppt、odp も開けます
  • 新しいファイル、テンプレート、テーマ、すべての種類の最近使ったファイルがあるホーム
  • 変更履歴、コメント、数式付きの表、目次
  • 関数ヘルプ付きの数式バー、条件付き書式、グラフ
  • マジック ムーブ、発表者ビュー、スライド ショーで再生されるナレーション
  • すべてのファイルの種類を PDF にエクスポート
  • 無料で使えて、Pro は買い切り

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

文書 – 開く: .docx .dotx .docm .doc .rtf .odt .hwpx .hwp .md .txt .html、保存: .docx .dotx .rtf .md .html .txt、PDF エクスポート。スプレッドシート – 開く: .xlsx .xlsm .xls .csv .tsv .ods、保存: .xlsx .csv、PDF。プレゼンテーション – 開く: .pptx .potx .ppsx .pptm .ppt .odp、保存: .pptx、PDF・画像・MP4 エクスポート。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

ファイルが開きません。

ファイルが別のアプリで開かれている、破損している、または対応していない形式の可能性があります。ファイルを使用しているアプリを閉じて再試行してください。対応形式は上の質問をご覧ください。

保存またはエクスポートできません。

フォルダーが読み取り専用か、ディスクの空き容量が不足している可能性があります。ドキュメントなど別のフォルダーを選択してください。Windows セキュリティの [コントロールされたフォルダー アクセス] がオンの場合は、このアプリを許可します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
