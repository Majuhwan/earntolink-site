使い方

曲を始める

  1. ジャンル テンプレートやデモ曲を選ぶか、空の状態で始めます。
  2. ブラウザーからループをトラックにドラッグします。ループは常に曲のテンポとキーに合わせて再生されます。

オーディオ・MIDI を録音する

  1. トラックを録音待機にして入力を選び、録音を押します。カウントイン後に開始し、ループ録音ではすべてのテイクが残ります。

ミックスと書き出し

  1. ミキサーで音量・パン・センドを設定し、トラックごとにエフェクトを追加します。
  2. [書き出し] を選択し、WAV、MP3、MIDI から選びます。

機能

  • CC0 録音の 47 サンプル音源、12 シンセエンジン、8 ジャンル 1,008 ループ
  • 一緒に演奏するドラマー: 8 ジャンル × 3 スタイル、複雑さ/強さパッド、フィル、ベースに追従
  • シーン付きライブループ、ソング配置、ピアノロール、ステップシーケンサー、印刷できる楽譜表示
  • テイクとコンピング、フェード、タイムストレッチ、ビート合わせ、ピッチ補正
  • ギター/ベースアンプ 8 種、ペダル 14 種、チューナー、28 エフェクト、ラウドネスメーター、VST3/CLAP
  • WAV・MP3・M4A・FLAC・ステム・MIDI・DAWproject 書き出し、排他モード低レイテンシー

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

読み込み: WAV、MP3、FLAC などの一般的な音声、MIDI。書き出し: WAV、MP3、MIDI、FLAC・M4A・ステム・DAWproject (Pro)。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

録音が遅れて聞こえる、またはノイズが入ります。

オーディオ設定でオーディオ インターフェイスを選び、バッファー サイズを調整します。遅延を減らすには小さく、ノイズが出る場合は大きくします。ほかのオーディオ アプリを閉じてください。

音が出ません。

Windows のサウンド設定と音量ミキサーで出力デバイスと音量を確認します。別のアプリがオーディオ デバイスを排他的に使用している場合は、そのアプリを閉じます。

マイクが動作しません。

[設定] > [プライバシーとセキュリティ] > [マイク] で [マイクへのアクセス] と [デスクトップ アプリにマイクへのアクセスを許可する] をオンにします。その後、アプリで正しい入力デバイスを選択します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
