使い方

無劣化でカットする

  1. 動画を開くか、ウィンドウにドラッグします。すぐに開き、キーフレームはタイムラインにオレンジの目盛りで表示されます。
  2. 開始位置に移動し (矢印: 1 フレーム、Ctrl+矢印: キーフレーム)、I を押してから終了位置で O を押します。I/O ごとに区間が追加され、タイムラインで端をドラッグして調整します。
  3. エクスポートで残す/削除、1 つのファイル/区間ごと、形式を選んでエクスポートします。映像と音声は再エンコードせずコピーされます。スマート カットなしでは各区間は開始前のキーフレームから始まります (斜線表示)。

フレーム単位のスマート カット (Pro)

  1. エクスポートでスマート カットをオンにします。カット位置と最寄りのキーフレームの間のフレームだけを同じコーデックの Windows エンコーダーで再エンコードし、それ以外はそのままコピーします。
  2. スマート カットは H.264・HEVC 動画 (8 ビット 4:2:0) で動作します。HEVC には Windows の HEVC エンコーダー (HEVC ビデオ拡張機能またはグラフィックス カードのエンコーダー) が必要です。ない場合はキーフレームでカットして保存し、通知を表示します。

トラック・オーディオ・フレーム

  1. トラックで、結果に不要なオーディオ・字幕トラックのチェックを外します。オーディオをエクスポートは、チェックしたトラックを再エンコードせずに個別のファイルとして保存します。
  2. フレームを保存は、再生位置の正確なフレームを PNG で保存します。結合は、コーデック・画面サイズ・オーディオ トラックが同じファイルをつなぎます。

シーン・チャプター・リスト・一括処理 (Pro)

  1. シーンで分割は、動画のシーンの切り替わりごとに区間を作ります。チャプターは結合したファイルに区間ごとのチャプターを追加します。リストのインポート・エクスポートは CSV (開始・終了・名前) とチャプター テキスト (00:00 名前) を読み書きします。
  2. 一括処理は、複数ファイルの先頭と末尾から同じ秒数を無劣化でカットします。

作業を保存

  1. プロジェクトを保存は、区間・トラック・オプションを動画の横の .clipkeel.json に書き込みます。プロジェクトを開くで後から続けられます。元のファイルは変更されず、結果は新しいファイルになります。

機能

  • 再エンコードなしの無劣化カット、透かしなし (無料)
  • タイムラインにキーフレーム表示、フレーム単位の移動
  • 区間を残す/削除、1 ファイルまたは区間ごと
  • トラック・MP4/MKV/MOV・結合・音声トラック・PNG (無料)
  • Windows エンコーダーによるフレーム単位のスマート カット (Pro)
  • 一括処理・シーン分割・チャプター・区間リスト (Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

結果が開始位置より少し前から始まります。

無劣化カットはキーフレームからしか始められないため、開始位置の前のキーフレームから始まります (タイムラインの斜線部分)。開始をキーフレームに移動するか (Ctrl+矢印)、スマート カット (Pro) を使ってください。

プレビューで動画が再生されません。

再生には Windows にインストールされたビデオ コーデックを使います。停止中のフレームは常に表示され、Windows で再生できないファイルもカットできます。HEVC・AV1 の再生には Microsoft Store から対応する拡張機能をインストールしてください。

結合でファイルをつなげないと表示されます。

再エンコードなしでつなぐには、すべてのファイルのビデオ コーデック・画面サイズ・オーディオ トラックが同じである必要があります (同じカメラ・同じ設定)。異なるファイルは先に動画編集ソフトで変換してください。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

[お問い合わせ] でメール アプリが開きません。

既定のメール アプリがない場合は、[情報をコピー] を選択し、お使いのメール サービスから hello@earntolink.com に送信してください。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
