使い方

データと数式を入力する

  1. セルに入力するか、= で数式を始めます。関数ヘルパーが引数と例を表示し、セルをクリックまたはドラッグして参照を入れます。
  2. F2、F4、Ctrl+D、Ctrl+R、Alt+= など Excel のショートカットが使えます。フィル ハンドルをドラッグすると数値や日付が続きます。

並べ替え・フィルター・書式

  1. [データ] メニューで並べ替え、フィルター (Ctrl+Shift+L)、重複の削除を行い、[書式] メニューで表示形式と条件付き書式を設定します。

グラフを挿入する

  1. データを選択し、[挿入] > [グラフ] (Alt+F11) を選びます。8 種類から選べ、高度なグラフは Pro です。

印刷・PDF 書き出し

  1. [ファイル] > [ページ設定] で向き、余白、1 ページに収めるを設定し、印刷または PDF に書き出します。

機能

  • Excel の xlsx を開いて保存、xls・csv・tsv・ods にも対応
  • Excel のショートカット、関数ヘルパー付き数式バー
  • 表・グラフ・テキスト・図形を自由に配置できるシート
  • 30 以上のテーブル スタイル、条件付き書式、入力規則
  • 印刷プレビューと PDF 出力、自動保存と回復
  • ピボットテーブル、大容量 CSV/Parquet のデータモード、高度なグラフ (Pro)

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

対応しているファイル形式は?

開く・保存: Excel (.xlsx)、CSV。書き出し: PDF。既存の Excel ファイル内のグラフ・画像・ピボット テーブルは保存時にまだ保持されず、保存前に通知します。データ モード (Pro) は数百万行の CSV・Parquet を開けます。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

Excel ファイルのグラフやピボット テーブルが保存後に消えました。

既存の Excel ファイル内のこれらのオブジェクトは保存時にまだ保持されず、事前に警告が表示されます。[名前を付けて保存] で元のファイルを残し、バージョン履歴から以前の版を復元してください。

ファイルが開きません。

ファイルが別のアプリで開かれている、破損している、または対応していない形式の可能性があります。ファイルを使用しているアプリを閉じて再試行してください。対応形式は上の質問をご覧ください。

保存またはエクスポートできません。

フォルダーが読み取り専用か、ディスクの空き容量が不足している可能性があります。ドキュメントなど別のフォルダーを選択してください。Windows セキュリティの [コントロールされたフォルダー アクセス] がオンの場合は、このアプリを許可します。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。
