使い方

ゲームを取り込む

  1. Steam、Epic、GOG、EA app、Ubisoft Connect、Battle.net、Riot、Xbox、itch.io のゲームを自動で検出します。ランチャーのファイルは読み取るだけで変更しません。
  2. その他のプログラムやエミュレーターの ROM フォルダーは手動で追加します。

探して起動する

  1. 検索・並べ替えや、ランチャー・ジャンル・状態・プレイ時間でグループ化してから [プレイ] を選択します。
  2. プレイ時間は実行中のプログラムを 5 秒ごとに確認して記録し、ゲームのメモリは読み取りません。

機能

  • Steam、Epic Games、GOG、EA app、Ubisoft Connect、Battle.net、Riot、Xbox/Microsoft Store、itch.io を 1 つのライブラリに
  • サインイン不要: ランチャーのローカルファイルを読み取り。プログラムやエミュレーター ROM フォルダーも追加可能
  • ランチャー経由で起動、Steam と統合したプレイ時間の記録、メモリの読み取りなし
  • ステータス・評価・メモ・タグ・お気に入り、検索・並べ替え・自動グループ、ランダム選択
  • ゲーム別・ドライブ別の使用量、フォルダーを開く、ランチャーでアンインストール
  • Pro: スマートコレクション、統計、コントローラー対応ビッグピクチャー、アート編集、バックアップ

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

ライブラリ、プレイ時間、メモはこの PC にのみ保存されます。Steam ストアの情報取得をオンにすると、各ゲームの Steam ID だけを使って公開ストア情報を取得し、アカウントは使いません。広告やトラッキングはありません。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

ゲームが一覧にありません。

ランチャーを一度開いてローカル ライブラリを最新にしてから更新してください。非対応ランチャーのゲームは手動で追加できます。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

[お問い合わせ] でメール アプリが開きません。

既定のメール アプリがない場合は、[情報をコピー] を選択し、お使いのメール サービスから hello@earntolink.com に送信してください。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ

アプリ名とバージョンを記載して hello@earntolink.com にメールを送信してください。アプリの [ヘルプ] > [お問い合わせ] を使うと、この情報が自動で入ります。
