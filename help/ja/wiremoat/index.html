使い方

接続しているアプリを見る

  1. ライブ一覧が、リモート アドレス、ホスト名、ポート、署名発行元をアプリごとに 1 秒ごとに表示します。
  2. 初めてのアプリが外部に接続すると、通知から許可またはブロックできます。

アプリをブロック・許可する

  1. アプリを選択して [ブロック] または [許可] を選びます。ルールは名前が ETLNW- で始まる Windows Defender ファイアウォール ルールで、アプリを開いてから最初の変更時に Windows の確認が 1 回表示されます。
  2. 無料版は同時に 5 個までブロックでき、許可は無制限です。

ブロックされた接続の試行を見る

  1. 設定でブロック記録をオンにします。オンの間、Windows はファイアウォールが遮断した接続を監査ログに記録し(セキュリティ監査「フィルタリング プラットフォームの接続」の失敗)、履歴にブロックしたアプリの試行が表示されます。
  2. オフにするかアプリを閉じると、Windows の監査設定を元の値どおりに戻します。アプリが異常終了して戻せなかった場合は、設定に「元に戻す」が表示されます。接続の多い PC では、オンの間セキュリティ ログが早く埋まります。

機能

  • アプリ別のリアルタイム接続: パス、発行元、アドレス、ポート、ホスト、状態
  • 新しいアプリの初回接続を通知、その場で許可・ブロック
  • Windows Defender ファイアウォールの規則でアプリをブロック・許可
  • 管理者権限なしで動作、UAC の確認はアプリを開くごとに 1 回
  • ブロックされた接続の記録(任意、Windows の監査)
  • ロックダウン モードと仕事・ゲームのプロファイル(Pro)
  • アプリ別の接続履歴、CSV 書き出し(Pro)、通知領域アプリ

よく寄せられる質問

Pro とは何ですか?

Pro は Microsoft Store で 1 回購入するアドオンで、サブスクリプションではありません。同じ Microsoft アカウントでサインインした Windows PC で使用できます。

別の PC や再インストール後に Pro を使うには?

購入に使用したアカウントで Microsoft Store にサインインし、[ヘルプ] > [購入の復元] を選択します。

返金を受けるには?

支払いと返金は Microsoft が処理します。account.microsoft.com の [注文履歴] で注文を選択し、返金をリクエストします。Microsoft の返金ポリシーが適用されます。

インターネット接続は必要ですか? データは送信されますか?

いいえ。ファイルと入力内容はこの PC でのみ処理され、送信されることはありません。アカウント、広告、トラッキングはありません。インターネットは Microsoft Store での購入と更新にのみ使用します。

アプリを更新するには?

更新は Microsoft Store が自動でインストールします。今すぐ確認するには、Microsoft Store の [ライブラリ] で [更新プログラムを取得する] を選択します。

トラブルシューティング

アンインストール後もルールが残ります。

Windows はアプリを削除してもファイアウォール ルールを残します。アンインストール前に [設定] で削除してください。ETLNW- で始まるルールは Windows Defender ファイアウォールでも削除できます。

アクセス許可の確認が表示されます。

一部の操作はシステム設定や他のプログラムを変更するため、管理者権限が必要です。ユーザー アカウント制御で [はい] を選択します。[いいえ] を選ぶと、その操作だけがスキップされます。

Pro を購入したのに機能がロックされたままです。

[ヘルプ] > [購入の復元] を選択します。Microsoft Store に購入したアカウントでサインインしているか確認してください。購入直後は確認に数分かかることがあります。

アプリの言語を変更するには?

アプリは Windows の表示言語に従います。[設定] > [時刻と言語] > [言語と地域] で変更し、アプリを再起動します。

アプリが起動しない、または応答しません。

アプリを閉じて開き直します。解決しない場合は、[設定] > [アプリ] > [インストールされているアプリ] でこのアプリの [詳細オプション] を開き、[修復] を選択します。[リセット] を選ぶとアプリの設定も消去されます。

お問い合わせ
