Guías

Agregar una cuenta

  1. En el sitio web, active la verificación en dos pasos con una aplicación de autenticación. El sitio muestra un código QR y una clave.
  2. En Sixkeel, seleccione Agregar. Elija Archivo de imagen o Portapapeles para una imagen QR guardada, Área de la pantalla para un código QR en pantalla (Pro), Enlace de configuración para un enlace otpauth:// o Escribir clave.
  3. Escriba en el sitio web el código de 6 dígitos que muestra Sixkeel para terminar.

Copiar un código

  1. Seleccione el código o el botón Copiar. El anillo muestra los segundos restantes y debajo aparece el código siguiente.
  2. El código copiado no se guarda en el historial ni en el portapapeles en la nube y se borra a los 30 segundos (Configuración > Borrar portapapeles).

Bloquear con contraseña o Windows Hello

  1. Las cuentas siempre se cifran en este equipo para su usuario de Windows. Configuración > Establecer contraseña añade una contraseña necesaria para abrir los códigos.
  2. Con una contraseña, active Windows Hello (Pro) para desbloquear con rostro, huella o PIN. El bloqueo automático actúa tras el tiempo elegido y al bloquear Windows.

Copia de seguridad y restauración

  1. Copia de seguridad > Exportar guarda un archivo .sixkeel cifrado con una contraseña (scrypt + AES-256-GCM). Guárdelo en una unidad USB u otro equipo.
  2. Restaurar lee un archivo .sixkeel y añade las cuentas que faltan. Las copias automáticas con versiones en una carpeta son de Pro.

Pasar desde otra aplicación de autenticación

  1. En la otra aplicación, exporte las cuentas como archivo (Aegis, 2FAS, andOTP) o como códigos QR de exportación.
  2. Importar > Elegir archivo (Pro) lee el archivo; los archivos cifrados piden su contraseña. Para los códigos QR de exportación use Agregar > Archivo de imagen o Área de la pantalla.

Funciones

  • Cuentas ilimitadas, códigos basados en tiempo o contador
  • Agrega con imagen QR, portapapeles, enlace de configuración o clave
  • Cifrado en este equipo, contraseña opcional, bloqueo automático
  • Los códigos copiados no quedan en el historial y se borran
  • Copia cifrada y restauración, sin Internet
  • Windows Hello, QR de un área de la pantalla, importación, carpetas, copias automáticas (Pro)

Preguntas frecuentes

¿Qué es Pro?

Pro es un complemento de compra única en Microsoft Store, no una suscripción. Funciona en los PC con Windows que usen la misma cuenta Microsoft.

¿Cómo recupero Pro en otro PC o tras reinstalar?

Inicie sesión en Microsoft Store con la cuenta de la compra y seleccione Ayuda > Restaurar compra.

¿Cómo obtengo un reembolso?

Microsoft gestiona los pagos y reembolsos. Vaya a account.microsoft.com > Historial de pedidos, seleccione el pedido y solicite un reembolso. Se aplica la directiva de reembolso de Microsoft.

¿La aplicación necesita internet? ¿Se envían mis datos?

No. Los archivos y datos se procesan solo en este PC y nunca se envían. No hay cuentas, anuncios ni seguimiento. Internet solo se usa para compras y actualizaciones de Microsoft Store.

¿Cómo actualizo la aplicación?

Microsoft Store instala las actualizaciones automáticamente. Para comprobarlo ahora, abra Microsoft Store > Biblioteca y seleccione Obtener actualizaciones.

Solución de problemas

El sitio web rechaza el código.

Los códigos basados en tiempo necesitan la hora correcta. En Configuración de Windows > Hora e idioma > Fecha y hora, active Establecer la hora automáticamente y seleccione Sincronizar ahora. Si el código está por cambiar, espere al siguiente.

No se encuentra el código QR.

Use una imagen nítida con todo el código visible o seleccione solo el código con Área de la pantalla. Si aún falla, use la clave que muestra el sitio junto al código QR (Escribir clave).

Olvidé la contraseña.

La contraseña no se puede recuperar ni restablecer; no se guarda en ningún sitio. Si Windows Hello está activado, desbloquee con él y establezca una contraseña nueva. Si no, restaure una copia de seguridad.

Compré Pro, pero las funciones siguen bloqueadas.

Seleccione Ayuda > Restaurar compra. Compruebe que Microsoft Store tiene iniciada la sesión con la cuenta de la compra. Justo después de comprar, la confirmación puede tardar unos minutos.

¿Cómo cambio el idioma de la aplicación?

La aplicación usa el idioma de Windows. Cámbielo en Configuración > Hora e idioma > Idioma y región y reinicie la aplicación.

Contactar con soporte no abre el correo.

Si no hay una aplicación de correo predeterminada, seleccione Copiar información y envíe el texto a hello@earntolink.com desde cualquier servicio de correo.

Contactar con soporte

Escriba a hello@earntolink.com con el nombre y la versión de la aplicación. En la aplicación, Ayuda > Contactar con soporte añade esta información automáticamente.
