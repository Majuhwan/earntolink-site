사용법

사진의 얼굴·개인정보 가리기

  1. 사진을 추가합니다. 얼굴, 전화번호, 이메일, 카드·계좌번호, 주민·외국인등록번호를 자동으로 찾습니다.
  2. 상자를 켜거나 끄고 옮기거나 새로 그립니다. 흐림·모자이크·상자 중 고른 뒤 저장합니다. 원본은 바꾸지 않습니다.

영상의 얼굴 흐리기

  1. 영상을 엽니다. 얼굴을 프레임마다 따라가며, 시간 막대에서 트랙을 켜고 끄거나 시작·끝을 정합니다.
  2. 다른 물체는 상자를 그리면 따라갑니다. 원래 소리를 살린 새 MP4로 내보내며, 무료 버전은 1분 이하 영상까지입니다.

PDF 진짜 가림

  1. PDF를 열고 찾은 개인정보 목록을 확인한 뒤 쪽 위를 끌어 영역을 더합니다.
  2. 저장합니다. 상자 아래 글자를 파일에서 지우고 결과를 다시 확인하므로 가린 내용을 복사해 낼 수 없습니다.

기능

  • 사진 속 얼굴 자동 흐림, 영상에서는 얼굴을 따라가며 가림
  • 그림 속 전화번호·이메일·카드·계좌번호 찾아 가리기
  • PDF 진짜 가림: 글자를 파일에서 지우고 결과 확인
  • 영상 시간 막대: 트랙 자르기·나누기, 움직임 따라가는 상자, 삐 소리
  • EXIF·GPS 지우기, 폴더 일괄 처리와 감시 폴더(일괄·감시 폴더: Pro)
  • 체크섬 작업 기록, 오프라인, 계정·업로드 없음(CSV 내보내기: Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

사진: JPG, PNG, WebP, HEIC(Windows 확장 필요). 영상: MP4, MOV 등 Windows가 재생할 수 있는 형식, 결과는 MP4. 문서: PDF.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

얼굴이나 번호를 찾지 못했습니다.

작거나 돌아간 얼굴, 흐린 얼굴, 손글씨 번호는 놓칠 수 있습니다. 결과를 꼭 확인하고 남은 부분에 상자를 그립니다.

파일이 열리지 않습니다.

파일이 다른 앱에서 열려 있거나, 손상되었거나, 지원하지 않는 형식일 수 있습니다. 파일을 사용하는 다른 앱을 닫고 다시 시도합니다. 지원 형식은 위 질문을 참고합니다.

처리가 느립니다.

큰 파일이나 많은 파일은 시간이 더 걸립니다. 다른 무거운 앱을 닫고, 노트북은 전원을 연결하고, 작업이 끝날 때까지 PC가 절전 모드로 들어가지 않게 합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
