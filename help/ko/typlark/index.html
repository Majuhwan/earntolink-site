사용법

자판 고르기

  1. 42개 자판 중 하나를 고르거나 1분 실력 진단으로 시작 단계를 추천받습니다.

단계 연습

  1. 화면 자판과 손 그림을 따라 칩니다. 다음 키와 손가락이 강조됩니다.
  2. 입력하는 동안 속도와 정확도가 바뀝니다. 단계마다 별을 얻고 연속 일수를 이어 갑니다.

시간 검사

  1. 1·3·5분 중에서 고릅니다. 검사가 끝나면 키별 오타 지도가 연습할 키를 보여 줍니다.

기능

  • 38개 언어·42개 자판(한국어·일본어·중국어·아랍어·힌디어·태국어 포함)
  • 기본 자리부터 숫자·기호·악센트까지 단계 연습
  • 다음 키·손가락·손 그림을 보여 주는 화면 자판
  • 실시간 WPM·분당 타수·분당 글자 수와 정확도
  • 시간 검사, 실력 진단, 키별 오타 지도, 하루 목표와 연속 일수
  • 게임·추이 그래프·내 글·코드·프로필·인증서(Pro, 게임 1개 무료)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

누른 키와 화면이 맞지 않습니다.

앱에서 고른 자판과 Windows에서 쓰는 키보드가 같아야 합니다. Windows 입력 언어를 바꾸거나(Win + Space) 앱에서 맞는 자판을 고릅니다. 일본어는 로마자 입력, 중국어는 병음입니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

문의하기에서 메일 앱이 열리지 않습니다.

기본 메일 앱이 없으면 정보 복사를 선택하고, 사용하는 메일 서비스에서 hello@earntolink.com(으)로 보냅니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.

문의하기

앱 이름과 버전을 적어 hello@earntolink.com(으)로 메일을 보내십시오. 앱의 도움말 > 문의하기를 사용하면 이 정보가 자동으로 들어갑니다.
