사용법

타임라인 편집

  1. 미디어 보관함에서 클립을 타임라인으로 끌어 놓습니다. 빈틈은 저절로 메워지고 연결된 클립은 함께 움직입니다.
  2. J/K/L로 재생하고 재생 위치에서 분할, 잔물결 삭제를 합니다. 효과·전환·제목은 렌더링 없이 바로 재생됩니다.

예고편 만들기

  1. 예고편 템플릿을 고르고 장면 칸과 제목 카드를 채우면 음악이 맞춰집니다.

영상 내보내기

  1. 내보내기를 선택하고 해상도와 품질을 골라 MP4로 저장합니다. 무료 버전은 워터마크 없이 1080p까지 내보냅니다.

기능

  • 실시간 GPU 미리보기: 효과·전환·제목 바로 재생
  • 멀티캠(앵글 4개까지), 합성 클립, 자석 여러 트랙 타임라인
  • 필터 30·곡선·스코프, 색 바퀴·색 맞추기·LUT(Pro)
  • 전환 40개·애니메이션 제목 40개(무료 15개·12개)
  • EQ·컴프레서 트랙 믹서, 음악 30곡·효과음 200개
  • 자막 편집기, SRT/WebVTT, MP4 챕터 표시
  • 워터마크 없는 1080p 내보내기, 4K·HEVC·HDR·ProRes·AV1(Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

가져오기: MP4, MOV, MKV 등 Windows가 재생할 수 있는 영상, MP3·WAV·M4A 소리, JPG·PNG 그림, OpenTimelineIO·EDL. 내보내기: 1080p까지 MP4(4K·1440p·HEVC는 Pro), OpenTimelineIO·EDL·FCPXML.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

휴대폰 영상이 흐릿하게 보입니다.

휴대폰 HDR 영상(HLG·PQ)은 자동으로 톤 매핑합니다. 그래도 밋밋하면 클립에 색감을 적용하거나 노출·대비를 조절합니다.

미리 보기가 끊기거나 화면이 깨집니다.

PC나 그래픽 카드 제조사에서 그래픽 드라이버를 최신으로 업데이트합니다. 노트북이면 전원 어댑터를 연결하고 전원 모드를 최고 성능으로 설정합니다.

처리가 느립니다.

큰 파일이나 많은 파일은 시간이 더 걸립니다. 다른 무거운 앱을 닫고, 노트북은 전원을 연결하고, 작업이 끝날 때까지 PC가 절전 모드로 들어가지 않게 합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
