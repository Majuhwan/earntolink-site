Findall 도움말

Microsoft Store에서 받기

사용법

이름으로 파일 찾기

  1. 처음에 색인할 드라이브와 폴더를 고릅니다. 새 파일, 이름 변경, 삭제는 자동으로 반영됩니다.
  2. 입력하는 대로 결과가 나옵니다. 종류·크기·날짜로 거르고 ext:pdf, size:>100mb, dm:2025-06, "정확한 구절", !빼기 같은 문법을 씁니다.

어디서나 검색

  1. 전역 단축키를 누르면 작은 검색 창이 열립니다. 앱은 알림 영역에서 대기할 수 있습니다.
  2. ↑ ↓와 Enter로 열고, Ctrl+Enter로 폴더에서 보기, Ctrl+Shift+C로 경로를 복사합니다.

파일 내용 검색 (Pro)

  1. PDF, Word, Excel, PowerPoint, 텍스트, 코드의 내용 색인을 켭니다. 무료 버전은 낱말이 든 파일 수를 보여 줍니다.
  2. Pro는 강조된 발췌와 함께 파일을 보여 주고, 그림 속 글자(OCR), 말로 사진 찾기, 사람 찾기를 제공합니다.

기능

  • 입력하는 대로 파일 이름 검색: 백만 개도 몇 밀리초, 실시간 반영
  • 필터·와일드카드·정규식·크기·날짜, 정렬·미리 보기·끌어 놓기
  • 어느 앱에서든 단축키로 작은 검색창 열기
  • PDF·Word·Excel·PowerPoint·텍스트·코드 내용 검색(Pro)
  • 말로 설명하거나 사람별로 사진 찾기(Pro)
  • 오프라인, 계정·관리자 권한 필요 없음

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 일부 기능은 처음 사용할 때 모델이나 구성 요소를 한 번 내려받고, 그 뒤에는 인터넷 없이 작동합니다. 계정, 광고, 추적이 없습니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

있는 파일이 검색되지 않습니다.

그 드라이브나 폴더가 색인 설정에 들어 있는지 확인합니다. 네트워크 드라이브와 Windows가 읽기를 막는 폴더는 제외됩니다.

처리가 느립니다.

큰 파일이나 많은 파일은 시간이 더 걸립니다. 다른 무거운 앱을 닫고, 노트북은 전원을 연결하고, 작업이 끝날 때까지 PC가 절전 모드로 들어가지 않게 합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
