사용법

도구 열기

  1. 홈에서 분류를 고르거나 검색 칸에 입력해 도구를 찾습니다.
  2. 파일을 도구에 끌어 놓고 옵션을 정한 뒤 실행합니다. 결과는 따로 고르지 않으면 문서\Kemptly에 저장됩니다.

디스크 공간 정리

  1. 용량 지도, 중복 파일, 비슷한 사진, 크고 오래된 파일로 공간을 차지하는 항목을 확인합니다.
  2. 선택한 파일은 휴지통으로 이동합니다. 무료 버전은 하루 20개까지입니다.

이동·이름 변경 되돌리기

  1. 작업 기록을 엽니다. 모든 이동과 이름 변경이 기록되어 되돌릴 수 있습니다.

새로 받은 파일 자동 정리

  1. 폴더 규칙에서 조건(이름·종류·크기)과 동작(이동·이름 변경·휴지통)으로 규칙을 추가합니다.
  2. 무료 버전은 규칙 3개까지입니다.

기능

  • 파일 정리·중복 삭제·자동 분류, 언제든 되돌리기
  • 사진 압축·변환·편집
  • PDF 합치기·나누기·서명·OCR·가림
  • 영상 변환·자르기, 받아쓰기·자막
  • 문서 내용 검색, 얼굴·말로 사진 찾기(Pro)
  • 작업 흐름·감시 폴더, 오프라인, 계정 없음(감시 폴더: Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 일부 기능은 처음 사용할 때 모델이나 구성 요소를 한 번 내려받고, 그 뒤에는 인터넷 없이 작동합니다. 계정, 광고, 추적이 없습니다.

지원하는 파일 형식은 무엇입니까?

이미지: JPG, PNG, WEBP, BMP, TIFF, GIF, ICO(HEIC·AVIF는 무료 Windows 확장 필요). 문서: PDF, Word·Excel·PowerPoint→PDF는 설치된 Microsoft Office 사용. 메일: EML, MBOX. 소리·영상: MP4, MOV, MKV, MP3, WAV, M4A 등.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

Word·Excel·PowerPoint를 PDF로 바꿀 수 없습니다.

이 변환은 PC에 설치된 Microsoft Office를 사용합니다. 데스크톱용 Office를 설치하고 한 번 실행한 뒤 다시 시도합니다.

파일이 열리지 않습니다.

파일이 다른 앱에서 열려 있거나, 손상되었거나, 지원하지 않는 형식일 수 있습니다. 파일을 사용하는 다른 앱을 닫고 다시 시도합니다. 지원 형식은 위 질문을 참고합니다.

처리가 느립니다.

큰 파일이나 많은 파일은 시간이 더 걸립니다. 다른 무거운 앱을 닫고, 노트북은 전원을 연결하고, 작업이 끝날 때까지 PC가 절전 모드로 들어가지 않게 합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
