사용법

무음 자르기

  1. 녹화 파일을 엽니다. 무음을 자동으로 찾습니다.
  2. 프리셋(촘촘히·보통·여유 있게)을 고르거나 기준, 최소 무음 길이, 앞뒤 여유를 정합니다. 줄어드는 시간이 바로 표시됩니다.

자를 곳 확인·수정

  1. 미리 보기를 재생하면 잘린 곳은 건너뜁니다. J/K/L로 재생, C로 자르기/남기기, I/O/X로 범위를 자릅니다.
  2. Pro: 9개 언어의 군말(음, 어)도 찾습니다. 음성 인식은 이 PC에서 합니다.

내보내기

  1. 내보내기를 선택하고 MP4, 소리만, SRT 자막 중에서 고릅니다. 무료 버전은 15분 이하 파일까지입니다.
  2. Pro: Final Cut Pro·DaVinci Resolve(FCPXML), Premiere Pro(XML), EDL 컷 목록 내보내기와 여러 녹화 일괄 처리.

기능

  • 무음은 바로, 군말은 PC 안 음성 인식으로 찾기(군말: Pro)
  • 파형 타임라인: 남기기·자르기·길이 조절·직접 추가, 되돌리기
  • 잘린 곳을 건너뛰는 미리보기, J/K/L 키보드 편집
  • MP4(프레임 정확·스마트 컷), 소리, SRT 자막 내보내기(무료: 15분 이하 파일)
  • Final Cut·DaVinci Resolve·Premiere Pro·EDL 컷 목록(Pro)
  • 일괄 처리, 오프라인, 계정 없음, Pro 한 번 구매(일괄 처리: Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 일부 기능은 처음 사용할 때 모델이나 구성 요소를 한 번 내려받고, 그 뒤에는 인터넷 없이 작동합니다. 계정, 광고, 추적이 없습니다.

지원하는 파일 형식은 무엇입니까?

열기: MP4, MOV, MKV, MP3, WAV, M4A 등 Windows가 재생할 수 있는 영상·소리. 내보내기: MP4, M4A, MP3, WAV, FLAC, SRT, FCPXML·Premiere XML·EDL(Pro).

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

미리 보기에 화면이 나오지 않습니다.

미리 보기는 Windows Media Foundation을 사용합니다. HEVC 같은 일부 코덱은 Microsoft Store의 확장이 필요합니다. 내보내기는 그대로 됩니다.

미리 보기가 끊기거나 화면이 깨집니다.

PC나 그래픽 카드 제조사에서 그래픽 드라이버를 최신으로 업데이트합니다. 노트북이면 전원 어댑터를 연결하고 전원 모드를 최고 성능으로 설정합니다.

처리가 느립니다.

큰 파일이나 많은 파일은 시간이 더 걸립니다. 다른 무거운 앱을 닫고, 노트북은 전원을 연결하고, 작업이 끝날 때까지 PC가 절전 모드로 들어가지 않게 합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
