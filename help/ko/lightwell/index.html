사용법

사진 보정

  1. 사진을 열고 화이트 밸런스, 노출, 대비, 밝은 영역, 어두운 영역, 색 슬라이더를 씁니다. 자동 톤으로 시작점을 잡습니다.
  2. 이전/이후 단추를 길게 눌러 비교합니다. 모든 단계는 작업 내역에 남습니다.

자르기·리터치

  1. 자르기, 수평 맞추기, 원근으로 구도를 고칩니다. 복구 브러시나 복제 도장으로 잡티를 지웁니다.

내보내기

  1. 내보내기를 선택하고 형식, 크기, 품질을 골라 저장합니다. 원본 파일은 바뀌지 않습니다.

기능

  • 비파괴 현상: 화이트 밸런스, 톤, 곡선, 색상 혼합, 디테일, 효과
  • 붓·그레이디언트·방사형·광도·색상 마스크로 부분 보정
  • 30,000px까지의 16비트 레이어 편집기, 혼합 모드 27가지, 그룹, 클리핑 마스크
  • 벡터 펜, 스마트 개체, 레이어 스타일, 효과 60가지
  • HDR 합치기, 파노라마, 초점 쌓기, 내용 인식 채우기
  • 색 관리 내보내기(P3, Adobe RGB, CMYK TIFF, 16비트, AVIF, JPEG XL, OpenEXR, PDF)와 인쇄

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

지원하는 파일 형식은 무엇입니까?

열기: JPG, PNG, TIFF, WebP, 카메라 RAW·HEIC(무료 Windows 확장 필요). 내보내기: JPG, PNG, TIFF, WebP.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

RAW·HEIC 사진이 열리지 않습니다.

Microsoft Store에서 무료 Raw 이미지 확장이나 HEIF 이미지 확장을 설치한 뒤 다시 엽니다.

미리 보기가 끊기거나 화면이 깨집니다.

PC나 그래픽 카드 제조사에서 그래픽 드라이버를 최신으로 업데이트합니다. 노트북이면 전원 어댑터를 연결하고 전원 모드를 최고 성능으로 설정합니다.

저장하거나 내보낼 수 없습니다.

폴더가 읽기 전용이거나 디스크 공간이 부족할 수 있습니다. 문서 폴더 같은 다른 폴더를 선택합니다. Windows 보안의 제어된 폴더 액세스가 켜져 있으면 이 앱을 허용합니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.
