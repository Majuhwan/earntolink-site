사용법

스캐너로 스캔

  1. 스캐너를 열고 장치를 고릅니다. WIA 드라이버가 있는 스캐너가 표시됩니다. 네트워크 스캐너는 Windows 설정 > Bluetooth 및 장치 > 프린터 및 스캐너에서 추가한 뒤 나타납니다.
  2. 평판 또는 급지기(양면 급지기는 양면), 해상도, 색 모드를 고르고 스캔을 누릅니다. 스캔을 다시 누르면 쪽이 더해집니다. 600dpi 이상은 Pro입니다.
  3. 스캔 후 인쇄를 켜면 스캐너와 프린터를 복사기처럼 씁니다.

휴대폰 사진과 카메라

  1. 사진을 창으로 끌어 놓거나 가져오기를 누릅니다. 카메라는 웹캠으로 찍습니다.
  2. 쪽 가장자리를 자동으로 찾아 반듯하게 폅니다. 자르기에서 모서리를 끌어 고칩니다. 자동은 가장자리를 다시 찾고, 전체 그림은 사진 전체를 씁니다.
  3. 컬러·회색조·흑백·원본 중에서 고릅니다. 컬러는 그림자를 없애고 종이를 하얗게 만듭니다.

PDF 저장

  1. 쪽을 정리한 뒤(위·아래 이동, 회전, 삭제) 형식·용지 크기·파일 크기를 고르고 저장을 누릅니다. 모든 쪽이 PDF 하나로 저장됩니다.
  2. Pro: 검색 가능한 PDF는 보이지 않는 글자 층(Windows OCR)을 넣어 검색·복사가 됩니다. 암호로 PDF를 보호하고, 빈 쪽 제거·빈 쪽에서 나누기로 급지기 일괄 스캔을 정리합니다.

쪽에서 텍스트 복사

  1. 쪽을 고르고 텍스트 복사를 누릅니다. Windows에 설치된 OCR 언어로 이 PC에서 인식합니다. 언어는 설정에서 고르거나 자동으로 둡니다.

폴더 가져오기(Pro)

  1. 폴더 가져오기에서 폴더를 고르고 문서에 추가를 누릅니다. 그림이 이름 순서로 추가되고 쪽 가장자리를 자동으로 찾습니다.

기능

  • WIA 스캐너 스캔: 평판·급지기·양면
  • 휴대폰 사진: 쪽 가장자리 자동 찾기와 원근 보정
  • 그림자 없는 컬러·회색조·흑백
  • 여러 쪽 PDF·JPG·PNG·TIFF 저장과 인쇄(무료)
  • Windows OCR 검색 가능한 PDF·빈 쪽 제거(Pro)
  • 오프라인, 계정 없음, 구독 없는 한 번 구매 Pro

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

인터넷 연결이 필요합니까? 내 데이터가 전송됩니까?

아니요. 파일과 입력한 내용은 이 PC에서만 처리하며 외부로 보내지 않습니다. 계정, 광고, 추적이 없습니다. 인터넷은 Microsoft Store 구매와 업데이트에만 사용합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

스캐너가 목록에 없습니다.

Platenwise는 Windows에 들어 있는 스캐너 방식(WIA)을 씁니다. 제조사의 스캐너 드라이버를 설치하고, Windows 스캔이나 Windows 팩스 및 스캔에서 보이는지 확인한 뒤 새로 고침을 누르십시오. 네트워크 스캐너는 먼저 설정 > Bluetooth 및 장치 > 프린터 및 스캐너에서 추가해야 합니다.

쪽 가장자리가 맞지 않습니다.

쪽이 더 어두운 바탕 위에 있고 네 모서리가 모두 보일 때 가장 잘 찾습니다. 자르기에서 각 모서리를 쪽 모서리로 끌거나 전체 그림을 고르십시오.

텍스트가 인식되지 않거나 다른 언어로 인식됩니다.

인식은 Windows에 설치된 OCR 언어를 씁니다. 설정 > 시간 및 언어 > 언어 및 지역에서 그 언어(광학 문자 인식 포함)를 추가한 뒤 Platenwise 설정의 OCR 언어에서 고르십시오.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

문의하기에서 메일 앱이 열리지 않습니다.

기본 메일 앱이 없으면 정보 복사를 선택하고, 사용하는 메일 서비스에서 hello@earntolink.com(으)로 보냅니다.

앱이 시작되지 않거나 응답하지 않습니다.

앱을 닫고 다시 엽니다. 계속되면 설정 > 앱 > 설치된 앱에서 이 앱의 고급 옵션을 열고 복구를 선택합니다. 초기화를 선택하면 앱 설정도 지워집니다.

문의하기

앱 이름과 버전을 적어 hello@earntolink.com(으)로 메일을 보내십시오. 앱의 도움말 > 문의하기를 사용하면 이 정보가 자동으로 들어갑니다.
