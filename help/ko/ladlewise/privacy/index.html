Ladlewise 개인정보 처리방침

Ladlewise 앱은 개인 정보를 수집, 저장, 전송하지 않습니다.

열거나 만든 파일과 입력한 내용은 사용자의 PC에서만 처리합니다. 계정, 광고, 분석, 추적 기능이 없습니다.

구매와 라이선스 확인은 Microsoft Store가 처리하며 Microsoft 개인정보처리방침이 적용됩니다.

페이지 내려받기를 누를 때만 그 페이지 하나와 요리 사진을 내려받습니다. 요리법·사진·식단·장보기 목록은 이 PC에만 있고 올리지 않습니다. 계정·광고·추적이 없고, 구매와 업데이트는 Microsoft Store가 처리합니다.

지원팀에 메일을 보내면 메일 주소와 내용은 답장에만 사용합니다.
