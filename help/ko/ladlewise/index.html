사용법

웹 사이트의 요리법 저장

  1. 브라우저에서 요리법 페이지 주소를 복사합니다.
  2. 가져오기에서 웹 주소에 붙여넣고 페이지 내려받기를 선택합니다. 그 페이지와 요리 사진만 내려받습니다.
  3. 제목·재료·순서를 확인하고 저장을 선택합니다. 출처 주소가 요리법과 함께 남습니다.

인분·단위 바꾸기

  1. 요리법을 열고 인분 옆 +·−를 씁니다. 양이 다시 계산되고, 읽기 쉬우면 분수(1 1/2컵)로 보입니다.
  2. 단위에서 원래 단위·미터법(ml, g)·미국식(컵, oz)을 바꿉니다. 숟가락 단위는 그대로입니다.

요리 모드

  1. 요리 모드는 큰 글씨로 한 단계씩 보여 주고 옆에 재료를 둡니다. 열려 있는 동안 화면이 꺼지지 않습니다.
  2. ←·→(또는 이전·다음)로 넘깁니다. 단계에 시간이 있으면 타이머 단추로 바로 잽니다.

장보기 목록과 식단

  1. 장보기 목록에 추가를 누르면 보이는 인분 기준 재료가 목록에 들어갑니다. 같은 재료는 합쳐지고 매장 구역별로 묶입니다.
  2. Pro에서는 식단에서 한 주를 계획하고 이번 주 재료를 장보기 목록에를 선택해 한 번에 넣습니다.

인쇄·PDF·다른 앱 파일

  1. 요리법의 … 메뉴에 인쇄와 PDF로 내보내기가 있습니다. 장보기 목록은 인쇄하거나 텍스트로 복사할 수 있습니다.
  2. 가져오기 > 파일에서는 JSON(schema.org) 파일을 읽습니다. Paprika·MealMaster 파일, 여러 주소 한 번에, Paprika·MealMaster 내보내기, 요리책 PDF는 Pro 기능입니다.

기능

  • 웹 페이지의 요리법을 광고 없이 저장(schema.org 요리법 데이터)
  • 인분 조절·단위 변환(미터법, 미국식)
  • 큰 글씨 단계·타이머·화면 꺼짐 방지 요리 모드
  • 재료를 합치고 매장 구역별로 묶는 장보기 목록
  • 있는 재료로 찾기, 태그, 별점, 인쇄·PDF
  • 주간 식단표, 요리책 PDF, 일괄 가져오기(Pro)

자주 묻는 질문

Pro는 무엇입니까?

Pro는 Microsoft Store에서 한 번 구매하는 추가 기능이며 구독이 아닙니다. 같은 Microsoft 계정으로 로그인한 Windows PC에서 사용합니다.

다른 PC나 다시 설치한 뒤 Pro를 쓰려면 어떻게 합니까?

구매에 사용한 계정으로 Microsoft Store에 로그인한 뒤 도움말 > 구매 복원을 선택합니다.

환불은 어떻게 받습니까?

결제와 환불은 Microsoft가 처리합니다. account.microsoft.com > 주문 기록에서 주문을 선택하고 환불을 요청합니다. Microsoft 환불 정책이 적용됩니다.

앱이 인터넷을 사용합니까?

페이지 내려받기를 누를 때만 그 페이지 하나와 요리 사진을 내려받습니다. 요리법·사진·식단·장보기 목록은 이 PC에만 있고 올리지 않습니다. 계정·광고·추적이 없고, 구매와 업데이트는 Microsoft Store가 처리합니다.

앱은 어떻게 업데이트합니까?

Microsoft Store가 업데이트를 자동으로 설치합니다. 바로 확인하려면 Microsoft Store > 라이브러리에서 업데이트 받기를 선택합니다.

문제 해결

웹 사이트를 가져올 수 없습니다.

일부 사이트는 앱의 내려받기를 막거나 페이지에 요리법 데이터를 넣지 않습니다. 브라우저에서 요리법 글을 선택해 복사한 뒤 텍스트·HTML 붙여넣기에 붙여넣으면 재료와 순서로 나눕니다.

컵 양이 다르게 보입니다.

컵은 나라마다 다릅니다. 한국·일본 요리법은 200 ml, 독일·프랑스·이탈리아는 보통 250 ml, 미국은 236.6 ml입니다. Ladlewise는 요리법에 쓰인 단어에 따라 따로 바꿉니다.

Pro를 구매했는데 기능이 잠겨 있습니다.

도움말 > 구매 복원을 선택합니다. Microsoft Store에 구매한 계정으로 로그인되어 있는지 확인합니다. 구매 직후에는 확인에 몇 분 걸릴 수 있습니다.

앱 언어를 바꾸려면 어떻게 합니까?

앱은 Windows 표시 언어를 따릅니다. 설정 > 시간 및 언어 > 언어 및 지역에서 바꾼 뒤 앱을 다시 시작합니다.

문의하기에서 메일 앱이 열리지 않습니다.
