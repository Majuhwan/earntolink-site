1. Umum

EarnToLink (언투링크, "EarnToLink") melindungi data pribadi berdasarkan Undang-Undang Perlindungan Informasi Pribadi Korea. Kebijakan ini mencakup situs web earntolink.com dan aplikasi yang dibuat EarnToLink.

Ringkasan: situs web tidak menggunakan pendaftaran, formulir, cookie, analitik, maupun iklan. Aplikasi kami memproses file dan foto hanya di perangkat dan tidak pernah mengirimkannya ke mana pun.

2. Situs web

  • Tanpa pendaftaran, login, atau formulir.
  • Tanpa cookie, alat analitik, atau skrip iklan.
  • Situs web disajikan oleh GitHub Pages (GitHub, Inc.). GitHub dapat memproses log akses seperti alamat IP untuk operasional dan keamanan, sesuai GitHub General Privacy Statement.
  • Font Pretendard dimuat dari CDN jsDelivr, yang dapat menerima informasi permintaan seperti alamat IP browser Anda.
  • Jika cookie atau analitik suatu saat diterapkan, kebijakan ini akan diperbarui terlebih dahulu.

4. Aplikasi kami

Aplikasi yang tercakup: Roll Tidy (정리 싹), Roll Flick (넘겨 정리), Space Map (용량 지도), Dupeless (중복 싹), Archive Fix (한글 압축). Semuanya segera hadir.

  • Tanpa akun, iklan, analitik, pelaporan crash, atau pelacakan.
  • File dan foto yang dihapus masuk ke tempat sampah sistem (Baru Dihapus di iOS) dan dapat dipulihkan.
  • Pengaturan, catatan progres (Roll Flick) dan cache analisis foto (Roll Tidy: hash, ketajaman, kecerahan) tersimpan di penyimpanan aplikasi pada perangkat.
  • Pembayaran ditangani oleh masing-masing toko aplikasi. EarnToLink tidak pernah menerima rincian pembayaran.

5. Proyek klien

Jika proyek klien melibatkan data pribadi milik klien, ruang lingkup dan cara pemrosesan mengikuti kontrak dan perjanjian pemrosesan data dengan klien tersebut.

6. Pengungkapan kepada pihak ketiga

Kami tidak memberikan data pribadi kepada pihak ketiga, kecuali diwajibkan oleh hukum.

7. Hak Anda

Anda dapat meminta akses, perbaikan, penghapusan, atau penghentian pemrosesan kapan saja. Kirim permintaan ke hello@earntolink.com; kami akan menindaklanjutinya tanpa penundaan.

8. Penghapusan

Data pribadi dimusnahkan tanpa penundaan setelah masa retensinya berakhir atau tujuannya tercapai. File elektronik dihapus sehingga tidak dapat dipulihkan.

9. Keamanan

Akses ke email pertanyaan dibatasi hanya untuk perwakilan, dan kami tidak mengumpulkan data pribadi lebih dari yang diperlukan.
